What you need depends on what you do with Plugify. Each case has its own short list.

## Running a server

- A Counter-Strike 2 dedicated server on **Linux** or **Windows**, 64-bit.
- For the Metamod host, Metamod:Source 2.x installed on the server.

Nothing else is installed by hand: the build brings the host, the package manager, the language modules and the base plugins.

:read-more{icon="lucide:book-open" to="/builds/source2/installation" title="Installing the build"}

## Writing plugins

A language module carries the runtime of its language, so a server needs nothing installed for it. On your own machine you need the usual tools of the language to write and build a plugin.

| Language | On your machine | Runtime on the server |
|---|---|---|
| **C++** | A compiler with C++23 support and CMake | Not needed, plugins are native libraries |
| **C# (.NET)** | .NET SDK 10.0 | .NET 10, comes with the module |
| **Python** | Any editor | Python 3.12, comes with the module |
| **JavaScript** | Any editor | V8, comes with the module |
| **Lua** | Any editor | Lua 5.4, comes with the module |
| **Go** | Go compiler with cgo and a C compiler | Not needed, plugins are native libraries |
| **Rust** | Rust 1.85 or later (edition 2024) | Not needed, plugins are native libraries |

## Building the core

You need this only to embed Plugify into your own application or to work on the core itself.

- **Platforms**: Windows, Linux and macOS.
- **Compiler**: C++23 support. Clang, GCC, MSVC (Visual Studio 2022) and Apple Clang are used.
- **CMake** 3.14 or later, **Git**, and optionally **Ninja**.
- The libraries the core depends on ([asmjit](https://github.com/asmjit/asmjit), [glaze](https://github.com/stephenberry/glaze), [libsolv](https://github.com/openSUSE/libsolv), [valijson](https://github.com/tristanpenman/valijson)) are downloaded by CMake during the build.
