Plugify Source 2 is a ready-to-run Plugify pack for **Counter-Strike 2**: a host, language modules and the base plugins for the Source 2 SDK in one archive.

::build-download{build="plugify-source2"}
::

## Install in 3 steps

::steps
### Extract into `game/`
Extract the archive into the `game/` folder of the server, replacing files when asked.

### Start the server through the host
Launcher: `s2launcher` instead of `cs2`. Runtime: start `cs2` as usual. Metamod: start the server with Metamod installed.

### Check
Run `plg plugins` in the server console. The base plugins are listed as `Running`.
::
