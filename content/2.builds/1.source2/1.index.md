Plugify Source 2 is a ready-to-run Plugify pack for **Counter-Strike 2**: a host, language modules and the standard plugins for the Source 2 SDK in one archive.

::build-download{build="plugify-source2"}
::

## Quick install

::steps
### Download the archive
In the block above pick your OS and a host, then press **Download**. Not sure about the host? Take **Launcher**, or read [Choosing a Host](/builds/hosts).

### Extract it into `game/`
The archive holds the `bin/` and `csgo/` folders. Extract it into the `game/` folder of your server, so they merge with the folders of the same name. Replace files when asked.

```bash
tar -xzf plugify-source2-launcher-linux-1.1.0.tar.gz -C /path/to/server/game
```

### Start the server
How you start it depends on the host you picked:

- **Launcher**: run `s2launcher` instead of `cs2`, with the same arguments.
- **Runtime**: run `cs2` as usual.
- **Metamod**: install Metamod:Source first, then run `cs2` as usual.

### Check that it works
Type `plg plugins` in the server console. The standard plugins are listed as `Running`.
::
