## Requirements

- A Counter-Strike 2 dedicated server on Linux or Windows (64-bit).
- For the **Metamod** host, [Metamod:Source](https://www.sourcemm.net/downloads.php/?branch=master) 2.x installed on the server. It is not part of the pack.

:span{id="hosts"}

## Choosing a host

The host is the part that loads Plugify into the game. The rest of the pack is the same for every host.

| Host | How it starts | Platforms |
|---|---|---|
| **Launcher** (S2-Launcher) | Run `s2launcher` instead of `cs2`, with the same arguments | Linux, Windows |
| **Runtime** (S2-Launcher as a library) | The game loads Plugify by itself, so `cs2` is started as usual. Fits hosting panels where the start command can't be changed | Linux |
| **Metamod** (MM-Loader) | Plugify runs as a Metamod:Source plugin | Linux, Windows |

:read-more{icon="lucide:square-m" to="/builds/hosts/metamod-plugin/overview" title="MM-Loader"}

## Languages

The pack contains the language modules its own plugins are written in. The standard plugins are written in C++ and Go, so the pack includes these two modules. The list of components on the [download page](/builds/source2) shows the current ones. Modules for other languages are installed with one command, see [Adding packages](/builds/source2/contents#adding-packages).

## Installation

::steps
### Download
Pick the OS and host on the [download page](/builds/source2) and download the archive.

### Extract
The archive holds what goes inside the server's `game/` folder: the `bin/` and `csgo/` folders. Extract it into `game/`, replacing files when asked.

On Linux:
```bash
tar -xzf plugify-source2-launcher-linux-1.1.0.tar.gz -C /path/to/server/game
```

On Windows, extract the `.zip` with Explorer or any archiver.

The full archive is meant for a new installation. To update an installed build, follow [Updating](/builds/source2/updating) instead of extracting a new archive over it.

### Start the server

::tabs{variant="card"}
  ::div{label="Launcher"}
  Start `s2launcher` instead of `cs2`, with the same arguments:

  ```bash
  # Linux
  ./game/bin/linuxsteamrt64/s2launcher -dedicated +map de_dust2

  # Windows
  game\bin\win64\s2launcher.exe -dedicated +map de_dust2
  ```
  ::
  ::div{label="Runtime"}
  Start the server as usual, and the game loads Plugify by itself:

  ```bash
  ./game/bin/linuxsteamrt64/cs2 -dedicated +map de_dust2
  ```
  ::
  ::div{label="Metamod"}
  Make sure Metamod:Source is installed, then start the server as usual. Metamod loads Plugify from `csgo/addons/metamod/plugify.vdf`.
  ::
::

### Check
In the server console:

```bash
plg plugins
plg modules
```

The standard plugins and language modules are listed as `Running`.
::

## What goes where

All of Plugify lives in `game/csgo/addons/plugify/`:

- `envs/modules` and `envs/plugins`: the pack's language modules and plugins;
- `configs/`: your settings. Plugins keep their defaults inside their package and read your overrides from here;
- `data/`: translations and saved state of plugins. The archive puts the translations of the standard plugins here;
- `logs/`: logs;
- `.condarc`: the channels `mamba` installs and updates packages from;
- `build.json`: which build the host came with, and the host and core versions.

The full layout and the list of components are on the [Contents](/builds/source2/contents) page.
