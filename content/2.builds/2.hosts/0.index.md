A **host** is the part that loads Plugify into the game. It starts the plugin manager, gives the server console the `plg` and `mamba` commands and updates Plugify every server frame. Everything else, language modules, plugins and settings, is the same for every host.

There are three hosts for Counter-Strike 2. Two of them are builds of the same project, S2-Launcher.

| | Launcher | Runtime | Metamod |
|---|---|---|---|
| Project | S2-Launcher | S2-Launcher | MM-Loader |
| How the server starts | `s2launcher` instead of `cs2`, same arguments | `cs2` as usual | `cs2` as usual |
| What loads Plugify | The launcher starts the game itself | The game loads the `libserver_valve.so` library, which starts Plugify and passes control to the game | Metamod:Source loads Plugify as its plugin |
| Needs Metamod:Source | No | No | Yes |
| Platforms | Linux, Windows | Linux | Linux, Windows |
| Crash reports and profiler | Yes | Yes | No |

## Which one to pick

- **Launcher**: the default choice for a server where you control the start command. Nothing but Plugify is added to the game.
- **Runtime**: pick it when the start command can't be changed, for example on a hosting panel that always runs `cs2`. The server starts as usual and Plugify loads by itself.
- **Metamod**: pick it when the server already runs Metamod:Source plugins and you want Plugify next to them.

Plugins don't depend on the host: a plugin that works with one host works with the others.
