**S2-Launcher** loads Plugify into a Source 2 game without Metamod:Source. The same project is built in two forms:

| Form | File | How it works |
|---|---|---|
| **Launcher** | `game/bin/<platform>/s2launcher` | Replaces the game executable. It loads the engine and the game itself, with Plugify already inside. You start `s2launcher` with the arguments you would give `cs2` |
| **Runtime** | `game/csgo/bin/linuxsteamrt64/libserver_valve.so` | A library the game loads by itself on start. It starts Plugify and passes control to the game. You start `cs2` as usual. Linux only |

Both forms give the same result: the `plg` and `mamba` console commands, and Plugify updated every server frame.

## What it adds

- **Crash reports.** With Sentry turned on in `sentry.jsonc`, crash dumps are sent to your Sentry project together with the console output and Plugify log messages, see [Crash Detection](/builds/hosts/s2-launcher/crash-detection).
- **Profiler.** Start with `--profiler` to report the time of Plugify, its modules and plugins to the engine's VProf, see [Profiling](/builds/hosts/s2-launcher/profiling).
- **Log level.** `--verbosity=<level>` sets how much Plugify writes to the console.
- **Client mode.** The launcher also runs the game client, for testing plugins locally. The client must be started with `-insecure`.
