::alert{type="info" icon="lucide:package-open" to="/builds/source2/updating"}
**Installed the Plugify Source 2 build?** Update its packages with `mamba update` and its host with the host-only archive. This page covers a host installed on its own.
::

The host and the packages are updated separately: the host from a new archive, the language modules and plugins with `mamba`.

## Updating the host

::steps
### Stop the game

### Save `sentry.jsonc`
Copy `game/bin/<platform>/sentry.jsonc` if you changed it. The archive replaces it.

### Extract the new archive
Download the new archive from the [S2-Launcher releases](https://github.com/untrustedmodders/plugify-source2-launcher/releases) and extract it into `game/`, replacing files, as on [Installation](/builds/hosts/s2-launcher/installation). Your packages, settings and data in `csgo/addons/plugify/` are kept.

### Start the game
Put your `sentry.jsonc` back if you saved it, start the game and check the version:

```bash
plg --version
```
::

## Updating packages

In the console:

```bash
plg unload
mamba update -n modules --all
mamba update -n plugins --all
plg load
```

`-n` selects the environment to update. `mamba` looks for new versions only in the channels it knows about. A host installed on its own has no list of channels, so create `csgo/addons/plugify/.condarc` with the channels of your packages:

```yaml [.condarc]
channels:
  - https://untrustedmodders.github.io/plugify-module-cpp/
  - https://untrustedmodders.github.io/plugify-plugin-configs/
  - https://untrustedmodders.github.io/plugify-plugin-polyhook/
  - https://untrustedmodders.github.io/plugify-plugin-s2sdk/
```

Without it, pass the channels with `-c` in the update command, otherwise `mamba` finds nothing to update.

## Troubleshooting

- **`mamba` refuses to run.** Run `plg unload` first: package operations work only while Plugify is unloaded.
- **A package doesn't update.** Check that the channel of the package is reachable, and see the version you have with `mamba list -n plugins`.
- **The game crashes after an update.** Check the console output at start for errors of Plugify, its language modules and plugins.
