**MM-Loader** runs Plugify as a [Metamod:Source](https://www.sourcemm.net/) plugin. Metamod loads it from `csgo/addons/metamod/plugify.vdf`, and Plugify starts together with the other Metamod plugins of the server.

Pick this host when the server already uses Metamod:Source. The server is started as usual, and Plugify plugins work next to the Metamod ones.

## How it works

- Metamod:Source 2.x must be installed on the server first, see [Metamod](/builds/hosts/metamod-plugin/metamod).
- The Plugify library and the package manager live in `csgo/addons/plugify/bin/<platform>/`.
- When Metamod loads the plugin, Plugify starts and loads all language modules and plugins.
- `meta list` shows Plugify among the Metamod plugins, and the `plg` and `mamba` console commands work as with any other host.
