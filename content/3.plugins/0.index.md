## Base plugins

::alert{type="info" icon="lucide:package-open" to="/builds/source2"}
The base plugins (Configs, Permissions, PolyHook, DynCall and Source 2 SDK) are already included in the **Plugify Source 2** build.
::

- [S2SDK](/plugins/s2sdk/features): access to the Source 2 game: commands, events, entities, messages.
- [Config System](/plugins/config-system/features): reads plugin settings from JSON and JSONC and merges layers.
- [Permissions](/plugins/permissions/features): users, groups and permissions, with a database storage and commands for CS2.
- [PolyHook](/plugins/polyhook/features): function hooks with callbacks before and after the call.
- [DynCall](/plugins/dyncall/features): calls C functions by address at runtime.
