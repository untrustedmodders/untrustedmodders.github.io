The **Python Language Module** can be installed in two ways: manually downloading the release or using the Plugify package manager. This guide explains both methods and provides step-by-step instructions.

## **Method 1: Manual Installation**

::steps
### **Download the Release**
1. Go to the [Python Language Module repository](https://github.com/untrustedmodders/plugify-module-python3).
2. Navigate to the **Releases** section.
3. Download the archive for your platform: `plugify-module-python3-<version>-linux_64.tar.bz2`, `win_64` or `osx_arm64`.

### **Extract the Package**
1. Create a new folder inside `addons/plugify/envs`, for example `envs/python3`.
2. Extract the archive into it. The manifest `plugify-module-python3.pmodule` must end up in the root of that folder.

### **Verify Installation**
1. Run `plg load` in the server console, or restart the server.
2. Run `plg modules`: the module is listed as `python3_module`.
::

## **Method 2: Installation via Package Manager**

::steps
### **Open the Server Console**
The `mamba` command is built into the server console, so nothing has to be installed first. Package operations run while Plugify is unloaded: `plg unload` before them and `plg load` after. See [Commands](/builds/management/commands).

### **Install the Module**
1. Run the following commands in the server console:
   ```bash
   plg unload
   mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-python3/" plugify-module-python3
   plg load
   ```
   Enter the commands one at a time, as described in [Commands](/builds/management/commands).

### **Verify Installation**
1. Run `plg modules`: the module is listed as `python3_module`.
::

## **Folder Structure**

After installation, the Python Language Module should have the following folder structure:

::file-tree
---
tree:
- addons/plugify/envs:
    - modules:
        - bin:
            - libplugify-module-python3.so
        - lib:
            - plugify/
        - python3.12/
        - ^plugify-module-python3.pmodule^
---
::

### **Explanation**
- **`addons/plugify/envs/modules`**: The environment `mamba` installs language modules into. Other modules live in the same folder.
- **`bin`**: The module library: `plugify-module-python3.dll` on Windows, `libplugify-module-python3.so` on Linux, `libplugify-module-python3.dylib` on macOS.
- **`lib/plugify`**: The `plugify` Python package that plugins import (`plugify.plugin`, `plugify.pps`).
- **`python3.12`**: The embedded Python 3.12 runtime and its standard library. A separate Python installation is not needed.
- **`plugify-module-python3.pmodule`**: The module manifest file that describes the module and its language.

## **Troubleshooting**

### **Module Not Found**
- Ensure the repository URL is correct and accessible.

### **Installation Fails**
- Check your internet connection.
- Ensure you have the latest version of Plugify installed.
