The **JavaScript Language Module** can be installed in two ways: manually downloading the release or using the Plugify package manager. This guide explains both methods and provides step-by-step instructions.

## **Method 1: Manual Installation**

::steps
### **Download the Release**
1. Go to the [JavaScript Language Module repository](https://github.com/untrustedmodders/plugify-module-v8).
2. Navigate to the **Releases** section.
3. Download the archive for your platform: `plugify-module-v8-<version>-linux_64.tar.bz2` or `win_64`.

### **Extract the Package**
1. Create a new folder inside `addons/plugify/envs`, for example `envs/v8`.
2. Extract the archive into it. The manifest `plugify-module-v8.pmodule` must end up in the root of that folder.

### **Verify Installation**
1. Run `plg load` in the server console, or restart the server.
2. Run `plg modules`: the module is listed as `v8_module`.
::

## **Method 2: Installation via Package Manager**

::steps
### **Open the Server Console**
The `mamba` command is built into the server console, so nothing has to be installed first. Package operations run while Plugify is unloaded: `plg unload` before them and `plg load` after. See [Commands](/builds/management/commands).

### **Install the Module**
1. Run the following commands in the server console:
   ```bash
   plg unload
   mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-v8/" plugify-module-v8
   plg load
   ```
   Enter the commands one at a time, as described in [Commands](/builds/management/commands).

### **Verify Installation**
1. Run `plg modules`: the module is listed as `v8_module`.
::

## **Folder Structure**

After installation, the JavaScript Language Module should have the following folder structure:

::file-tree
---
tree:
- addons/plugify/envs:
    - modules:
        - bin:
            - plugify-module-v8.dll
            - libplugify-module-v8.so
        - lib/
        - v8/
        - ^plugify-module-v8.pmodule^
---
::

### **Explanation**
- **`addons/plugify/envs/modules`**: The environment `mamba` installs language modules into. Other modules live in the same folder.
- **`bin`**: Contains the compiled module binaries (`.dll` for Windows, `.so` for Linux and `.dylib` for macOS).
- **`lib`**: The `plugify` module for plugins (`plugify.mjs`) and the ICU data file.
- **`v8`**: The V8 engine libraries.
- **`plugify-module-v8.pmodule`**: The module manifest file that describes the module and its language.

## **Troubleshooting**

### **Module Not Found**
- Ensure the repository URL is correct and accessible.

### **Installation Fails**
- Check your internet connection.
- Ensure you have the latest version of Plugify installed.
