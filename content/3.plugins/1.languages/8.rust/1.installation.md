The **Rust Language Module** can be installed in two ways: manually downloading the release or using the Plugify package manager. This guide explains both methods and provides step-by-step instructions.

## **Method 1: Manual Installation**

::steps
### **Download the Release**
1. Go to the [Rust Language Module repository](https://github.com/untrustedmodders/plugify-module-rust).
2. Navigate to the **Releases** section.
3. Download the archive for your platform: `plugify-module-rust-<version>-linux_64.tar.bz2`, `win_64` or `osx_arm64`.

### **Extract the Package**
1. Create a new folder inside `addons/plugify/envs`, for example `envs/rust`.
2. Extract the archive into it. The manifest `plugify-module-rust.pmodule` must end up in the root of that folder.

### **Verify Installation**
1. Run `plg load` in the server console, or restart the server.
2. Run `plg modules`: the module is listed as `rust_module`.
::

## **Method 2: Installation via Package Manager**

::steps
### **Open the Server Console**
The `mamba` command is built into the server console, so nothing has to be installed first. Package operations run while Plugify is unloaded: `plg unload` before them and `plg load` after. See [Commands](/builds/management/commands).

### **Install the Module**
1. Run the following commands in the server console:
   ```bash
   plg unload
   mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-rust/" plugify-module-rust
   plg load
   ```
   Enter the commands one at a time, as described in [Commands](/builds/management/commands).

### **Verify Installation**
1. Run `plg modules`: the module is listed as `rust_module`.
::

## **Folder Structure**

After installation, the Rust Language Module should have the following folder structure:

::file-tree
---
tree:
- addons/plugify/envs:
    - modules:
        - bin:
            - plugify-module-rust.dll
            - libplugify-module-rust.so
        - ^plugify-module-rust.pmodule^
---
::

### **Explanation**
- **`addons/plugify/envs/modules`**: The root folder for the Rust Language Module.
- **`bin`**: Contains the compiled module binaries (`.dll` for Windows, `.so` for Linux, etc.).
- **`plugify-module-rust.pmodule`**: The module manifest file that describes the module and its language.

## **Prerequisites**

Before using the Rust Language Module, ensure you have the following installed:

### **Rust Toolchain**
The Rust Language Module requires the Rust compiler and Cargo (Rust's package manager).

::steps
### **Install Rust**
1. Visit [https://rustup.rs/](https://rustup.rs/)
2. Follow the instructions to install `rustup`, the Rust toolchain installer
3. Verify installation:
   ```bash
   rustc --version
   cargo --version
   ```

### **Install Required Targets** (Optional)
For cross-platform development, you may need to install additional targets:
```bash
# For Windows
rustup target add x86_64-pc-windows-msvc

# For Linux
rustup target add x86_64-unknown-linux-gnu

# For macOS
rustup target add x86_64-apple-darwin
```
::

## **Troubleshooting**

### **Module Not Found**
- Ensure the repository URL is correct and accessible.
- Verify that the module files are placed in the correct `envs` folder.

### **Installation Fails**
- Check your internet connection.
- Ensure you have the latest version of Plugify installed.

### **Rust Toolchain Not Found**
- Make sure Rust is properly installed and available in your system PATH.
- Try restarting your terminal or IDE after installing Rust.
