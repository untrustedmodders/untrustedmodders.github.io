The **Source 2 SDK** plugin (`s2sdk`) connects Plugify to a Counter-Strike 2 server. It exports about 1200 functions through its manifest, so plugins in every language can work with the game: commands, events, entities, messages and more. It runs on x86-64 Windows and Linux servers, under the [Plugify Source 2](/builds/source2) build.

## What it does

- **Console commands and ConVars.** Create commands and ConVars, hook existing ones, read and change their values. See [Console Commands](/plugins/s2sdk/guides/console-commands) and [Console Variables](/plugins/s2sdk/guides/console-variables).
- **Game events.** Hook events before or after the game fires them, change or block them, create and fire your own. See [Game Events](/plugins/s2sdk/guides/game-events).
- **Listeners.** Callbacks for the server and player lifecycle: map start and end, client connect, authentication, disconnect, entity creation, game frames and more. See [Global Listeners](/plugins/s2sdk/guides/global-listeners).
- **Entities and schemas.** Find entities, read and write their networked fields by class and field name, teleport, change models, deal damage. See [Entity Schemas](/plugins/s2sdk/guides/entity-schemas) and [Handle System](/plugins/s2sdk/guides/handle-system).
- **Players.** Names, SteamIDs, teams, languages, kicking players and changing their team, chat and console output.
- **User messages.** Create, send and hook protobuf messages such as chat text, hints and screen fades. See [User Messages](/plugins/s2sdk/guides/user-messages).
- **Visibility.** Hide entities from chosen players with CheckTransmit. See [Check Transmit](/plugins/s2sdk/guides/check-transmit).
- **Menus and votes.** Chat menus and the built-in Panorama vote. See [Menus](/plugins/s2sdk/guides/menus) and [Panorama Vote](/plugins/s2sdk/guides/panorama-vote).
- **Timers.** Repeating and one-shot timers.
- **Gamedata.** Signatures, offsets, virtual tables and patches in `s2sdk.gamedata.jsonc`, readable by other plugins. See [Gamedata](/plugins/s2sdk/guides/gamedata).
- **CS_Script.** JavaScript plugins can call the game's `point_script` API. See [CS_Script Integration](/plugins/s2sdk/guides/cs_script-integration).
- **Workshop addons, KeyValues, voice, traces and logging.**

The full list of functions with their signatures is on the [API Hub](https://api.plugify.net/?file=https://raw.githubusercontent.com/untrustedmodders/plugify-plugin-s2sdk/refs/heads/main/plugify-plugin-s2sdk.pplugin.in).

## When to use it

- Your plugin runs on a Counter-Strike 2 server and needs anything from the game.
- You want one API that works the same in C++, C#, Python, Go, JavaScript, Lua and other Plugify languages.
