First, let's look at what a simple command requires. Commands are registered with the `AddConsoleCommand` function. It takes a name, a description, command flags, a callback function and a hook mode (`HookMode.Pre` or `HookMode.Post`).

The callback is invoked every time the command is used. Its prototype is `ConCommandCallback`: it receives the caller's player slot (`-1` for the server console), the calling context (`ConCommandContext.Console` or `ConCommandContext.Chat`) and the arguments, and returns a `ResultType`. Example:

```csharp
public void OnPluginStart()
{
    var flags = ConVarFlag.LinkedConcommand | ConVarFlag.Release | ConVarFlag.ClientCanExecute;
    AddConsoleCommand("sm_myslap", "slap me baby!", flags, Command_MySlap, HookMode.Pre);
}

public ResultType Command_MySlap(int caller, ConCommandContext context, string[] arguments)
{
    return ResultType.Continue;
}
```

Now we've successfully implemented a command, though it doesn't do anything yet.
Returning `ResultType.Continue` lets the engine go on processing the command. For a command created by `AddConsoleCommand` the engine part does nothing, so this is harmless here, but for an existing command it means the original handler still runs.

```csharp
public ResultType Command_MySlap(int caller, ConCommandContext context, string[] arguments)
{
    return ResultType.Handled;
}
```

Returning `ResultType.Handled` (or `ResultType.Stop`) from a `Pre` callback stops the engine from processing the command: the original handler is skipped. See the `ResultType` enumeration in the API to learn more about these return values.

## Adding a Console Command

You can bind commands in the `OnPluginStart` (or anywhere you like).

::tabs{variant="card"}
  ::div{label="c#" icon="vscode-icons:file-type-csharp2"}
  ```csharp
  using Plugify;
  using s2sdk;
  using static s2sdk.s2sdk;
  
  public unsafe class Sample : Plugin
  {
      public void OnPluginStart()
      {
          var flags = ConVarFlag.LinkedConcommand | ConVarFlag.Release | ConVarFlag.ClientCanExecute;
          AddConsoleCommand("custom_command", "A command is registered during OnPluginStart", flags, 
          (caller, context, arguments) =>
          {
              if (caller == -1) return ResultType.Handled;
              PrintToServer("Custom command called.\n");
              return ResultType.Handled;
          }, HookMode.Post);
      }
  }
  ```

## Accessing Command Parameters

`arguments` array provides access to the calling command parameters. The first parameter will always be the command being called. Quoted values are returned unquoted, e.g.

```csharp
public ResultType OnCommand(int caller, ConCommandContext context, string[] arguments)
{
    PrintToServer($@"
        Command Caller: {caller}
        Command Context: {context}
        Arg Count: {arguments.Length}
        Arg String: {string.Join(" ", arguments[1..])}
        First Argument: {arguments[0]}
        Second Argument: {arguments[1]}
");
    return ResultType.Handled;
}
```

```shell
> custom_command "Test Quoted" 5 13

# Output
Command Caller: 1
Command Context: Console
Arg Count: 4
Arg String: Test Quoted 5 13
First Argument: custom_command
Second Argument: Test Quoted
```
