## Overview

The Panorama Voting System allows you to create custom Yes/No votes that appear in the CS2 UI. Players can vote using the native game interface, making it seamless and familiar.

::callout{type="info"}
**Key Features:**
- Native CS2 UI integration
- Customizable vote messages and pass/fail text
- Selective player targeting using bitmask
- Vote event callbacks (start, vote, end)
- Custom pass/fail logic with detailed vote statistics
- Automatic timeout handling
::

Players vote with F1 and F2 (the console commands `vote option1` and `vote option2`). The game accepts their votes only while the ConVar `sv_allow_votes` is `1`, which is its default value.

## Callback Types

The voting system uses two callback types:

### YesNoVoteHandler
Called for vote events (start, individual votes, end):

```csharp
void Handler(VoteAction action, int clientSlot, int choice)
```

- **VoteAction.Start**: Vote has started (clientSlot = -1, choice = -1)
- **VoteAction.Vote**: Player voted (clientSlot = client slot, choice = vote option)
  - `VOTE_OPTION1` (0) = Yes
  - `VOTE_OPTION2` (1) = No
- **VoteAction.End**: Vote has ended (clientSlot = -1, choice = VoteEndReason)

The `End` event is sent **before** the result callback runs, so it does not tell you whether the vote passed. Act on the outcome in the result callback.

### YesNoVoteResult
Called when vote ends to determine if it passed:

```csharp
Bool8 Result(int numVotes, int yesVotes, int noVotes, int numClients,
             int[] clientInfoSlot, int[] clientInfoItem)
```

- **Returns**: `true` to pass the vote, `false` to fail (in C# the delegate returns `Bool8`, which converts implicitly from `bool`)
- **numVotes**: Total votes cast (yes + no)
- **yesVotes**: Number of yes votes
- **noVotes**: Number of no votes
- **numClients**: Number of players in the vote pool
- **clientInfoSlot**: Slots of all players in the vote pool
- **clientInfoItem**: Vote of each of those players (`0` = yes, `1` = no, `5` = did not vote)

The result callback is not called when the vote is cancelled (`VoteEndReason.Cancelled`); the vote is shown as failed.

## Basic Vote Creation

There are two main functions to start a vote:

1. **`PanoramaSendYesNoVoteToAll`** - Creates a vote for all players
2. **`PanoramaSendYesNoVote`** - Creates a vote for specific players (using recipients bitmask)

Both return `true` if the vote started. They return `false` when another vote is in progress, when there are no recipients, when no result callback is given, or when the map's `vote_controller` entity has not been found yet (s2sdk looks it up on `round_start`, so start votes once a round is running, for example from a command).

### Simple Vote to All Players

::tabs{variant="card"}
::div{label="c#" icon="vscode-icons:file-type-csharp2"}
```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public class VoteExample : Plugin
{
    // Not exported by s2sdk: player slot shown as "Server" and the vote options
    private const int VOTE_CALLER_SERVER = 99;
    private const int VOTE_OPTION1 = 0; // Yes

    // Call this once a round is running (for example from a command)
    public void StartRestartVote()
    {
        // Create a simple vote for all players
        bool started = PanoramaSendYesNoVoteToAll(
            duration: 30.0,
            caller: VOTE_CALLER_SERVER,
            voteTitle: "#SFUI_vote_restart_game",
            detailStr: "",
            votePassTitle: "#SFUI_vote_passed_restart_game",
            detailPassStr: "",
            failReason: VoteCreateFailed.Generic,
            result: OnVoteResult,
            handler: OnVoteHandler
        );

        if (!started)
        {
            PrintToServer("Could not start the vote\n");
        }
    }

    // Called to determine if vote passes
    private Bool8 OnVoteResult(int numVotes, int yesVotes, int noVotes,
                               int numClients, int[] clientInfoSlot, int[] clientInfoItem)
    {
        PrintToServer($"Vote finished: {yesVotes} Yes, {noVotes} No, " +
                     $"{numVotes}/{numClients} voted\n");

        // Simple majority of the votes cast
        bool passed = yesVotes > noVotes;
        if (passed)
        {
            ServerCommand("mp_restartgame 1");
        }
        return passed;
    }

    // Called for vote events
    private void OnVoteHandler(VoteAction action, int clientSlot, int choice)
    {
        switch (action)
        {
            case VoteAction.Start:
                PrintToServer("Vote started!\n");
                break;

            case VoteAction.Vote:
                string vote = choice == VOTE_OPTION1 ? "Yes" : "No";
                PrintToServer($"Player {clientSlot} voted: {vote}\n");
                break;

            case VoteAction.End:
                VoteEndReason reason = (VoteEndReason)choice;
                PrintToServer($"Vote ended: {reason}\n");
                // The result callback runs after this event
                break;
        }
    }
}
```

## Enumerations

### CastVote
Vote choice values used in callbacks. s2sdk passes them as plain integers and does not export this enum, so define the constants you need in your plugin:

| Value | Description |
|-------|-------------|
| `VOTE_OPTION1` (0) | Yes vote |
| `VOTE_OPTION2` (1) | No vote |
| `VOTE_NOTINCLUDED` (-1) | Player not included in vote |
| `VOTE_UNCAST` (5) | Player didn't vote |

### VoteAction
Events passed to the handler callback:

| Value | Description | clientSlot | choice |
|-------|-------------|--------|--------|
| `Start` | Vote started | -1 | -1 |
| `Vote` | Player voted | client slot | vote choice (CastVote) |
| `End` | Vote ended | -1 | VoteEndReason |

### VoteEndReason
Reasons why a vote ended:

| Value | Description |
|-------|-------------|
| `AllVotes` | All possible votes were cast |
| `TimeUp` | Vote duration expired |
| `Cancelled` | Vote was manually cancelled |

## Recipients Bitmask (Selective Voting)

To create a vote for specific players, use `PanoramaSendYesNoVote` with a **recipients bitmask** (the `filter` parameter). Each bit in the `uint64` represents a player slot:

- **Bit 0** (value 1) = Player slot 0
- **Bit 1** (value 2) = Player slot 1
- **Bit 2** (value 4) = Player slot 2
- **Bit N** (value 2^N) = Player slot N

::callout{type="info"}
**Bitmask Construction:** Set bit N to 1 to include player slot N in the vote. The recipients value is the sum of all included player bit values.
::

### Building Recipients Bitmask

::tabs{variant="card"}
::div{label="c#" icon="vscode-icons:file-type-csharp2"}
```csharp
// Include specific players by slot
public ulong BuildRecipients(int[] playerSlots)
{
    ulong recipients = 0;
    foreach (int slot in playerSlots)
    {
        if (slot >= 0 && slot < 64)
        {
            recipients |= (1UL << slot);
        }
    }
    return recipients;
}

// Examples:
// Only player slot 0
ulong player0Only = 1UL << 0;  // = 1

// Only player slot 5
ulong player5Only = 1UL << 5;  // = 32

// Players 0, 1, and 2
ulong players012 = (1UL << 0) | (1UL << 1) | (1UL << 2);  // = 7

// Use in vote
int[] targetPlayers = { 0, 2, 5 };
ulong recipients = BuildRecipients(targetPlayers);

PanoramaSendYesNoVote(
    duration: 30.0,
    caller: VOTE_CALLER_SERVER,
    voteTitle: "#SFUI_vote_kick_player_other",
    detailStr: "Bob",
    votePassTitle: "#SFUI_vote_passed_kick_player",
    detailPassStr: "Bob",
    failReason: VoteCreateFailed.Generic,
    filter: recipients,
    result: OnVoteResult,
    handler: OnVoteHandler
);
```

## Custom Vote Pass Logic

The `result` callback allows you to implement custom logic for determining if a vote passes:

```csharp
// Require 60% yes votes
private Bool8 OnVoteResult(int numVotes, int yesVotes, int noVotes,
                           int numClients, int[] clientInfoSlot, int[] clientInfoItem)
{
    if (numVotes == 0) return false;

    double yesPercent = (double)yesVotes / numVotes * 100.0;
    bool passed = yesPercent >= 60.0;

    PrintToServer($"Vote: {yesPercent:F1}% yes ({yesVotes}/{numVotes})\n");
    return passed;
}

// Require majority of ALL clients (not just voters)
private Bool8 OnVoteResultStrict(int numVotes, int yesVotes, int noVotes,
                                 int numClients, int[] clientInfoSlot, int[] clientInfoItem)
{
    bool passed = yesVotes > (numClients / 2);
    PrintToServer($"Vote: {yesVotes}/{numClients} clients voted yes\n");
    return passed;
}

// Analyze individual votes
private Bool8 OnVoteResultDetailed(int numVotes, int yesVotes, int noVotes,
                                   int numClients, int[] clientInfoSlot, int[] clientInfoItem)
{
    PrintToServer("Vote details:\n");
    for (int i = 0; i < clientInfoSlot.Length; i++)
    {
        int slot = clientInfoSlot[i];
        int choice = clientInfoItem[i];
        string vote = choice switch
        {
            VOTE_OPTION1 => "Yes",
            VOTE_OPTION2 => "No",
            _ => "Did not vote",
        };
        PrintToServer($"  Slot {slot}: {vote}\n");
    }

    return yesVotes > noVotes;
}
```

## Vote Helper Functions

The voting system provides several utility functions:

### Check If Vote Is Active

```csharp
bool isVoting = PanoramaIsVoteInProgress();
if (isVoting)

    PrintToServer("A vote is currently active!\n");
```

### Remove Player From Vote

Removes a player from the current vote pool (they can no longer vote). Players who disconnect are removed automatically:

```csharp
PanoramaRemovePlayerFromVote(3);  // Remove player slot 3
```

### Check If Player Is In Vote Pool

```csharp
int playerSlot = 5;
if (PanoramaIsPlayerInVotePool(playerSlot))
{
    PrintToServer($"Player {playerSlot} can vote\n");
}
```

Clears the player's current vote and shows the vote UI to them again:

```csharp
bool success = PanoramaRedrawVoteToClient(playerSlot);
```

```csharp
PanoramaEndVote(VoteEndReason.Cancelled);
```

## Practical Examples

### Example 1: Map Vote with Team Restriction

Only allow Counter-Terrorists to vote on changing the map:

```csharp
public void StartMapVote()
{
    // Build recipients bitmask for CT team only
    ulong recipients = 0;
    for (int slot = 0; slot < 64; slot++)
    {
        if (!IsClientInGame(slot)) continue;

        if (GetClientTeam(slot) == CSTeam.CT)
        {
            recipients |= (1UL << slot);
        }
    }

    if (recipients == 0)
    {
        PrintToServer("No CT players to vote!\n");
        return;
    }

    PanoramaSendYesNoVote(
        duration: 30.0,
        caller: VOTE_CALLER_SERVER,
        voteTitle: "#SFUI_vote_changelevel",
        detailStr: "de_dust2",
        votePassTitle: "#SFUI_vote_passed_changelevel",
        detailPassStr: "de_dust2",
        failReason: VoteCreateFailed.Generic,
        filter: recipients,
        result: (numVotes, yesVotes, noVotes, numClients, slots, items) =>
        {
            bool passed = yesVotes > noVotes;
            if (passed)
            {
                // The result callback decides the outcome, so act here
                ServerCommand("changelevel de_dust2");
            }
            return passed;
        },
        handler: (action, clientSlot, choice) => { }
    );
}
```

### Example 2: Tracking Vote Progress

```csharp
private int totalYesVotes = 0;
private int totalNoVotes = 0;

public void StartTrackedVote()
{
    totalYesVotes = 0;
    totalNoVotes = 0;

    PanoramaSendYesNoVoteToAll(
        duration: 30.0,
        caller: VOTE_CALLER_SERVER,
        voteTitle: "#SFUI_vote_restart_game",
        detailStr: "",
        votePassTitle: "#SFUI_vote_passed_restart_game",

        result: (numVotes, yesVotes, noVotes, numClients, slots, items) =>
        {
            PrintToServer($"Final: {yesVotes} Yes, {noVotes} No\n");
            return yesVotes > (numClients / 2);  // Majority of all clients

        {
            switch (action)
            {
                case VoteAction.Start:
                    PrintToChatAll("Vote started: Restart match?");

                case VoteAction.Vote:
                    if (choice == VOTE_OPTION1)
                        totalYesVotes++;
                    else if (choice == VOTE_OPTION2)
                        totalNoVotes++;

                    PrintToChatAll($"Current: {totalYesVotes} Yes, {totalNoVotes} No");
                    break;

                case VoteAction.End:
                    VoteEndReason reason = (VoteEndReason)choice;
                    PrintToChatAll($"Vote ended: {reason}");
                    break;
            }
        }
    );
}
```

### Example 3: Player-Initiated Kick Vote

```csharp
public void StartKickVote(int callerSlot, int targetSlot)
{
    if (PanoramaIsVoteInProgress())
    {
        PrintToChat(callerSlot, "A vote is already in progress!");
        return;
    }

    string targetName = GetClientName(targetSlot);

    PanoramaSendYesNoVoteToAll(
        duration: 30.0,
        caller: callerSlot,
        voteTitle: "#SFUI_vote_kick_player_other",
        detailStr: targetName,
        votePassTitle: "#SFUI_vote_passed_kick_player",
        detailPassStr: targetName,
        failReason: VoteCreateFailed.Generic,
        result: (numVotes, yesVotes, noVotes, numClients, slots, items) =>
        {
            // Require 60% yes votes
            bool passed = numVotes > 0 && ((double)yesVotes / numVotes) >= 0.6;
            if (passed)
            {
                KickClient(targetSlot, NetworkDisconnectionReason.Kicked, "Kicked by vote");
            }
            return passed;
        },
        handler: (action, clientSlot, choice) =>
        {
            if (action == VoteAction.Start)
            {
                // Remove target from vote pool
                PanoramaRemovePlayerFromVote(targetSlot);
                PrintToChatAll($"Vote: Kick {targetName}?");
            }
        }
    );
}
```

## Translation Strings

The vote window shows the game's own translation strings from `resource/csgo_<language>.txt`. Where the text of a string contains `{s:s1}`, the game puts `detailStr` (or `detailPassStr`) there. Strings without `{s:s1}` show their fixed text, and the detail string is not shown. The game has no string for a free-form question, so pick the one that matches your vote:

| `voteTitle` | Text | `votePassTitle` | Text |
|---|---|---|---|
| `#SFUI_vote_restart_game` | Restart the match? | `#SFUI_vote_passed_restart_game` | Restarting the match... |

## Method Reference

### Starting Votes

| Method | Description |
|--------|-------------|
| `PanoramaSendYesNoVoteToAll(duration, caller, voteTitle, detailStr, votePassTitle, detailPassStr, failReason, result, handler)` | Start a vote for all players. Returns `true` if the vote started |
| `PanoramaSendYesNoVote(duration, caller, voteTitle, detailStr, votePassTitle, detailPassStr, failReason, filter, result, handler)` | Start a vote for specific players (using bitmask). Returns `true` if the vote started |

#### Parameters

- **`duration`** (double) - Maximum time in seconds for the vote
- **`caller`** (int) - Player slot who initiated the vote, or the server slot (`VOTE_CALLER_SERVER`, 99) for server votes
- **`voteTitle`** (string) - Translation string for the vote question, see [Translation Strings](#translation-strings)
- **`detailStr`** (string) - Text put into `{s:s1}` of `voteTitle`
- **`votePassTitle`** (string) - Translation string shown when the vote passes
- **`detailPassStr`** (string) - Text put into `{s:s1}` of `votePassTitle`
- **`failReason`** (VoteCreateFailed) - Reason shown when the vote fails (`VoteCreateFailed.Generic` for a plain "vote failed")
- **`filter`** (uint64) - Bitmask of player slots who can vote (only for `PanoramaSendYesNoVote`)
- **`result`** (YesNoVoteResult callback) - Function that determines if vote passes:
  ```csharp
  Bool8 Result(int numVotes, int yesVotes, int noVotes, int numClients,
               int[] clientInfoSlot, int[] clientInfoItem)
  ```
  - Returns `true` to pass the vote, `false` to fail
  - `numVotes`: Total votes cast
  - `yesVotes`: Number of yes votes
  - `noVotes`: Number of no votes
  - `numClients`: Number of players in the vote pool
  - `clientInfoSlot`: Slots of the players in the vote pool
  - `clientInfoItem`: Vote of each of those players (CastVote)

- **`handler`** (YesNoVoteHandler callback) - Function called for vote events:
  ```csharp
  void Handler(VoteAction action, int clientSlot, int choice)
  ```
  - `action`: Event type (Start, Vote, End)
  - `clientSlot`: Depends on action (client slot for Vote, -1 for Start and End)
  - `choice`: Depends on action (vote choice for Vote, VoteEndReason for End)

## Tips and Best Practices

1. **Check for active votes** - Always use `PanoramaIsVoteInProgress()` before starting a new vote
2. **Implement custom pass logic** - Use the `result` callback to define what "passing" means for your vote
3. **Track vote progress** - Use the `handler` callback's `VoteAction.Vote` event to monitor votes in real-time
4. **Disconnections are handled** - Players who disconnect are removed from the vote pool automatically
5. **Use appropriate durations** - 20-30 seconds is typical for most votes
6. **Validate recipients** - Ensure at least one player is in the recipients bitmask
7. **Use translation strings** - Stick to `#SFUI_vote` or `#Panorama_vote` strings for proper localization
8. **Remove vote targets** - Don't allow players being voted on to participate
9. **Separate logic** - Use `result` for pass/fail logic and for acting on the outcome, `handler` for progress events
10. **Log vote data** - Use `clientInfoSlot` and `clientInfoItem` arrays for detailed vote tracking
