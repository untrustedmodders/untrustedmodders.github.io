## Understanding User Messages

User messages are the primary method for sending custom data from the server to clients in Source 2. They use **Protocol Buffers (protobuf)** for serialization, providing a structured and efficient way to transmit game information.

Common use cases include:
- Displaying HUD elements and notifications
- Playing sounds or visual effects on clients
- Sending custom game state information
- Creating chat messages and hints
- Triggering client-side events

User messages work similarly to SourceMod's implementation, with protobuf replacing the old bitbuffer system for better type safety and flexibility.

::callout{icon="i-lucide-lightbulb" color="blue"}
**New**: The `UserMessage` class provides automatic resource management and cleaner syntax for working with user messages. It ensures proper cleanup and provides intuitive methods!
::

## Finding Message Definitions

You can find protobuf message definitions at:
- **CS:GO Protobufs**: [SteamDatabase/Protobufs](https://github.com/SteamDatabase/Protobufs/tree/master/csgo)
- These `.proto` files define available messages and their fields
- Common messages include `TextMsg`, `HintText`, `Fade`, and many more

Each message definition shows the message name, ID, and available fields with their types.

## Hooking User Messages

You can intercept user messages before they're sent to clients:

::tabs{variant="card"}
::div{label="c#" icon="vscode-icons:file-type-csharp2"}
```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public unsafe class Sample : Plugin
{
    public void OnPluginStart()
    {
        // Find message ID by name
        short msgId = UserMessageFindMessageIdByName("TextMsg");

        // Hook the message in Post mode
        HookUserMessage(msgId, OnTextMessage, HookMode.Post);
    }
    
    public void OnPluginEnd()
    {
        short msgId = UserMessageFindMessageIdByName("TextMsg");
        UnhookUserMessage(msgId, OnTextMessage, HookMode.Post);
    }
    
    private static ResultType OnTextMessage(nint userMessage)
    {
        // "param" is a repeated field, read its first element
        string text = PbReadString(userMessage, "param", 0);
        PrintToServer($"TextMsg intercepted: {text}\n");
        return ResultType.Continue;
    }
}
```

```lua
M.Sample = Sample
```

## Creating and Sending User Messages

An unknown message name or ID gives an invalid message: `UserMessageCreateFromName` and `UserMessageCreateFromId` return `0`, and the class has `IsValid == false`. Check it before writing fields.

::tabs
  ::div{label="With Classes (Recommended)" icon="lucide:box"}
  Create user messages using the `UserMessage` class with automatic cleanup:
  ```csharp
  // Create from message name (most common)
  using (var msg = new UserMessage("TextMsg"))
  {
      // Set recipients
      msg.AddAllPlayers();

      // Set message fields ("param" is a repeated field)
      msg.AddString("param", "Hello from server!");
      msg.SetUInt32("dest", 3);  // 3 = chat

      // Send the message
      msg.Send();
  } // Automatically destroyed

  // Or create from message ID
  short msgId = UserMessage.FindMessageIdByName("TextMsg");
  using (var msg = new UserMessage(msgId))
  {
      // Configure and send...
  }
  ```
  ::
  ::div{label="Without Classes" icon="lucide:code"}
  Create user messages using explicit functions:
  ```csharp
  // Method 1: From message name (most common)
  nint msg = UserMessageCreateFromName("TextMsg");

  // Method 2: From message ID
  short msgId = UserMessageFindMessageIdByName("TextMsg");
  nint msg = UserMessageCreateFromId(msgId);

  // Method 3: From serializable (advanced)
  nint msg = UserMessageCreateFromSerializable(msgSerializable, message, recipientMask);

  // Set recipients (choose one approach)
  UserMessageAddAllPlayers(msg);  // All players
  // OR
  UserMessageAddRecipient(msg, playerSlot);  // Single player
  // OR
  UserMessageSetRecipientMask(msg, customMask);  // Custom mask

  // Set message fields
  PbAddString(msg, "param", "Hello from server!");
  PbSetUInt32(msg, "dest", 3);  // 3 = chat

  // Send the message
  UserMessageSend(msg);

  // Clean up (IMPORTANT! Sending does not free the message)
  UserMessageDestroy(msg);
  ```

## Reading and Writing Data Types

User messages support various data types. You can use either the `UserMessage` class methods (recommended) or the `PbRead*`, `PbGet*` and `PbSet*` functions. `Read*` returns the value directly; `Get*` returns `true`/`false` and writes the value to a `ref` parameter. The `index` argument of `Read*` is `-1` for a normal field and the element index for a repeated field.

Message and field names in the snippets below are placeholders: use a real message and the field names from its `.proto` definition. The setter must match the field type (`SetUInt32` for a `uint32` field, `SetInt32` for `int32`), otherwise it returns `false`.

### Integers

::tabs
  ::div{label="With Classes (Recommended)" icon="lucide:box"}
  ```csharp
  using (var msg = new UserMessage("CustomMsg"))
  {
      // Write integers
      msg.SetInt32("fieldName", 42);
      msg.SetInt64("bigField", 1000000L);
      msg.SetUInt32("unsignedField", 99u);

      // Read integers (in hook callbacks)
      int value = msg.ReadInt32("fieldName", -1);
      long bigValue = msg.ReadInt64("bigField", -1);
      uint unsigned = msg.ReadUInt32("unsignedField", -1);

      // Or check that the read succeeded
      int checkedValue = 0;
      if (msg.GetInt32("fieldName", ref checkedValue))
      {
          PrintToServer($"fieldName = {checkedValue}\n");
      }
  }
  ```
  ::
  ::div{label="Without Classes" icon="lucide:code"}
  ```csharp
  // Read
  int value = PbReadInt32(msg, "fieldName", -1);
  long bigValue = PbReadInt64(msg, "bigField", -1);
  uint unsigned = PbReadUInt32(msg, "unsignedField", -1);

  // Write
  PbSetInt32(msg, "fieldName", 42);
  PbSetInt64(msg, "bigField", 1000000L);
  PbSetUInt32(msg, "unsignedField", 99u);
  ```

### Colors

Color functions work with `CMsgRGBA` fields; each component is a number from 0 to 255. Some messages store a color as a packed `fixed32` instead (for example `color` in `Fade`): write those with `SetUInt32`.

::tabs
  ::div{label="With Classes (Recommended)" icon="lucide:box"}
  ```csharp
  using System.Numerics;

  using (var msg = new UserMessage("CustomMsg"))
  {
      // Write color (RGBA, 0-255)
      msg.SetColor("color", new Vector4(255, 0, 0, 255)); // Red, full alpha

      // Create color from components
      var color = new Vector4(255, 128, 0, 255);
      msg.SetColor("color", color);

      // Read color (in hook callbacks)
      Vector4 clr = msg.ReadColor("color", -1);

      // Extract components
      float red   = clr.X;
      float green = clr.Y;
      float blue  = clr.Z;
      float alpha = clr.W;
  }
  ```

## Working with Repeated Fields

Some protobuf fields are arrays (repeated fields):

::tabs
  ::div{label="With Classes (Recommended)" icon="lucide:box"}
  ```csharp
  using (var msg = new UserMessage("CustomMsg"))
  {
      // Add values to repeated field
      msg.AddInt32("items", 10);
      msg.AddInt32("items", 20);
      msg.AddInt32("items", 30);
      msg.AddString("names", "Player1");
      msg.AddString("names", "Player2");

      // Get count of repeated field
      int count = msg.GetRepeatedFieldCount("items");
      PrintToServer($"Total items: {count}\n");

      // Read repeated values
      for (int i = 0; i < count; i++)
      {
          int value = msg.ReadInt32("items", i);
          PrintToServer($"Item[{i}] = {value}\n");
      }

      // Set specific index in repeated field
      msg.SetRepeatedInt32("items", 0, 999);  // Set index 0 to 999

      // Remove value from repeated field
      msg.RemoveRepeatedFieldValue("items", 0);  // Remove index 0
  }
  ```
  ::
  ::div{label="Without Classes" icon="lucide:code"}
  ```csharp
  // Get count of repeated field
  int count = UserMessageGetRepeatedFieldCount(msg, "items");

  // Read repeated values
  for (int i = 0; i < count; i++)
  {
      int value = PbReadInt32(msg, "items", i);  // Note: index is 3rd parameter
      PrintToServer($"Item[{i}] = {value}\n");
  }

  // Add values to repeated field
  PbAddInt32(msg, "items", 10);
  PbAddInt32(msg, "items", 20);
  PbAddString(msg, "names", "Player1");

  // Set specific index in repeated field
  PbSetRepeatedInt32(msg, "items", 0, 999);  // Set index 0 to 999

  // Remove value from repeated field
  UserMessageRemoveRepeatedFieldValue(msg, "items", 0);  // Remove index 0
  ```

## Working with Nested Messages

Some messages contain nested message fields. `GetMessage`, `ReadMessage` and `GetRepeatedMessage` (`PbGetMessage`, `PbReadMessage`, `PbGetRepeatedMessage`) return a raw protobuf message pointer, not a user message: it cannot be passed to `Pb*` read or write functions. Pass it to `SetMessage`, `SetRepeatedMessage` or `AddMessage`, which copy it into a field of the same message type. Nested vectors, angles and colors are read and written with the functions above.

::tabs
  ::div{label="With Classes (Recommended)" icon="lucide:box"}
  ```csharp
  using (var source = new UserMessage("CustomMsg"))
  using (var msg = new UserMessage("CustomMsg"))
  {
      // Get nested message (raw protobuf pointer)
      nint nested = 0;
      if (source.GetMessage("nested_field", ref nested))
      {
          // Copy it into the same field of another message
          msg.SetMessage("nested_field", nested);
      }

      // Copy every element of a repeated nested field
      int count = source.GetRepeatedFieldCount("repeated_nested");
      for (int i = 0; i < count; i++)
      {
          nint item = source.ReadMessage("repeated_nested", i);
          if (item != 0)
          {
              msg.AddMessage("repeated_nested", item);
          }
      }
  }
  ```
  ::
  ::div{label="Without Classes" icon="lucide:code"}
  ```csharp
  // Get nested message (raw protobuf pointer)
  nint nested = 0;
  if (PbGetMessage(source, "nested_field", ref nested))
  {
      // Copy it into the same field of another message
      PbSetMessage(msg, "nested_field", nested);
  }

  // Get repeated nested message
  nint item = 0;
  if (PbGetRepeatedMessage(source, "repeated_nested", 0, ref item))
  {
      // Add a copy to a repeated field
      PbAddMessage(msg, "repeated_nested", item);
  }
  ```

## Managing Recipients

Control who receives the message:

::tabs

  ```csharp
  using (var msg = new UserMessage("TextMsg"))
  {
      // Send to all players

      msg.AddRecipient(playerSlot);

      msg.AddRecipient(0);  // Player slot 0
  ```

## Practical Examples

### Example 1: Send Chat Message to All Players

::tabs{variant="card"}
::div{label="With Classes" icon="lucide:box"}
```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public unsafe class ChatMessage : Plugin
{
    public void OnPluginStart()
    {
        AddConsoleCommand("say_all", "Send message to all players",
        ConVarFlag.LinkedConcommand | ConVarFlag.Release | ConVarFlag.ClientCanExecute,
        Command_SayAll, HookMode.Post);
    }

    public ResultType Command_SayAll(int caller, ConCommandContext context, string[] arguments)
    {
        if (arguments.Length < 2)
        {
            PrintToServer("Usage: say_all <message>\n");
            return ResultType.Handled;
        }

        string message = string.Join(" ", arguments, 1, arguments.Length - 1);
        SendChatMessage(message);

        return ResultType.Handled;
    }

    private void SendChatMessage(string text)
    {
        // Using statement ensures automatic cleanup
        using (var msg = new UserMessage("TextMsg"))
        {
            // Add all players as recipients
            msg.AddAllPlayers();

            // Set message fields
            msg.AddString("param", text);
            msg.SetUInt32("dest", 3);  // 3 = chat

            // Send
            msg.Send();

            PrintToServer($"Sent chat message: {text}\n");
        } // Automatically destroyed here
    }
}
```

```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;
```

```csharp
            // Send only to this player
            msg.AddRecipient(playerSlot);

            // Set hint text
            msg.SetString("message", text);

            // Send
            msg.Send();
        } // Automatically destroyed
    }
}
```

```csharp
    {
        if (caller == -1) return ResultType.Handled;

        if (arguments.Length < 2)
        {
            PrintToServer("Usage: hint <message>\n");
            return ResultType.Handled;

        string hintText = string.Join(" ", arguments, 1, arguments.Length - 1);
        SendHintToPlayer(caller, hintText);

        return ResultType.Handled;

    private void SendHintToPlayer(int playerSlot, string text)
    {
        nint msg = UserMessageCreateFromName("HintText");

        // Send only to this player
        UserMessageAddRecipient(msg, playerSlot);

        // Set hint text
        PbSetString(msg, "message", text);

        // Send and cleanup
        UserMessageSend(msg);
        UserMessageDestroy(msg);
    }
```

### Example 4: Hook and Modify Messages

::tabs{variant="card"}
::div{label="With Classes" icon="lucide:box"}
```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public unsafe class MessageFilter : Plugin
{
    public void OnPluginStart()
    {
        short msgId = UserMessage.FindMessageIdByName("TextMsg");
        HookUserMessage(msgId, OnTextMessagePre, HookMode.Pre);
    }

    public void OnPluginEnd()
    {
        short msgId = UserMessage.FindMessageIdByName("TextMsg");
        UnhookUserMessage(msgId, OnTextMessagePre, HookMode.Pre);
    }

    private static ResultType OnTextMessagePre(nint userMessagePtr)
    {
        // Wrap the borrowed pointer (the default ownership is Borrowed)
        var userMessage = new UserMessage(userMessagePtr);

        // Read original message ("param" is a repeated field)
        string originalText = userMessage.ReadString("param", 0);

        // Filter profanity
        string filtered = originalText.Replace("badword", "****");

        if (filtered != originalText)
        {
            PrintToServer("Filtered message content\n");
        }

        // Replace the text with a prefixed, filtered version
        userMessage.SetRepeatedString("param", 0, "[Server] " + filtered);

        // Note: No need to destroy, the wrapper does not own the message
        return ResultType.Continue;
    }
}
```

## Tips and Best Practices

1. **Always destroy messages you create** - Call `UserMessageDestroy()` after sending (sending does not free the message); never destroy a message received in a hook callback
2. **Check message IDs** - `UserMessageFindMessageIdByName()` returns `0` for an unknown name, and hooking ID `0` hooks every message
3. **Pass the right index** - `-1` for a normal field, `0` to `count - 1` for a repeated field
4. **Use correct field names** - Reference protobuf definitions for exact field names
5. **Handle hook modes properly** - Use `Pre` to modify or block messages (return `Handled`), `Post` to observe them
6. **Unhook in OnPluginEnd** - Always clean up hooks when plugin unloads
7. **Validate repeated field counts** - Check count before accessing repeated field indices
8. **Test with clients** - Verify messages display correctly on client side
9. **Use appropriate data types** - Match `PbRead*`/`PbSet*` functions to field types
10. **Consider performance** - Avoid sending large messages or too many messages per tick

## Common User Messages

Here are frequently used user messages in CS:GO/CS2:

**TextMsg** (`CUserMessageTextMsg`) - Send text to chat or console:
- `dest` (uint32) - Destination: 1=notify, 2=console, 3=chat, 4=center
- `param` (repeated string) - Message text, then its arguments

**HintText** - Show hint message on screen:
- `message` (string) - Hint text to display

**Fade** (`CUserMessageFade`) - Screen fade effect:
- `duration` (uint32) - Fade duration, in 1/512 of a second (512 = one second)
- `hold_time` (uint32) - Hold time, in the same units
- `flags` (uint32) - Fade flags (FFADE_IN, FFADE_OUT, etc.)
- `color` (fixed32) - Packed RGBA color

**Damage** (`CCSUsrMsg_Damage`) - Show damage indicator:
- `amount` (int32) - Damage amount
- `inflictor_world_pos` (CMsgVector) - Position of the damage source
- `victim_entindex` (int32) - Victim entity index

**SayText2** (`CUserMessageSayText2`) - Formatted chat message:
- `entityindex` (int32) - Entity index of sender
- `chat` (bool) - Send to chat
- `messagename` (string) - Message format string
- `param1` ... `param4` (string) - Message parameters

Refer to the [CS:GO protobuf definitions](https://github.com/SteamDatabase/Protobufs/tree/master/csgo) for the complete list of messages and their fields.

## Hook Modes

- **Pre** (`HookMode.Pre`) - Hook before message is processed, allows modification
- **Post** (`HookMode.Post`) - Hook after message is processed, read-only observation

Use Pre mode when you want to modify or block messages, Post mode for logging or triggering side effects.
