The **Permissions Plugin** can be installed in two ways: manually downloading the release or using the Plugify package manager. This guide explains both methods and provides step-by-step instructions.

## **Method 1: Manual Installation**

::steps
### **Download the Release**
1. Go to the [Permissions Plugin repository](https://github.com/untrustedmodders/plugify-plugin-permissions).
2. Navigate to the **Releases** section.
3. Download the latest release package (e.g., `plugify-plugin-permissions.zip`).

### **Extract the Package**
1. Extract the downloaded package to a temporary directory.

### **Place the Plugin in the Plugins Folder**
1. Locate the `envs` folder in your Plugify installation directory.
2. Copy the extracted plugin files into the `envs` folder.

### **Verify Installation**
1. Start Plugify.
2. The Permissions Plugin should now be available for use.
::

## **Method 2: Installation via Package Manager**

::steps
### **Open the Server Console**
The `mamba` command is built into the server console, so nothing has to be installed first. Package operations run while Plugify is unloaded: `plg unload` before them and `plg load` after. See [Commands](/builds/management/commands).

### **Install the Plugin**
1. Run the following commands in the server console:
   ```bash
   plg unload
   mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-permissions/" plugify-plugin-permissions
   mamba install -n plugins -c "https://fr0nch.github.io/permissions-storage/" permissions-storage
   mamba install -n plugins -c "https://fr0nch.github.io/permissions-connector-s2/" permissions-connector-s2
   plg load
   ```

   The first package is the core. `permissions-storage` saves groups and players to a database, and `permissions-connector-s2` connects the core to a Counter-Strike 2 server and adds the `perms_*` commands. The connector also needs the `plugify-plugin-s2sdk` and `plugify-plugin-translations` packages.

### **Verify Installation**
1. Start Plugify.
2. The Permissions Plugin should now be installed and ready for use.
::

## **Folder Structure**

After installation, the Permissions Plugin should have the following folder structure:

::file-tree
---
tree:
- addons/plugify/envs:
    - plugins:
        - bin:
            - plugify-plugin-permissions.dll
            - libplugify-plugin-permissions.so
        - ^plugify-plugin-permissions.pplugin^
---
::

### **Explanation**
- **`addons/plugify/envs/plugins`**: The root folder for the Permissions Plugins.
- **`bin`**: Contains the compiled plugin binaries (`.dll` for Windows, `.so` for Linux/macOS).
- **`plugify-plugin-permissions.pplugin`**: The plugin manifest file that describes the plugin and its exported functions.

## **Troubleshooting**

### **Plugin Not Found**
- Ensure the repository URL is correct and accessible.

### **Installation Fails**
- Check your internet connection.
- Ensure you have the latest version of Plugify installed.
