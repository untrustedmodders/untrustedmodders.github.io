The **Permissions** plugin can be installed with the Plugify package manager or by hand from a release.

## **Method 1: Installation via Package Manager**

::steps
### **Open the Server Console**
The `mamba` command is built into the server console, so nothing has to be installed first. Package operations run while Plugify is unloaded: `plg unload` before them and `plg load` after. See [Commands](/builds/management/commands).

### **Install the Plugin**
1. Run the following commands in the server console:
   ```bash
   plg unload
   mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-permissions/" plugify-plugin-permissions
   mamba install -n plugins -c "https://fr0nch.github.io/permissions-storage/" permissions-storage
   mamba install -n plugins -c "https://fr0nch.github.io/permissions-connector-s2/" permissions-connector-s2
   plg load
   ```

   Enter the commands one at a time, not as one pasted block. See [Commands](/builds/management/commands).

   The first package is the core. `permissions-storage` saves groups and players to a database, and `permissions-connector-s2` connects the core to a Counter-Strike 2 server and adds the `perms_*` commands. The connector also needs the `plugify-plugin-s2sdk` and `plugify-plugin-translations` packages.

### **Verify Installation**
1. Run `plg plugins`: the plugin is listed as `permissions`.
::

## **Method 2: Manual Installation**

::steps
### **Download the Release**
1. Go to the [Permissions repository](https://github.com/untrustedmodders/plugify-plugin-permissions).
2. Navigate to the **Releases** section.
3. Download the archive for your platform: `plugify-plugin-permissions-<version>-linux_64.tar.bz2` or `win_64`.

### **Extract the Package**
1. Extract the archive into `addons/plugify/envs/plugins`, without the `info` folder. The manifest `plugify-plugin-permissions.pplugin` must end up in the root of that folder.

### **Verify Installation**
1. Run `plg load` in the server console, or restart the server.
2. Run `plg plugins`: the plugin is listed as `permissions`.
::

## **Folder Structure**

After installation the plugin files are in the `plugins` environment:

::file-tree
---
tree:
- addons/plugify/envs:
    - plugins:
        - bin:
            - libplugify-plugin-permissions.so
            - plugify-plugin-permissions.dll
        - ^plugify-plugin-permissions.pplugin^
---
::

### **Explanation**
- **`addons/plugify/envs/plugins`**: The environment `mamba` installs plugins into. Other plugins live in the same folder.
- **`bin`**: The plugin library: `plugify-plugin-permissions.dll` on Windows, `libplugify-plugin-permissions.so` on Linux.
- **`plugify-plugin-permissions.pplugin`**: The plugin manifest that describes the plugin and its exported functions.

## **Troubleshooting**

### **Plugin Not Found**
- Ensure the repository URL is correct and accessible.

### **Installation Fails**
- Check your internet connection.
- Ensure you have the latest version of Plugify installed.
