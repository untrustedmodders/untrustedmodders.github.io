The **PolyHook** plugin (`polyhook`) intercepts calls to native functions at runtime. A plugin in any language gives it the address of a function and its signature, and gets callbacks before and after every call. The plugin is built on [PolyHook 2](https://github.com/stevemk14ebr/PolyHook_2_0), AsmJit and Zydis, and works on x86-64 Windows and Linux.

## What it does

- **Detour hooks.** `HookDetour` intercepts a function by its address.
- **Virtual function hooks.** `HookVirtualTable` replaces the virtual table of one object, so only that object is affected. `HookVirtualFunc` patches an entry of a virtual table, so every object of the class is affected.
- **Mid-function hooks.** `HookDetour2` intercepts execution at any address and gives the callback the CPU registers instead of arguments.
- **Pre and post callbacks.** A pre callback can read and change the arguments and skip the original function. A post callback can read and change the return value. Several plugins can add callbacks to the same hook, with priorities.
- **Variadic functions.** The index of the first variadic argument is part of the signature.
- **One API for every language.** The functions are exported through the plugin manifest, and the callbacks are ordinary functions of your language.

## When to use it

- You need to react to a call inside the game or another library that has no event for it.
- You want to change the arguments or the result of such a call, or block it.
- You know the address of the function, for example from a signature in [gamedata](/plugins/s2sdk/guides/gamedata).
