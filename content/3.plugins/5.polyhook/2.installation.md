The **PolyHook** plugin can be installed with the Plugify package manager or by hand from a release.

## **Method 1: Installation via Package Manager**

::steps
### **Open the Server Console**
The `mamba` command is built into the server console, so nothing has to be installed first. Package operations run while Plugify is unloaded: `plg unload` before them and `plg load` after. See [Commands](/builds/management/commands).

### **Install the Plugin**
1. Run the following commands in the server console:
   ```bash
   plg unload
   mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-polyhook/" plugify-plugin-polyhook
   plg load
   ```

   Enter the commands one at a time, not as one pasted block. See [Commands](/builds/management/commands).

### **Verify Installation**
1. Run `plg plugins`: the plugin is listed as `polyhook`.
::

## **Method 2: Manual Installation**

::steps
### **Download the Release**
1. Go to the [PolyHook repository](https://github.com/untrustedmodders/plugify-plugin-polyhook).
2. Navigate to the **Releases** section.
3. Download the archive for your platform: `plugify-plugin-polyhook-<version>-linux_64.tar.bz2` or `win_64`.

### **Extract the Package**
1. Extract the archive into `addons/plugify/envs/plugins`, without the `info` folder. The manifest `plugify-plugin-polyhook.pplugin` must end up in the root of that folder.

### **Verify Installation**
1. Run `plg load` in the server console, or restart the server.
2. Run `plg plugins`: the plugin is listed as `polyhook`.
::

## **Folder Structure**

After installation the plugin files are in the `plugins` environment:

::file-tree
---
tree:
- addons/plugify/envs:
    - plugins:
        - bin:
            - libplugify-plugin-polyhook.so
            - plugify-plugin-polyhook.dll
        - ^plugify-plugin-polyhook.pplugin^
---
::

### **Explanation**
- **`addons/plugify/envs/plugins`**: The environment `mamba` installs plugins into. Other plugins live in the same folder.
- **`bin`**: The plugin library: `plugify-plugin-polyhook.dll` on Windows, `libplugify-plugin-polyhook.so` on Linux.
- **`plugify-plugin-polyhook.pplugin`**: The plugin manifest that describes the plugin and its exported functions.

## **Troubleshooting**

### **Plugin Not Found**
- Ensure the repository URL is correct and accessible.

### **Installation Fails**
- Check your internet connection.
- Ensure you have the latest version of Plugify installed.
