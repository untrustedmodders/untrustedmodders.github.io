This guide shows how a plugin hooks native functions with the **PolyHook** plugin. The examples are in C++ and use the generated header `polyhook/polyhook.hpp`, where every function lives in the `polyhook` namespace. The functions are the same in every language, see [Import Functions](/plugins/languages) for how your language calls them.

## Add the dependency

Declare `polyhook` in the manifest of your plugin, so it is loaded before yours:

```json
"dependencies": [
  { "name": "polyhook" }
]
```

## Describe the signature

A hook needs to know the types of the arguments and of the return value. They are described with `DataType`:

```c++
enum class DataType : uint8_t {
  Void, Bool, Int8, UInt8, Int16, UInt16, Int32, UInt32,
  Int64, UInt64, Float, Double, Pointer, String
};
```

For a member function the first argument is `this`, a `Pointer`.

## Hook a function

Every hook function returns a hook handle, or `nullptr` on failure. `GetError` returns the reason.

| Function | What it hooks |
|---|---|
| `HookDetour(pFunc, returnType, arguments, varIndex, name)` | The function at the address `pFunc` |
| `HookVirtualTable(pClass, index, returnType, arguments, varIndex, name)` | The virtual function number `index` of one object `pClass`. The object gets its own copy of the virtual table, other objects of the class are not affected |
| `HookVirtualFunc(pClass, index, returnType, arguments, varIndex, name)` | The entry number `index` in the virtual table `pClass`. Every object that uses this table is affected |
| `HookVirtualTable2`, `HookVirtualFunc2` | The same, with a pointer to the member function `pFunc` instead of the index |
| `HookDetour2(pFunc, name)` | A mid-function hook at any address, see below |

- `varIndex` is the index of the first variadic argument, or `-1` for a normal function.
- `name` is a name for logs and the profiler. It may be empty.
- `GetVirtualIndex(pFunc)` returns the index of a virtual function from a pointer to the member function.

Hooking the same function again returns the hook that already exists, so several plugins can share one hook.

```c++
#include <polyhook/polyhook.hpp>

using namespace polyhook;

void* hook = HookDetour(pAdd, DataType::Int32, { DataType::Int32, DataType::Int32 }, -1, "Add");
if (!hook) {
  // GetError() tells why
}
```

## Add callbacks

```c++
bool AddCallback(HookHandle hook, CallbackType type, CallbackHandler handler);
bool AddCallback2(HookHandle hook, CallbackType type, CallbackHandler handler, int32_t priority);
```

`type` is `CallbackType::Pre` (before the original function) or `CallbackType::Post` (after it). Callbacks with a higher priority run first, `AddCallback` uses priority `0`. `RemoveCallback` removes a callback.

Every callback has the same signature:

```c++
ResultType Handler(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type);
```

The result of the pre callbacks decides what happens to the original function. The highest result of all pre callbacks wins:

```c++
enum class ResultType : int32_t {
  Ignored,   // The callback did nothing
  Handled,   // The callback did something, the original function runs
  Override,  // The callback changed the result, the original function runs
  Supercede  // The original function is skipped, the value set with SetReturn* is returned
};
```

The result of a post callback is not used.

## Arguments and the return value

`GetArgument<Type>(params, index)` and `SetArgument<Type>(params, index, value)` read and change an argument. `GetReturn<Type>(ret)` and `SetReturn<Type>(ret, value)` read and change the return value. `<Type>` is one of `Bool`, `Int8` … `UInt64`, `Float`, `Double`, `Pointer` and `String`. The `String` setters also take the hook handle: `SetArgumentString(hook, params, index, value)` and `SetReturnString(hook, ret, value)`.

## Example

Hook `int Add(int a, int b)`: add one to each argument before the call and double the result after it.

```c++
ResultType PreAdd(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type) {
  int32_t a = GetArgumentInt32(params, 0);
  int32_t b = GetArgumentInt32(params, 1);
  SetArgumentInt32(params, 0, a + 1);
  SetArgumentInt32(params, 1, b + 1);
  return ResultType::Handled;
}

ResultType PostAdd(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type) {
  SetReturnInt32(ret, GetReturnInt32(ret) * 2);
  return ResultType::Ignored;
}

void Setup(void* pAdd) {
  void* hook = HookDetour(pAdd, DataType::Int32, { DataType::Int32, DataType::Int32 }, -1, "Add");
  AddCallback(hook, CallbackType::Pre, PreAdd);
  AddCallback(hook, CallbackType::Post, PostAdd);
}
```

Now `Add(2, 3)` returns `14`. To skip the original function, set the return value in a pre callback and return `ResultType::Supercede`:

```c++
ResultType BlockAdd(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type) {
  SetReturnInt32(ret, 100);
  return ResultType::Supercede;
}
```

## Mid-function hooks

`HookDetour2` stops execution at any address, even in the middle of a function. The callbacks get the CPU registers in `params`, `count` is the number of registers and `ret` is empty. Read and change the registers with `GetRegister<Type>(params, reg)` and `SetRegister<Type>(params, reg, value)`, where `reg` is a `RegisterType` such as `RegisterType::RDI` or `RegisterType::XMM0`.

```c++
ResultType OnMid(HookHandle hook, ParametersHandle registers, int32_t count, ReturnHandle ret, CallbackType type) {
  int32_t first = GetRegisterInt32(registers, RegisterType::RDI); // the first argument on Linux
  return ResultType::Ignored;
}
```

## Remove hooks

| Function | What it removes |
|---|---|
| `UnhookDetour(pFunc)` | A detour or mid-function hook |
| `UnhookVirtualTable(pClass, index)`, `UnhookVirtualFunc(pClass, index)` | A virtual function hook (and the `2` variants that take `pFunc`) |
| `UnhookAllVirtual(pClass)` | All virtual hooks of an object |
| `UnhookAll()` | All hooks |

Hooks are shared between plugins, and removing a hook removes the callbacks of every plugin with it. If other plugins may hook the same function, remove only your own callbacks with `RemoveCallback` when your plugin ends.

## Other functions

- `FindDetour`, `FindVirtual`, `FindVirtual2` return an existing hook or `nullptr`.
- `AreCallbacksRegistered`, `IsCallbackRegistered` tell whether a hook has callbacks.
- `GetFunctionAddr` returns the address of the generated function, `GetOriginalAddr` the address to call the original function.

In C++ the header also has the classes `Callback`, `Parameters`, `Return`, `Registers` and `PolyHook` with the same functions as methods. There the `2` variants are named `HookVirtualTableByFunc`, `HookVirtualFuncByFunc` and `FindVirtualByFunc`.

The full list of functions with their signatures is on the [API Hub](https://api.plugify.net/?file=https://raw.githubusercontent.com/untrustedmodders/plugify-plugin-polyhook/refs/heads/main/plugify-plugin-polyhook.pplugin.in).
