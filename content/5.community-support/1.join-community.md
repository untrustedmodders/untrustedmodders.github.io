Plugify is an open-source project. You can ask questions, share what you build and help improve it in these places.

## Discord

The Discord server is where users and developers talk: questions about servers and plugins, help with problems, news about releases and plugins shared by the community.

:read-more{icon="lucide:link" to="https://discord.gg/rX9TMmpang" title="Join the Plugify Discord server"}

## GitHub

All code is in the [untrustedmodders](https://github.com/untrustedmodders) organization on GitHub. There you can:

- report bugs and request features in the issues of the repository they concern;
- ask questions and discuss ideas in [GitHub Discussions](https://github.com/untrustedmodders/plugify/discussions) of the core;
- send pull requests with fixes, features and documentation.

:read-more{icon="lucide:link" to="https://github.com/untrustedmodders/plugify" title="Plugify on GitHub"}

## Ways to help

- **Report problems** you hit, with the steps to reproduce them.
- **Improve the documentation**: fix mistakes, add examples, help with the Russian translation. Every page has an "Edit this page on GitHub" link at the bottom.
- **Write plugins** and share them with others.
- **Contribute code** to the core, a language module or a plugin, see [How to Contribute](/core/contributing/how-to-contribute).

## Guidelines

- Be respectful to everyone.
- Stay on topic.
- Do not spam.
- Search before asking: the answer may already be in the docs, an issue or a discussion.
