This page is for projects built with Plugify: plugins, game modes, tools and applications that embed the core.

## Share your project

Post your project on the [Discord server](https://discord.gg/rX9TMmpang) or in [GitHub Discussions](https://github.com/untrustedmodders/plugify/discussions). A good post has:

- the name of the project and what it does;
- screenshots or a video, if it has something to show;
- a link to the code or the download page;
- the languages and Plugify plugins it uses.

You can use this outline:

```markdown
### Project name
What the project does, in one or two sentences.

### Features
- ...

### Media
Screenshots, videos or links.

### Link
Repository or download page.
```
