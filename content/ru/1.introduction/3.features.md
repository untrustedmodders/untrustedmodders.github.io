## Много языков, одна система

Плагины можно писать на любом языке, для которого есть языковой модуль:

- **C++**: нативные плагины, вызываются напрямую;
- **C# (.NET)**: плагины на .NET 10;
- **Python**: плагины на Python 3.12;
- **JavaScript**: плагины на движке V8;
- **Lua**: плагины на Lua 5.4;
- **Go**: нативные плагины, собранные через cgo;
- **Rust**: нативные плагины.

Каждый модуль приносит среду выполнения своего языка, поэтому на машине, где работают плагины, ничего ставить не нужно. Новый язык добавляется [языковым модулем](/ru/core/language-modules/writing-language-module), без изменений ядра.

## Вызовы между языками

- **Экспортируемые методы.** Плагин перечисляет в манифесте функции, которые он предоставляет. Любой другой плагин может их вызвать, на каких бы языках ни были написаны оба.
- **Общие типы.** Между языками передаются числа, строки, массивы, векторы, матрицы, значения любого типа и колбэки. Параметр можно передать по ссылке, чтобы вызываемая функция могла его изменить.
- **Колбэки.** Функцию, написанную на одном языке, можно передать плагину на другом языке и вызвать оттуда.
- **Классы, перечисления и прототипы**, описанные в манифесте, дают генераторам биндингов всё нужное, чтобы сделать естественный API для каждого языка.
- **Нативная скорость, где возможно.** Нативные плагины вызывают друг друга по обычным указателям на функции. Остальные языки работают через небольшие функции, сгенерированные во время выполнения.

## Зависимости и порядок загрузки

- **Зависимости с ограничениями версий**, например `>=1.2.0 <2.0.0`, и необязательные зависимости.
- **Конфликты и замены.** Плагин может объявить плагины, с которыми он не может работать, и плагины, которые он заменяет.
- **Разрешение зависимостей** решателем [libsolv](https://github.com/openSUSE/libsolv), тем же, что используют пакетные менеджеры Linux.
- **Порядок загрузки** вычисляется по зависимостям. Все плагины загружаются до запуска первого из них, поэтому к старту плагина всё, от чего он зависит, уже готово.
- **Понятные отчёты о сбоях.** Если что-то не запустилось, ядро объясняет почему, а зависящие плагины пропускаются, а не падают.

## Пакеты

Языковые модули и плагины распространяются conda-пакетами. Хосты игровых серверов включают [micromamba](https://mamba.readthedocs.io/) и консольную команду для установки, обновления и удаления пакетов из каналов.

## Встраивание

- **Библиотека с небольшим API.** Хост создаёт ядро, каждый кадр вызывает `Update` и завершает его работу. См. [Интеграцию](/ru/core/embedding/integrating).
- **Заменяемые части.** Логгер, файловую систему, загрузчик библиотек и решатель зависимостей можно заменить своими реализациями.
- **Платформы.** Windows, Linux и macOS на x86-64 и ARM64; в ядре есть также платформенный код для Android, PlayStation и Nintendo Switch.

## Где используется

- **Серверы Counter-Strike 2**: через готовый [билд](/ru/builds) с хостом S2-Launcher или Metamod и плагином [Source 2 SDK](/ru/plugins/s2sdk/features).
- **Ваше приложение**: движок, инструмент или сервер, которому нужны плагины на нескольких языках.
