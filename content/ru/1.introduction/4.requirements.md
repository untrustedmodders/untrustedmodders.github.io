Что вам понадобится, зависит от того, что вы делаете с Plugify. Для каждого случая свой короткий список.

## Запуск сервера

- Выделенный сервер Counter-Strike 2 на **Linux** или **Windows**, 64 бита.
- Для загрузчика Metamod нужен установленный на сервере Metamod:Source 2.x.

Больше ничего вручную ставить не нужно: билд приносит загрузчик, менеджер пакетов, языковые модули и базовые плагины.

## Написание плагинов

Языковой модуль несёт в себе рантайм своего языка, поэтому на сервер для него ничего ставить не нужно. На своей машине нужны обычные инструменты языка, чтобы написать и собрать плагин.

| Язык | На вашей машине | Рантайм на сервере |
|---|---|---|
| **C++** | Компилятор с поддержкой C++23 и CMake | Не нужен, плагины являются нативными библиотеками |
| **C# (.NET)** | .NET SDK 10.0 | .NET 10, идёт вместе с модулем |
| **Python** | Любой редактор | Python 3.12, идёт вместе с модулем |
| **JavaScript** | Любой редактор | V8, идёт вместе с модулем |
| **Lua** | Любой редактор | Lua 5.4, идёт вместе с модулем |
| **Go** | Компилятор Go с cgo и компилятор C | Не нужен, плагины являются нативными библиотеками |
| **Rust** | Rust 1.85 или новее (edition 2024) | Не нужен, плагины являются нативными библиотеками |

## Сборка ядра

Это нужно, только чтобы встроить Plugify в своё приложение или работать над самим ядром.

- **Платформы**: Windows, Linux и macOS.
- **Компилятор**: с поддержкой C++23. Используются Clang, GCC, MSVC (Visual Studio 2022) и Apple Clang.
- **CMake** 3.14 или новее, **Git** и по желанию **Ninja**.
- Библиотеки, от которых зависит ядро ([asmjit](https://github.com/asmjit/asmjit), [glaze](https://github.com/stephenberry/glaze), [libsolv](https://github.com/openSUSE/libsolv), [valijson](https://github.com/tristanpenman/valijson)), CMake скачивает сам во время сборки.
