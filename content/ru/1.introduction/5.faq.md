  #title
  Что такое Plugify?

  #content
  Plugify — менеджер плагинов, написанный на C++. Приложение встраивает его как библиотеку и получает плагины, которые можно писать на разных языках и которые напрямую вызывают друг друга. Сейчас он чаще всего используется на серверах Counter-Strike 2, но встроить его может любое приложение. См. [Обзор](/ru/introduction/overview).
  ::

  ::accordion-item
  #title
  С чего начать?

  #content
  Зависит от того, что вы хотите сделать:

  - **Запустить сервер с плагинами**: установите готовый [билд](/ru/builds).
  - **Писать плагины**: выберите язык в разделе [Плагины](/ru/plugins).
  - **Встроить Plugify или добавить язык**: начните с раздела [Ядро](/ru/core). Чтобы попробовать плагины без игры, соберите тестовое приложение `plug`, см. [Установку](/ru/core/embedding/installation).
  ::

  ::accordion-item
  #title
  Сколько языков поддерживается?

  #content
  Языковые модули есть для семи языков: **C++**, **C# (.NET)**, **Python**, **JavaScript** (V8), **Lua**, **Go** и **Rust**. См. [Языки](/ru/plugins/languages).

  Поддержка другого языка добавляется новым [языковым модулем](/ru/core/language-modules/writing-language-module); ядро при этом не меняется.
  ::

  ::accordion-item
  #title
  Где найти плагины?

  #content
  Базовые плагины (Source 2 SDK, configs, permissions и другие) описаны в разделе [Плагины](/ru/plugins) и лежат в репозиториях `plugify-plugin-*` организации [untrustedmodders](https://github.com/untrustedmodders). Плагинами сообщества делятся на [Discord-сервере](https://discord.gg/rX9TMmpang).
  ::

  ::accordion-item
  #title
  Как плагины на разных языках общаются друг с другом?

  #content
  Плагин перечисляет в манифесте методы, которые он экспортирует. Каждый метод становится нативной функцией с соглашением о вызовах C данной платформы, а каждый языковой модуль делает методы всех плагинов доступными на своём языке. Строки, массивы, векторы и другие сложные значения передаются в общих типах `plg::` из ядра, а колбэки можно передавать в обе стороны. См. [Архитектуру](/ru/core/architecture).
  ::

  ::accordion-item
  #title
  Какие платформы поддерживает Plugify?

  #content
  Ядро собирается и работает на **Windows**, **Linux** и **macOS**, на **x86-64** и **ARM64**. В нём есть также платформенный код для Android, PlayStation и Nintendo Switch. Билд для Counter-Strike 2 выпускается для 64-битных Windows и Linux.
  ::

  ::accordion-item
  #title
  Как создать новый языковой модуль?

  #content
  1. Возьмите за основу репозиторий [plugify-module-template](https://github.com/untrustedmodders/plugify-module-template).
  2. Реализуйте интерфейс `ILanguageModule` и экспортируйте функцию `GetLanguageModule()`.
  3. Укажите свой язык в манифесте `.pmodule`.
  4. Положите модуль в папку `extensions` приложения `plug` вместе с плагином на своём языке и проверьте, что оба доходят до `Running`.

  См. [Создание языкового модуля](/ru/core/language-modules/writing-language-module).
  ::

  ::accordion-item
  #title
  Как устанавливать и обновлять плагины и модули?

  #content
  Модули и плагины — это conda-пакеты. В самом ядре пакетного менеджера нет: оно загружает то, что находит в своей папке расширений. Хосты Counter-Strike 2 включают **micromamba** и консольную команду `mamba`, которая устанавливает, обновляет и удаляет пакеты из каналов. См. [Команды](/ru/builds/management/commands).
  ::

  ::accordion-item
  #title
  Что такое файлы манифестов?

  #content
  Манифесты — JSON-файлы (комментарии разрешены), описывающие расширение. Ключи, которых нет в схеме, делают манифест невалидным.

  1. **`*.pplugin`** описывает плагин: его язык, точку входа, зависимости и экспортируемые методы. В `name` допустимы буквы, цифры и `_`.
     ```json [my_plugin.pplugin]
     {
       "$schema": "https://raw.githubusercontent.com/untrustedmodders/plugify/refs/heads/main/schemas/plugin.schema.json",
       "name": "my_plugin",
       "version": "1.0.0",
       "description": "An example plugin",
       "author": "Your Name",
       "website": "https://example.com",
       "license": "MIT",
       "language": "cpp",
       "entry": "bin/my_plugin",
       "dependencies": []
     }
     ```

  2. **`*.pmodule`** описывает языковой модуль: язык, который он обслуживает.
     ```json [cpp_module.pmodule]
     {
       "$schema": "https://raw.githubusercontent.com/untrustedmodders/plugify/refs/heads/main/schemas/module.schema.json",
       "name": "cpp_module",
       "version": "1.0.0",
       "description": "Adds support for C++ plugins",
       "author": "Your Name",
       "website": "https://example.com",
       "license": "MIT",
       "language": "cpp"
     }
     ```

  3. **`*.pconfig`** хранит настройки ядра: папки, загрузку, безопасность и логирование. Он необязателен и читается, только когда хост передаёт его ядру. Хосты Counter-Strike 2 задают папки сами и его не используют.
     ```json [plugify.pconfig]
     {
       "$schema": "https://raw.githubusercontent.com/untrustedmodders/plugify/refs/heads/main/schemas/config.schema.json",
       "paths": {
         "baseDir": ".",
         "extensionsDir": "extensions"
       },
       "logging": {
         "severity": "debug",
         "printReport": true
       }
     }
     ```

  Все поля описаны в [Архитектуре](/ru/core/architecture).
  ::

  ::accordion-item
  #title
  Как раскладывать файлы?

  #content
  Ядро ищет манифесты в своей папке расширений и её подпапках. В папку, где есть манифест, ядро глубже не заходит, а в одной папке может лежать несколько манифестов. Языковой модуль держит свою библиотеку в `bin/` рядом с манифестом:

     ::file-tree
     ---
     tree:
     - ^extensions^:
        - cpp_module:
           - bin:
              - cpp_module.dll
              - libcpp_module.so
           - cpp_module.pmodule
        - my_plugin:
           - bin:
              - my_plugin.dll
              - libmy_plugin.so
           - my_plugin.pplugin
        - my_script:
           - my_script.py
           - my_script.pplugin
     ---
     ::

  На сервере Counter-Strike 2 папка расширений — `csgo/addons/plugify/envs`, см. [Структуру каталогов](/ru/builds/management/directory-structure).
  ::

  #title
  Как отлаживать плагины и языковые модули?

  #content
  1. Прочитайте отчёт, который ядро пишет в лог после загрузки: в нём сказано, почему не запустилось каждое расширение.
  2. Поднимите уровень логирования: `logging.severity` со значением `debug` в `.pconfig` для своего хоста или `plug`, либо `--verbosity=<уровень>` в командной строке S2-Launcher.
  3. Соберите отлаживаемую часть с символами и запустите приложение под отладчиком.

  См. [Отладку](/ru/core/contributing/debugging).
  ::

  #title
  Можно ли использовать Plugify в коммерческих проектах?

  #content
  Да. Plugify распространяется по **лицензии MIT**, которая разрешает использование, изменение и распространение в открытых и коммерческих проектах. См. файл [LICENSE](https://github.com/untrustedmodders/plugify/blob/main/LICENSE).
  ::

  ::accordion-item
  #title
  Как внести вклад в Plugify?

  #content
  Сделайте форк нужного репозитория, внесите изменения в отдельной ветке с сообщениями коммитов по [Conventional Commits](https://www.conventionalcommits.org) и откройте pull request. См. [Как внести вклад](/ru/core/contributing/how-to-contribute) и [правила участия](https://github.com/untrustedmodders/plugify/blob/main/docs/CONTRIBUTING.md) ядра.

  #title
  Что нужно для сборки ядра?

  #content
  - Компилятор с поддержкой C++23: GCC, Clang, MSVC (Visual Studio 2022) или Apple Clang. Минимально поддерживаемый стандарт — C++20.
  - CMake 3.14 или новее.
  - 64-битная платформа: x86-64 или ARM64.

  Нужные ядру библиотеки скачивает CMake. См. [Требования](/ru/introduction/requirements) и [Инструкции по сборке](/ru/core/embedding/building).
  ::

  ::accordion-item
  #title
  Как удалить Plugify?

  #content
  - **С игрового сервера**: удалите хост (S2-Launcher или плагин Metamod), как описано на его странице установки, и удалите папку `csgo/addons/plugify` с установленными модулями и плагинами.
  - **Из своего приложения**: уберите библиотеку ядра из проекта и удалите папку с расширениями, если она больше не нужна.
  ::
