**Сборкой** называется готовый к запуску набор Plugify для игры: загрузчик, который загружает Plugify в игру, языковые модули и базовые плагины, проверенные вместе и выпущенные одним архивом. Архив распаковывается в папку игры, и сервер можно запускать, больше ничего ставить не нужно.

## Билд или пакеты по одному?

На диске результат одинаковый: билд кладёт пакеты в привычные окружения `envs/modules` и `envs/plugins`, и `mamba` работает с ними так же, как с пакетами, установленными вручную. Набор билда отмечен мета-пакетом, поэтому `mamba list` показывает, какая версия билда установлена.

| | Билд | Пакеты по одному |
|---|---|---|
| Что скачивать | Один архив | Загрузчик, затем каждый модуль и плагин через `mamba install` |
| Версии | Набор, проверенный вместе, одна версия на весь билд | Последняя версия каждого пакета |
| Обновление | `mamba update` переводит весь набор на следующий билд; ваши пакеты и конфиги сохраняются | `mamba update` каждого пакета до его последней версии |
| Подходит для | Настройки сервера, воспроизведения окружения, поддержки | Выбора отдельных пакетов, ранней проверки новых версий |

Способы можно совмещать: установить билд и добавить любой другой пакет через `mamba install`.

## Версии и каналы

- **stable**: релизы со своей версией (`1.0.0`) и тегом `plugify-source2-v1.0.0`. В каждом релизе указана точная версия каждого компонента.
- **dev**: пересобирается при каждом изменении билда, версии вида `1.0.1-dev.12`. Для проверки новых версий компонентов до того, как они попадут в stable.
