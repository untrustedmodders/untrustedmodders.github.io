Plugify Source 2 представляет собой готовый к запуску билд Plugify для **Counter-Strike 2**: загрузчик, языковые модули и стандартные плагины для Source 2 SDK в одном архиве.

::build-download{build="plugify-source2"}
::

## Быстрая установка

::steps
### Скачайте архив
В блоке выше выберите ОС и загрузчик, затем нажмите **Скачать**. Не знаете, какой загрузчик взять? Берите **Launcher** или прочитайте [Выбор загрузчика](/ru/builds/hosts).

### Распакуйте его в `game/`
В архиве лежат папки `bin/` и `csgo/`. Распакуйте архив в папку `game/` вашего сервера, чтобы они слились с одноимёнными папками. На вопрос о замене файлов ответьте согласием.

```bash
tar -xzf plugify-source2-launcher-linux-1.1.0.tar.gz -C /path/to/server/game
```

### Запустите сервер
Способ запуска зависит от выбранного загрузчика:

- **Launcher**: запускайте `s2launcher` вместо `cs2`, с теми же аргументами.
- **Runtime**: запускайте `cs2` как обычно.
- **Metamod**: сначала установите Metamod:Source, затем запускайте `cs2` как обычно.

### Проверьте, что всё работает
Введите `plg plugins` в консоли сервера. Стандартные плагины должны быть в состоянии `Running`.
::
