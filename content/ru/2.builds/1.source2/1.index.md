Plugify Source 2 представляет собой готовый к запуску билд Plugify для **Counter-Strike 2**: загрузчик, языковые модули и базовые плагины для Source 2 SDK в одном архиве.

::build-download{build="plugify-source2"}
::

## Установка в 3 шага

::steps
### Распакуйте в `game/`
Распакуйте архив в папку `game/` сервера с заменой файлов.

### Запустите сервер через загрузчик
Launcher: `s2launcher` вместо `cs2`. Runtime: запуск `cs2` как обычно. Metamod: запуск сервера с установленным Metamod.

### Проверьте
Выполните `plg plugins` в консоли сервера. Базовые плагины должны быть в состоянии `Running`.
::
