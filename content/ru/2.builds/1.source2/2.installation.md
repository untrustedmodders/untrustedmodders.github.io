## Требования

- Выделенный сервер Counter-Strike 2 на Linux или Windows (64-бит).
- Для загрузчика **Metamod** нужен установленный на сервере [Metamod:Source](https://www.sourcemm.net/downloads.php/?branch=master) 2.x. В билд он не входит.

:span{id="hosts"}

## Выбор загрузчика

Загрузчиком называется часть, которая загружает Plugify в игру. Остальное содержимое билда одинаково для всех загрузчиков.

| Загрузчик | Как запускается | Платформы |
|---|---|---|
| **Launcher** (S2-Launcher) | `s2launcher` вместо `cs2`, с теми же аргументами | Linux, Windows |
| **Runtime** (S2-Launcher как библиотека) | Игра сама загружает Plugify, поэтому `cs2` запускается как обычно. Подходит для хостинг-панелей, где команду запуска не изменить | Linux |
| **Metamod** (MM-Loader) | Plugify работает как плагин Metamod:Source | Linux, Windows |

:read-more{icon="lucide:square-m" to="/ru/builds/hosts/metamod-plugin/overview" title="MM-Loader"}

## Языки

В билд входят языковые модули тех языков, на которых написаны его плагины. Базовые плагины написаны на C++ и Go, поэтому в билде есть эти два модуля. Актуальный список приведён в составе на [странице загрузки](/ru/builds/source2). Модули других языков ставятся одной командой, см. [Добавление пакетов](/ru/builds/source2/contents#добавление-пакетов).

## Установка

::steps
### Скачайте
Выберите ОС и загрузчик на [странице загрузки](/ru/builds/source2) и скачайте архив.

### Распакуйте
В архиве лежит папка `game/` сервера. Распакуйте его в корневую папку сервера (ту, в которой лежит `game/`) с заменой файлов.

На Linux:
```bash
tar -xzf plugify-source2-launcher-linux-1.0.0.tar.gz -C /path/to/server
```

На Windows распакуйте `.zip` Проводником или любым архиватором.

Полный архив предназначен для новой установки. Установленный билд обновляйте по инструкции [Обновление](/ru/builds/source2/updating), а не распаковкой нового архива поверх.

### Запустите сервер

::tabs{variant="card"}
  ::div{label="Launcher"}
  Запускайте `s2launcher` вместо `cs2`, с теми же аргументами:

  ```bash
  # Linux
  ./game/bin/linuxsteamrt64/s2launcher -dedicated +map de_dust2

  # Windows
  game\bin\win64\s2launcher.exe -dedicated +map de_dust2
  ```
  ::
  ::div{label="Runtime"}
  Запускайте сервер как обычно, игра сама загрузит Plugify:

  ```bash
  ./game/bin/linuxsteamrt64/cs2 -dedicated +map de_dust2
  ```
  ::
  ::div{label="Metamod"}
  Убедитесь, что Metamod:Source установлен, и запускайте сервер как обычно. Metamod загружает Plugify через `csgo/addons/metamod/plugify.vdf`.
  ::
::

### Проверьте
В консоли сервера:

```bash
plg plugins
plg modules
```

Базовые плагины и языковые модули должны быть в состоянии `Running`.
::

## Что где лежит

Всё, что относится к Plugify, находится в `game/csgo/addons/plugify/`:

- `envs/modules` и `envs/plugins`: языковые модули и плагины билда;
- `configs/`: ваши настройки. Плагины хранят значения по умолчанию в своём пакете, а ваши изменения читают отсюда;
- `data/`, `logs/`: данные плагинов и логи;
- `.condarc`: каналы, из которых `mamba` ставит и обновляет пакеты;
- `build.json`: с каким билдом пришёл загрузчик, версии загрузчика и ядра.

Полная раскладка и список компонентов приведены на странице [Состав](/ru/builds/source2/contents).
