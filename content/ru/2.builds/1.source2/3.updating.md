Билд обновляется в две части:

- **Пакеты** (языковые модули и плагины) обновляются через `mamba` из консоли сервера. Архив для этого не нужен.
- **Загрузчик** обновляется только распаковкой архива вручную, и только если новый билд его изменил. Такие релизы отмечены в [списке изменений](/ru/builds/source2/changelog).

Ваши настройки в `configs/`, `data/` и `logs/`, пакеты, которые вы поставили сами, и ваши остальные окружения в `envs/` сохраняются.

## Обновление пакетов

В консоли сервера, по одной команде:

```bash
plg unload
mamba update -n modules --all
mamba update -n plugins --all
plg load
```

Набор билда оформлен мета-пакетом: `plugify-source2-modules` в `envs/modules` и `plugify-source2-plugins` в `envs/plugins`. Его версия совпадает с версией билда, а зависимости указывают точные версии пакетов билда. Поэтому `mamba update` переводит стандартные пакеты на версии следующей билда, ставит пакеты, которые в ней появились, и удаляет те, что из неё убрали. Пакеты, которые вы поставили сами, обновляются из своих каналов.

Чтобы посмотреть, какой билд установлен:

```bash
mamba list -n plugins
```

Строка `plugify-source2-plugins` показывает версию билда. Все остальные пакеты, от которых этот мета-пакет не зависит, добавлены вами.

## Обновление загрузчика

Нужно, только если в [списке изменений](/ru/builds/source2/changelog) сказано, что изменился загрузчик. Сначала обновите пакеты, затем:

::steps
### Остановите сервер

### Сохраните `sentry.jsonc`
Для загрузчиков Launcher и Runtime скопируйте `game/bin/<platform>/sentry.jsonc`, если вы его меняли. Архив его заменит.

### Распакуйте архив загрузчика
Скачайте `plugify-source2-<загрузчик>-<ос>-<версия>-host-only` для своих загрузчика и ОС на [странице загрузки](/ru/builds/source2) и распакуйте его в папку `game/` сервера с заменой файлов. В нём нет `envs/`, поэтому ваши пакеты не затрагиваются. Файл `addons/plugify/.condarc` он заменяет, так что сохраните и его, если добавляли в него каналы.

### Запустите сервер
Верните сохранённые файлы и запустите сервер.
::

::alert{icon="lucide:info"}
Не распаковывайте полный архив поверх установленного билда: в записях пакетов в `conda-meta/` старые версии останутся рядом с новыми. Полный архив предназначен для новой установки или для установки после удаления `envs/modules` и `envs/plugins`.
::

## Другие операции

Установить конкретную версию билда, например чтобы откатиться:

```bash
plg unload
mamba install -n plugins plugify-source2-plugins=1.0.0
mamba install -n modules plugify-source2-modules=1.0.0
plg load
```

Поставить пакет новее, чем в билде: сначала отвяжите окружение от билда. Пакеты останутся установленными, а дальше их версиями управляете вы. Канал билда стоит в `.condarc` первым и содержит только версии билда, поэтому более новую версию берите из канала самого пакета через `-c`:

```bash
plg unload
mamba remove -n plugins --no-prune-deps plugify-source2-plugins
mamba update -n plugins -c "https://fr0nch.github.io/permissions-storage/" permissions-storage
plg load
```

Чтобы удалить один из плагинов билда, тоже передайте `--no-prune-deps`. Без него `mamba` удалит мета-пакет вместе со всеми пакетами, от которых он зависит, то есть весь набор билда:

```bash
plg unload
mamba remove -n plugins --no-prune-deps plugify-plugin-dyncall
plg load
```

Вместе с плагином удаляется мета-пакет, и окружение перестаёт следовать за билдами. Повторная установка `plugify-source2-plugins` возвращает оба.
