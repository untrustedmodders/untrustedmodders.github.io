**Загрузчик** это часть, которая загружает Plugify в игру. Он запускает менеджер плагинов, даёт консоли сервера команды `plg` и `mamba` и обновляет Plugify каждый кадр сервера. Всё остальное, то есть языковые модули, плагины и настройки, одинаково для любого загрузчика.

Для Counter-Strike 2 есть три загрузчика. Два из них это сборки одного проекта, S2-Launcher.

| | Launcher | Runtime | Metamod |
|---|---|---|---|
| Проект | S2-Launcher | S2-Launcher | MM-Loader |
| Как запускается сервер | `s2launcher` вместо `cs2`, с теми же аргументами | `cs2` как обычно | `cs2` как обычно |
| Что загружает Plugify | Лаунчер сам запускает игру | Игра загружает библиотеку `libserver_valve.so`, она запускает Plugify и передаёт управление игре | Metamod:Source загружает Plugify как свой плагин |
| Нужен Metamod:Source | Нет | Нет | Да |
| Платформы | Linux, Windows | Linux | Linux, Windows |
| Отчёты о падениях и профайлер | Да | Да | Нет |

## Какой выбрать

- **Launcher**: выбор по умолчанию для сервера, где вы управляете командой запуска. В игру добавляется только Plugify.
- **Runtime**: подходит, когда команду запуска менять нельзя, например на хостинг-панели, которая всегда запускает `cs2`. Сервер стартует как обычно, а Plugify загружается сам.
- **Metamod**: подходит, когда на сервере уже работают плагины Metamod:Source и Plugify нужен рядом с ними.

Плагины от загрузчика не зависят: плагин, который работает с одним загрузчиком, работает и с остальными.
