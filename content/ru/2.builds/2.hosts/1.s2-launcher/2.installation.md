**Рекомендуем ставить билд Plugify Source 2.** В нём загрузчик, языковые модули и стандартные плагины собраны в один архив. Эта страница описывает установку только загрузчика.
::

## Скачивание

Скачайте архив со страницы [релизов S2-Launcher](https://github.com/untrustedmodders/plugify-source2-launcher/releases):

| Архив | Вид | Платформа |
|---|---|---|
| `plugify-source2-launcher-build-linuxsteamrt64-<commit>.tar.bz2` | Launcher | Linux |
| `plugify-source2-launcher-build-win64-<commit>.tar.bz2` | Launcher | Windows |
| `plugify-source2-runtime-build-linuxsteamrt64-<commit>.tar.bz2` | Runtime | Linux |

## Установка

::steps
### Распакуйте в `game/`
В архиве лежат папки `bin/` и `csgo/`. Распакуйте его в папку `game/` сервера или игры, чтобы они слились с одноимёнными папками:

```bash
tar -xjf plugify-source2-launcher-build-linuxsteamrt64-<commit>.tar.bz2 -C /path/to/server/game
```

На Windows распакуйте его любым архиватором, который открывает `.tar.bz2`, например 7-Zip.

Launcher на Linux добавляет такие файлы:

::file-tree
---
tree:
- game:
    - bin:
        - linuxsteamrt64:
            - cs2
            - ^s2launcher^
            - ^libplugify.so^
            - ^libsentry.so^
            - ^crashpad_handler^
            - ^sentry.jsonc^
    - csgo:
        - addons:
            - plugify:
                - bin:
                    - linuxsteamrt64:
                        - ^micromamba^
---
::

На Windows файлы лежат в `bin/win64/` (`s2launcher.exe`, `plugify.dll`, `sentry.dll`, `crashpad_handler.exe`, `sentry.jsonc`) и `csgo/addons/plugify/bin/win64/micromamba.exe`. В архиве Runtime вместо `s2launcher` лежит `csgo/bin/linuxsteamrt64/libserver_valve.so`.

### Запустите игру
**Launcher**: запускайте `s2launcher` вместо `cs2`, с теми же аргументами:

```bash
# Linux
./game/bin/linuxsteamrt64/s2launcher -dedicated +map de_dust2

# Windows
game\bin\win64\s2launcher.exe -dedicated +map de_dust2
```

**Runtime**: запускайте `cs2` как обычно, игра загрузит Plugify сама.

Чтобы запустить клиент игры, а не выделенный сервер, добавьте `-insecure`. Без `-dedicated` или `-insecure` лаунчер не запускается.

При первом запуске Plugify создаёт в `csgo/addons/plugify/` папки `envs/`, `configs/`, `data/`, `logs/` и `pkgs/`.

### Проверьте
В консоли:

```bash
plg --version
```

Команда выводит версию Plugify.
::

## Языковые модули и плагины

Загрузчик приходит без языковых модулей и плагинов. Поставьте их через `mamba` в окружения `modules` и `plugins`. Без билда нет `.condarc` со списком каналов, поэтому канал каждого пакета передавайте через `-c`.

Стандартные плагины Source 2 и нужный им модуль C++:

```bash
plg unload
mamba create -n modules
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-cpp/" plugify-module-cpp
mamba create -n plugins
mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-configs/" plugify-plugin-configs
mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-polyhook/" plugify-plugin-polyhook
mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-s2sdk/" plugify-plugin-s2sdk
plg load
```

- **plugify-module-cpp**: запускает плагины на C++;
- **plugify-plugin-configs**: конфигурационные файлы для плагинов;
- **plugify-plugin-polyhook**: перехват функций;
- **plugify-plugin-s2sdk**: Source 2 SDK, функции игры для плагинов.

Модули других языков, только нужные вам:

```bash
plg unload
# C#
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-dotnet/" plugify-module-dotnet
# Python
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-python3/" plugify-module-python3
# JavaScript
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-v8/" plugify-module-v8
# Go
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-golang/" plugify-module-golang
# Lua
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-lua/" plugify-module-lua
# Rust
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-rust/" plugify-module-rust
plg load
```

Проверьте, что загружено:

```bash
plg modules
plg plugins
```

## Решение проблем

- **Игра не запускается.** Проверьте, что `s2launcher` лежит в одной папке с `cs2`, что его можно запускать и что среди аргументов есть `-dedicated` (сервер) или `-insecure` (клиент).
- **Команда `plg` неизвестна.** Plugify не загрузился. Посмотрите вывод консоли при запуске и проверьте, что файлы лежат так, как показано в дереве выше.
- **`mamba` отказывается работать.** Операции с пакетами работают, только пока Plugify выгружен: сначала выполните `plg unload`.
