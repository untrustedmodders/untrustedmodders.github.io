**Рекомендуем ставить билд Plugify Source 2.** В нём загрузчик, языковые модули и стандартные плагины собраны в один архив. Эта страница описывает установку только загрузчика.
::

## Требования

На сервере установлен [Metamod:Source](https://www.sourcemm.net/downloads.php/?branch=master) 2.x.

:read-more{icon="lucide:link" to="/ru/builds/hosts/metamod-plugin/metamod"}

## Установка

::steps
### Скачайте
Скачайте архив для своей платформы со страницы [релизов MM-Loader](https://github.com/untrustedmodders/plugify-metamod-loader/releases): `plugify-metamod-loader-build-linuxsteamrt64-<commit>.tar.bz2` или `plugify-metamod-loader-build-win64-<commit>.tar.bz2`.

### Распакуйте в `game/`
В архиве лежит папка `csgo/`. Распакуйте его в папку `game/` сервера, чтобы она слилась с `game/csgo/`:

```bash
tar -xjf plugify-metamod-loader-build-linuxsteamrt64-<commit>.tar.bz2 -C /path/to/server/game
```

На Windows распакуйте его любым архиватором, который открывает `.tar.bz2`, например 7-Zip. Результат:

::file-tree
---
tree:
- game:
    - csgo:
        - addons:
            - metamod:
                - ^plugify.vdf^
            - plugify:
                - bin:
                    - linuxsteamrt64:
                        - ^libplugify.so^
                        - ^micromamba^
                    - win64:
                        - ^plugify.dll^
                        - ^micromamba.exe^
---
::

При первом запуске Plugify создаёт рядом с `bin/` папки `envs/`, `configs/`, `data/`, `logs/` и `pkgs/`.

### Запустите сервер
Запустите или перезапустите сервер как обычно.

### Проверьте
В консоли сервера или через `rcon`:

```bash
meta list
```

Plugify есть в списке плагинов Metamod:

```
Listing 1 plugin:
  [01] plugify-metamod-loader (2.1.5) by untrustedmodders
```

Можно также проверить версию Plugify:

```bash
plg --version
```
::

## Языковые модули и плагины

Загрузчик приходит без языковых модулей и плагинов. Поставьте их через `mamba` в окружения `modules` и `plugins`. Без билда нет `.condarc` со списком каналов, поэтому канал каждого пакета передавайте через `-c`.

Стандартные плагины Source 2 и нужный им модуль C++:

```bash
plg unload
mamba create -n modules
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-cpp/" plugify-module-cpp
mamba create -n plugins
mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-configs/" plugify-plugin-configs
mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-polyhook/" plugify-plugin-polyhook
mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-s2sdk/" plugify-plugin-s2sdk
plg load
```

- **plugify-module-cpp**: запускает плагины на C++;
- **plugify-plugin-configs**: конфигурационные файлы для плагинов;
- **plugify-plugin-polyhook**: перехват функций;
- **plugify-plugin-s2sdk**: Source 2 SDK, функции игры для плагинов.

Модули других языков, только нужные вам:

```bash
plg unload
# C#
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-dotnet/" plugify-module-dotnet
# Python
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-python3/" plugify-module-python3
# JavaScript
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-v8/" plugify-module-v8
# Go
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-golang/" plugify-module-golang
# Lua
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-lua/" plugify-module-lua
# Rust
mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-rust/" plugify-module-rust
plg load
```

Проверьте, что загружено:

```bash
plg modules
plg plugins
```

## Решение проблем

- **Plugify нет в `meta list`.** Проверьте, что работает сам Metamod и что на месте `csgo/addons/metamod/plugify.vdf` и библиотека в `csgo/addons/plugify/bin/<platform>/`. Без `micromamba` рядом с библиотекой плагин не загружается.
- **Сервер падает при запуске.** Посмотрите в логе сервера ошибки Plugify или Metamod и проверьте, что ваша сборка Metamod подходит к текущей версии игры.
- **Команда `plg` неизвестна.** Plugify не загрузился: проверьте `meta list`.
