::alert{type="info" icon="lucide:package-open" to="/ru/builds/source2/updating"}
**Установили билд Plugify Source 2?** Его пакеты обновляются через `mamba update`, а загрузчик только распаковкой архива вручную. Эта страница описывает загрузчик, установленный отдельно.
::

Загрузчик и пакеты обновляются отдельно: загрузчик из нового архива, языковые модули и плагины через `mamba`.

## Обновление загрузчика

::steps
### Остановите сервер

### Распакуйте новый архив
Скачайте новый архив со страницы [релизов MM-Loader](https://github.com/untrustedmodders/plugify-metamod-loader/releases) и распакуйте его в `game/` с заменой файлов, как при [установке](/ru/builds/hosts/metamod-plugin/installation). Ваши пакеты, настройки и данные в `csgo/addons/plugify/` сохраняются.

### Запустите сервер
Запустите сервер и проверьте версию в `meta list` или командой `plg --version`.
::

## Обновление пакетов

В консоли сервера:

```bash
plg unload
mamba update -n modules --all
mamba update -n plugins --all
plg load
```

`-n` выбирает окружение для обновления. `mamba` ищет новые версии только в известных ему каналах. У загрузчика, установленного отдельно, списка каналов нет, поэтому создайте `csgo/addons/plugify/.condarc` с каналами своих пакетов:

```yaml [.condarc]
channels:
  - https://untrustedmodders.github.io/plugify-module-cpp/
  - https://untrustedmodders.github.io/plugify-plugin-configs/
  - https://untrustedmodders.github.io/plugify-plugin-polyhook/
  - https://untrustedmodders.github.io/plugify-plugin-s2sdk/
```

Без него передавайте каналы через `-c` в команде обновления, иначе `mamba` не найдёт, что обновлять.

## Решение проблем

- **`mamba` отказывается работать.** Сначала выполните `plg unload`: операции с пакетами работают, только пока Plugify выгружен.
- **Пакет не обновляется.** Проверьте, что канал пакета доступен, и посмотрите установленную версию через `mamba list -n plugins`.
- **Сервер падает после обновления.** Посмотрите в логе сервера ошибки Plugify, его языковых модулей и плагинов.
