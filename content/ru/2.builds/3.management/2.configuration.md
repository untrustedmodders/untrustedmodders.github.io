Всё, что вы настраиваете, лежит в `game/csgo/addons/plugify/`. Самому Plugify на сервере файл конфигурации не нужен: папки задаёт загрузчик, а плагины приносят свои настройки.

## Настройки плагинов

Файлы плагина загружаются из трёх мест в таком порядке:

| Порядок | Где | Что там лежит |
|---|---|---|
| 1 | `envs/<окружение>/<name>.<kind>.jsonc` | Значения по умолчанию из пакета. Заменяются при каждом обновлении |
| 2 | `configs/<name>/<name>.<kind>.jsonc` | Ваши правки. Сохраняются при обновлениях |
| 3 | `data/<name>/<name>.<kind>.jsonc` | Переводы и сохранённое состояние плагина |

`<name>` это имя плагина, которое показывает `plg plugins`, а `<kind>` это `settings`, `gamedata` или `translations`. Более поздний файл перекрывает ключи более раннего.

Чтобы изменить настройку, не правьте файл в `envs/`. Создайте файл с тем же именем в `configs/<name>/` и запишите в него только те ключи, которые меняете:

::code-group
```jsonc [envs/plugins/s2sdk.settings.jsonc]
{
  // значения по умолчанию из пакета
  "ServerLanguage": "en",
  "FollowCS2ServerGuidelines": true
}
```
```jsonc [configs/s2sdk/s2sdk.settings.jsonc]
{
  // ваша правка
  "ServerLanguage": "ru"
}
```
::

Файлы сливаются на один уровень: ключ верхнего уровня из вашего файла заменяет значение этого ключа целиком. Чтобы изменить одно поле внутри вложенной секции, скопируйте в свой файл всю секцию.

Изменения читаются при запуске плагина. Выполните `plg reload` или перезапустите сервер.

### Переводы

Переводы используют те же три места с видом `translations`. Чтобы изменить или добавить фразы, правьте файл в `data/<name>/`. Полный архив билда уже кладёт туда переводы базовых плагинов, и обновления их не трогают:

```jsonc [data/s2sdk/s2sdk.translations.jsonc]
{
  "S2SDK.Menu.Prev": {
    "en": "Back",
    "ru": "Назад"
  }
}
```


### Временные файлы

Скачанные и сгенерированные файлы плагины хранят в `pkgs/<name>/`. Эту папку можно удалить в любой момент: плагин создаст её заново.

## Permissions

Плагины прав хранят свои файлы в общей папке `permissions`:

| Файл | Назначение |
|---|---|
| `configs/permissions/permissions_storage.settings.yaml` | База данных для групп и прав |
| `configs/permissions/permissions_connector_s2.settings.yaml` | Уведомления и настройки команд |
| `data/permissions/permissions_connector_s2.translations.yaml` | Фразы, которые видят игроки |
| `data/permissions/permissions.db` | База SQLite, используется по умолчанию |

## Каналы пакетов

В `addons/plugify/.condarc` перечислены conda-каналы, из которых `mamba` ставит и обновляет пакеты. Первым идёт канал самого билда, за ним каналы его компонентов и всех языковых модулей. Добавьте сюда канал, чтобы ставить свои пакеты по имени. Архив загрузчика заменяет этот файл, поэтому сохраните копию своих правок:

```yaml [.condarc]
channel_priority: strict
channels:
  - https://untrustedmodders.github.io/plugify-builds/source2/
  - https://example.github.io/my-plugin/
```

## Параметры загрузчика

S2-Launcher принимает в командной строке такие аргументы:

| Аргумент | Значение |
|---|---|
| `--verbosity=<уровень>` | Уровень логов Plugify |
| `--profiler` | Включить профайлер, см. [Профилирование](/ru/builds/hosts/s2-launcher/profiling) |

Отчёты о падениях S2-Launcher настраиваются в `game/bin/<платформа>/sentry.jsonc`, см. [Обнаружение сбоев](/ru/builds/hosts/s2-launcher/crash-detection).
