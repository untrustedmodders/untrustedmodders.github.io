## Базовые плагины

::alert{type="info" icon="lucide:package-open" to="/ru/builds/source2"}
Базовые плагины (Configs, Permissions, PolyHook, DynCall и Source 2 SDK) уже входят в билд **Plugify Source 2**.
::

- [Source 2 SDK](/ru/plugins/s2sdk/features): доступ к игре на Source 2: команды, события, сущности, сообщения.
- [Config System](/ru/plugins/config-system/features): чтение настроек плагинов из JSON и JSONC со слиянием слоёв.
- [Permissions](/ru/plugins/permissions/features): пользователи, группы и права, с хранилищем в базе данных и командами для CS2.
- [PolyHook](/ru/plugins/polyhook/features): перехват функций с колбэками до и после вызова.
- [DynCall](/ru/plugins/dyncall/features): вызов функций C по адресу во время выполнения.
