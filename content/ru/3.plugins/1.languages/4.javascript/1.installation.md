**Языковой модуль JavaScript** можно установить двумя способами: вручную, скачав релиз, или с помощью менеджера пакетов Plugify. Это руководство объясняет оба метода и предоставляет пошаговые инструкции.

## **Способ 1: Ручная установка**

::steps
### **Скачайте релиз**
1. Перейдите в [репозиторий языкового модуля JavaScript](https://github.com/untrustedmodders/plugify-module-v8).
2. Перейдите в раздел **Releases**.
3. Загрузите архив для своей платформы: `plugify-module-v8-<версия>-linux_64.tar.bz2` или `win_64`.

### **Извлеките пакет**
1. Создайте новую папку внутри `addons/plugify/envs`, например `envs/v8`.
2. Распакуйте в неё архив. Манифест `plugify-module-v8.pmodule` должен оказаться в корне этой папки.

### **Проверьте установку**
1. Выполните `plg load` в консоли сервера или перезапустите сервер.
2. Выполните `plg modules`: модуль показан как `v8_module`.
::

## **Способ 2: Установка через менеджер пакетов**

::steps
### **Откройте консоль сервера**
Команда `mamba` встроена в консоль сервера, поэтому заранее ничего ставить не нужно. Операции с пакетами выполняются, пока Plugify выгружен: перед ними `plg unload`, после них `plg load`. См. [Команды](/ru/builds/management/commands).

### **Установите модуль**
1. Выполните следующие команды в консоли сервера:
   ```bash
   plg unload
   mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-v8/" plugify-module-v8
   plg load
   ```
   Вводите команды по одной, как описано в разделе [Команды](/ru/builds/management/commands).

### **Проверьте установку**
1. Выполните `plg modules`: модуль показан как `v8_module`.
::

## **Структура папок**

После установки языковой модуль JavaScript должен иметь следующую структуру папок:

::file-tree
---
tree:
- addons/plugify/envs:
    - modules:
        - bin:
            - plugify-module-v8.dll
            - libplugify-module-v8.so
        - lib/
        - v8/
        - ^plugify-module-v8.pmodule^
---
::

### **Объяснение**
- **`addons/plugify/envs/modules`**: Окружение, в которое `mamba` ставит языковые модули. Другие модули лежат в той же папке.
- **`bin`**: Содержит скомпилированные бинарные файлы модуля (`.dll` для Windows, `.so` для Linux и `.dylib` для macOS).
- **`lib`**: Модуль `plugify` для плагинов (`plugify.mjs`) и файл данных ICU.
- **`v8`**: Библиотеки движка V8.
- **`plugify-module-v8.pmodule`**: Файл манифеста модуля, который описывает модуль и его язык.

## **Устранение неполадок**

### **Модуль не найден**
- Убедитесь, что URL-адрес репозитория правильный и доступен.

### **Сбой установки**
- Проверьте ваше интернет-соединение.
- Убедитесь, что у вас установлена последняя версия Plugify.
