**Языковой модуль Go** можно установить двумя способами: вручную, скачав релиз, или с помощью менеджера пакетов Plugify. Это руководство объясняет оба метода и предоставляет пошаговые инструкции.

## **Метод 1: Ручная установка**

::steps
### **Загрузите релиз**
1. Перейдите в [репозиторий языкового модуля Go](https://github.com/untrustedmodders/plugify-module-golang).
2. Перейдите в раздел **Releases**.
3. Загрузите архив для своей платформы: `plugify-module-golang-<версия>-linux_64.tar.bz2`, `win_64` или `osx_arm64`.

### **Извлеките пакет**
1. Создайте новую папку внутри `addons/plugify/envs`, например `envs/golang`.
2. Распакуйте в неё архив. Манифест `plugify-module-golang.pmodule` должен оказаться в корне этой папки.

### **Проверьте установку**
1. Выполните `plg load` в консоли сервера или перезапустите сервер.
2. Выполните `plg modules`: модуль показан как `golang_module`.
::

## **Метод 2: Установка через менеджер пакетов**

::steps
### **Откройте консоль сервера**
Команда `mamba` встроена в консоль сервера, поэтому заранее ничего ставить не нужно. Операции с пакетами выполняются, пока Plugify выгружен: перед ними `plg unload`, после них `plg load`. См. [Команды](/ru/builds/management/commands).

### **Установите модуль**
1. Выполните следующие команды в консоли сервера:
   ```bash
   plg unload
   mamba install -n modules -c "https://untrustedmodders.github.io/plugify-module-golang/" plugify-module-golang
   plg load
   ```
   Вводите команды по одной, как описано в разделе [Команды](/ru/builds/management/commands).

### **Проверьте установку**
1. Выполните `plg modules`: модуль показан как `golang_module`.
::

## **Структура папок**

После установки языковой модуль Go должен иметь следующую структуру папок:

::file-tree
---
tree:
- addons/plugify/envs:
    - modules:
        - bin:
            - plugify-module-golang.dll
            - libplugify-module-golang.so
        - ^plugify-module-golang.pmodule^
---
::

### **Объяснение**
- **`addons/plugify/envs/modules`**: Корневая папка для языкового модуля Go.
- **`bin`**: Содержит скомпилированные бинарные файлы модуля (`.dll` для Windows, `.so` для Linux и `.dylib` для macOS).
- **`plugify-module-golang.pmodule`**: Файл манифеста модуля, который описывает модуль и его язык.

## **Устранение неполадок**

### **Модуль не найден**
- Убедитесь, что URL-адрес репозитория правильный и доступен.

### **Сбой установки**
- Проверьте ваше интернет-соединение.
- Убедитесь, что у вас установлена последняя версия Plugify.
