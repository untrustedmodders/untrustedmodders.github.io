**Языковой модуль Rust** (`plugify-module-rust`) является основным компонентом Plugify, который обеспечивает создание и управление плагинами на Rust. Это руководство проведет вас через процесс сборки модуля из исходного кода.

:read-more{icon="lucide:link" to="https://github.com/untrustedmodders/plugify-module-rust" title="Репозиторий на GitHub"}

## **Предварительные требования**

Перед сборкой языкового модуля Rust убедитесь, что у вас установлено следующее:

- **CMake** (версия 3.14 или новее)
- **Компилятор C++** с поддержкой C++23. Релизы собираются:
    - GCC 14 (Linux)
    - MSVC 2022 (Windows)
    - Apple Clang (macOS)
- **Git**: ядро Plugify подключено к репозиторию сабмодулем, поэтому клонируйте его с `--recursive`. Отдельно собирать ядро не нужно.

## **Шаги по сборке языкового модуля Rust**

::steps
### **Клонируйте репозиторий**
Клонируйте репозиторий `plugify-module-rust` на ваш локальный компьютер:

```bash
git clone https://github.com/untrustedmodders/plugify-module-rust.git --recursive
cd plugify-module-rust
```

### **Сгенерируйте файлы сборки**
Создайте каталог `build` и сгенерируйте файлы сборки с помощью CMake:

```bash
mkdir build
cd build
cmake ..
```

### **Соберите модуль**
Соберите модуль, используя следующую команду. Имя цели - `plugify-module-rust`.

```bash
cmake --build . --target plugify-module-rust
```

### **Проверьте сборку**
После завершения процесса сборки скомпилированный модуль будет находиться в каталоге `build`. Проверьте сборку, найдя следующие файлы:
- `plugify-module-rust.dll` (Windows)
- `libplugify-module-rust.so` (Linux)
- `libplugify-module-rust.dylib` (macOS)
::

## **Интеграция языкового модуля Rust**

После сборки модуля вы можете интегрировать его в вашу установку Plugify:

1. Установите релизный пакет модуля, как описано в разделе [Установка](/ru/plugins/languages/rust/installation). В нём есть манифест и файлы рантайма, которые нужны модулю.
2. Замените библиотеку в его папке `bin` на собранную из папки `build`.
3. Выполните `plg load` и проверьте, что `plg modules` показывает модуль.

## **Устранение неполадок**

### **Распространенные проблемы**
1. **Сборка не удалась**:
    - Убедитесь, что у вас установлена правильная версия CMake и совместимый компилятор C++.
    - Проверьте, что сабмодули склонированы: `git submodule update --init --recursive`.

2. **Модуль не загружается**:
    - Убедитесь, что файл модуля помещен в правильный каталог (`envs`).
    - Проверьте логи Plugify на наличие ошибок, связанных с загрузкой модуля.

3. **Отсутствующие символы**:
    - Собирайте модуль из релизного тега, чтобы встроенное ядро совпадало с версией Plugify, которую вы запускаете.
