Сначала давайте посмотрим, что требуется для простой команды. Команды регистрируются функцией `AddConsoleCommand`. Она принимает имя, описание, флаги команды, функцию обратного вызова и режим хука (`HookMode.Pre` или `HookMode.Post`).

Коллбэк вызывается каждый раз при использовании команды. Его прототип `ConCommandCallback`: он получает слот игрока, вызвавшего команду (`-1` для консоли сервера), контекст вызова (`ConCommandContext.Console` или `ConCommandContext.Chat`) и аргументы, а возвращает `ResultType`. Пример:

```csharp
public void OnPluginStart()
{
    var flags = ConVarFlag.LinkedConcommand | ConVarFlag.Release | ConVarFlag.ClientCanExecute;
    AddConsoleCommand("sm_myslap", "slap me baby!", flags, Command_MySlap, HookMode.Pre);
}

public ResultType Command_MySlap(int caller, ConCommandContext context, string[] arguments)
{
    return ResultType.Continue;
}
```

Теперь мы успешно реализовали команду, хотя она пока ничего не делает.
Возврат `ResultType.Continue` позволяет движку продолжить обработку команды. Для команды, созданной через `AddConsoleCommand`, часть движка ничего не делает, поэтому здесь это безвредно, но для существующей команды это значит, что исходный обработчик всё равно выполнится.

```csharp
public ResultType Command_MySlap(int caller, ConCommandContext context, string[] arguments)
{
    return ResultType.Handled;
}
```

Возврат `ResultType.Handled` (или `ResultType.Stop`) из коллбэка `Pre` не даёт движку обработать команду: исходный обработчик пропускается. См. перечисление `ResultType` в API, чтобы узнать больше об этих значениях.

## Добавление консольной команды

Вы можете привязать команды в `OnPluginStart` (или где угодно).

::tabs{variant="card"}
  ::div{label="c#" icon="vscode-icons:file-type-csharp2"}
  ```csharp
  using Plugify;
  using s2sdk;
  using static s2sdk.s2sdk;
  
  public unsafe class Sample : Plugin
  {
      public void OnPluginStart()
      {
          var flags = ConVarFlag.LinkedConcommand | ConVarFlag.Release | ConVarFlag.ClientCanExecute;
          AddConsoleCommand("custom_command", "A command is registered during OnPluginStart", flags, 
          (caller, context, arguments) =>
          {
              if (caller == -1) return ResultType.Handled;
              PrintToServer("Custom command called.\n");
              return ResultType.Handled;
          }, HookMode.Post);
      }
  }
  ```

              static_cast<int64_t>(ConVarFlag::ClientCanExecute));

                  if (caller == -1) return ResultType::Handled;

              }, HookMode::Post);
          return {};
      }
  };

  from plugify.plugin import Plugin

  def custom_command(caller, context, arguments):
    if caller != -1:
      s2.PrintToServer("Custom command called.\n")

              }
              return s2sdk.ResultType_Handled
          }, s2sdk.HookMode_Post)
      return nil
  }
 
  func init() {
      plugify.NewPlugin("sample", onPluginStart, nil, nil)
  }

  local Sample = {}

  function Sample:plugin_start()

      s2.AddConsoleCommand("custom_command", "A command is registered during OnPluginStart", flags,
          function(caller, context, arguments)
              if caller ~= -1 then s2.PrintToServer("Custom command called.\n") end
              return s2.ResultType.Handled
          end, s2.HookMode.Post)
  end
  
  local M = {}
  M.Sample = Sample
  return M

## Доступ к параметрам команды

Массив `arguments` предоставляет доступ к параметрам вызываемой команды. Первым параметром всегда будет вызываемая команда. Значения в кавычках возвращаются без кавычек, например:

```csharp
public ResultType OnCommand(int caller, ConCommandContext context, string[] arguments)
{
    PrintToServer($@"
        Command Caller: {caller}
        Command Context: {context}
        Arg Count: {arguments.Length}
        Arg String: {string.Join(" ", arguments[1..])}
        First Argument: {arguments[0]}
        Second Argument: {arguments[1]}
");
    return ResultType.Handled;
}
```

```shell
> custom_command "Test Quoted" 5 13

# Output
Command Caller: 1
Command Context: Console
Arg Count: 4
Arg String: Test Quoted 5 13
First Argument: custom_command
Second Argument: Test Quoted
```
