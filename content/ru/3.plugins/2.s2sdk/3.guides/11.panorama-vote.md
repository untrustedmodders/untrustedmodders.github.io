## Обзор

Система голосования Panorama позволяет создавать пользовательские голосования Да/Нет, которые отображаются в интерфейсе CS2. Игроки могут голосовать с помощью встроенного игрового интерфейса, что делает процесс естественным и знакомым.

::callout{type="info"}
**Ключевые возможности:**
- Интеграция с нативным UI CS2
- Настраиваемые сообщения голосования и текст успеха/провала
- Выборочное таргетирование игроков с использованием битовой маски
- Обратные вызовы событий голосования (начало, голос, конец)
- Пользовательская логика успеха/провала с подробной статистикой голосования
- Автоматическая обработка тайм-аута
::

Игроки голосуют клавишами F1 и F2 (консольные команды `vote option1` и `vote option2`). Игра принимает их голоса, только пока ConVar `sv_allow_votes` равен `1`, это его значение по умолчанию.

## Типы обратных вызовов

Система голосования использует два типа обратных вызовов:

### YesNoVoteHandler
Вызывается для событий голосования (начало, индивидуальные голоса, конец):

```csharp
void Handler(VoteAction action, int clientSlot, int choice)
```

- **VoteAction.Start**: Голосование началось (clientSlot = -1, choice = -1)
- **VoteAction.Vote**: Игрок проголосовал (clientSlot = слот клиента, choice = вариант голоса)
  - `VOTE_OPTION1` (0) = Да
  - `VOTE_OPTION2` (1) = Нет
- **VoteAction.End**: Голосование завершено (clientSlot = -1, choice = VoteEndReason)

Событие `End` приходит **до** вызова обратного вызова результата, поэтому по нему нельзя узнать, прошло ли голосование. Действуйте по итогу в обратном вызове результата.

### YesNoVoteResult
Вызывается в конце голосования для определения, прошло ли оно:

```csharp
Bool8 Result(int numVotes, int yesVotes, int noVotes, int numClients,
             int[] clientInfoSlot, int[] clientInfoItem)
```

- **Возвращает**: `true` для прохождения голосования, `false` для провала (в C# делегат возвращает `Bool8`, который неявно преобразуется из `bool`)
- **numVotes**: Всего отдано голосов (да + нет)
- **yesVotes**: Количество голосов "Да"
- **noVotes**: Количество голосов "Нет"
- **numClients**: Количество игроков в пуле голосования
- **clientInfoSlot**: Слоты всех игроков в пуле голосования
- **clientInfoItem**: Голос каждого из этих игроков (`0` = да, `1` = нет, `5` = не голосовал)

Обратный вызов результата не вызывается, если голосование отменено (`VoteEndReason.Cancelled`); голосование показывается как проваленное.

## Базовое создание голосования

Есть две основные функции для начала голосования:

1. **`PanoramaSendYesNoVoteToAll`** - Создает голосование для всех игроков
2. **`PanoramaSendYesNoVote`** - Создает голосование для определенных игроков (используя битовую маску получателей)

Обе возвращают `true`, если голосование началось. Они возвращают `false`, если уже идёт другое голосование, нет получателей, не передан обратный вызов результата или сущность карты `vote_controller` ещё не найдена (s2sdk ищет её на `round_start`, поэтому запускайте голосования, когда раунд уже идёт, например из команды).

```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public class VoteExample : Plugin
{
    // Not exported by s2sdk: player slot shown as "Server" and the vote options
    private const int VOTE_CALLER_SERVER = 99;
    private const int VOTE_OPTION1 = 0; // Yes

    // Call this once a round is running (for example from a command)
    public void StartRestartVote()
    {
        // Create a simple vote for all players
        bool started = PanoramaSendYesNoVoteToAll(
            duration: 30.0,
            caller: VOTE_CALLER_SERVER,
            voteTitle: "#SFUI_vote_restart_game",
            detailStr: "",
            votePassTitle: "#SFUI_vote_passed_restart_game",
            detailPassStr: "",
            failReason: VoteCreateFailed.Generic,
            result: OnVoteResult,
            handler: OnVoteHandler
        );

        if (!started)
        {
            PrintToServer("Could not start the vote\n");
        }
    }

    // Called to determine if vote passes
    private Bool8 OnVoteResult(int numVotes, int yesVotes, int noVotes,
                               int numClients, int[] clientInfoSlot, int[] clientInfoItem)
    {
        PrintToServer($"Vote finished: {yesVotes} Yes, {noVotes} No, " +
                     $"{numVotes}/{numClients} voted\n");

        // Simple majority of the votes cast
        bool passed = yesVotes > noVotes;
        if (passed)
        {
            ServerCommand("mp_restartgame 1");
        }
        return passed;
    }

    // Called for vote events
    private void OnVoteHandler(VoteAction action, int clientSlot, int choice)
    {
        switch (action)
        {
            case VoteAction.Start:
                PrintToServer("Vote started!\n");
                break;

            case VoteAction.Vote:
                string vote = choice == VOTE_OPTION1 ? "Yes" : "No";
                PrintToServer($"Player {clientSlot} voted: {vote}\n");
                break;

            case VoteAction.End:
                VoteEndReason reason = (VoteEndReason)choice;
                PrintToServer($"Vote ended: {reason}\n");
                // The result callback runs after this event
                break;
        }
    }
}
```

## Перечисления

### CastVote
Значения выбора голосования, используемые в обратных вызовах. s2sdk передаёт их как обычные целые числа и не экспортирует это перечисление, поэтому объявите нужные константы в своём плагине:

| Значение | Описание |
|-------|-------------|
| `VOTE_OPTION1` (0) | Голос "Да" |
| `VOTE_OPTION2` (1) | Голос "Нет" |
| `VOTE_NOTINCLUDED` (-1) | Игрок не включен в голосование |
| `VOTE_UNCAST` (5) | Игрок не проголосовал |

### VoteAction
События, передаваемые в обратный вызов обработчика:

| Значение | Описание | clientSlot | choice |
|-------|-------------|--------|--------|
| `Start` | Голосование началось | -1 | -1 |
| `Vote` | Игрок проголосовал | слот клиента | выбор голоса (CastVote) |
| `End` | Голосование завершено | -1 | VoteEndReason |

### VoteEndReason
Причины завершения голосования:

| Значение | Описание |
|-------|-------------|
| `AllVotes` | Все возможные голоса были отданы |
| `TimeUp` | Время голосования истекло |
| `Cancelled` | Голосование было отменено вручную |

## Битовая маска получателей (Выборочное голосование)

Чтобы создать голосование для определенных игроков, используйте `PanoramaSendYesNoVote` с **битовой маской получателей** (параметр `filter`). Каждый бит в `uint64` представляет слот игрока:

- **Бит 0** (значение 1) = Слот игрока 0
- **Бит 1** (значение 2) = Слот игрока 1
- **Бит 2** (значение 4) = Слот игрока 2
- **Бит N** (значение 2^N) = Слот игрока N

::callout{type="info"}
**Построение битовой маски:** Установите бит N в 1, чтобы включить слот игрока N в голосование. Значение получателей - это сумма всех включенных битовых значений игроков.
::

### Создание битовой маски получателей

```csharp
// Include specific players by slot
public ulong BuildRecipients(int[] playerSlots)
{
    ulong recipients = 0;
    foreach (int slot in playerSlots)
    {
        if (slot >= 0 && slot < 64)
        {
            recipients |= (1UL << slot);
        }
    }
    return recipients;
}

// Examples:
// Only player slot 0
ulong player0Only = 1UL << 0;  // = 1

// Only player slot 5
ulong player5Only = 1UL << 5;  // = 32

// Players 0, 1, and 2
ulong players012 = (1UL << 0) | (1UL << 1) | (1UL << 2);  // = 7

// Use in vote
int[] targetPlayers = { 0, 2, 5 };
ulong recipients = BuildRecipients(targetPlayers);

PanoramaSendYesNoVote(
    duration: 30.0,
    caller: VOTE_CALLER_SERVER,
    voteTitle: "#SFUI_vote_kick_player_other",
    detailStr: "Bob",
    votePassTitle: "#SFUI_vote_passed_kick_player",
    detailPassStr: "Bob",
    failReason: VoteCreateFailed.Generic,
    filter: recipients,
    result: OnVoteResult,
    handler: OnVoteHandler
);
```

## Пользовательская логика прохождения голосования

Обратный вызов `result` позволяет реализовать пользовательскую логику для определения прохождения голосования:

```csharp
// Require 60% yes votes
private Bool8 OnVoteResult(int numVotes, int yesVotes, int noVotes,
                           int numClients, int[] clientInfoSlot, int[] clientInfoItem)
{
    if (numVotes == 0) return false;

    double yesPercent = (double)yesVotes / numVotes * 100.0;
    bool passed = yesPercent >= 60.0;

    PrintToServer($"Vote: {yesPercent:F1}% yes ({yesVotes}/{numVotes})\n");
    return passed;
}

// Require majority of ALL clients (not just voters)
private Bool8 OnVoteResultStrict(int numVotes, int yesVotes, int noVotes,
                                 int numClients, int[] clientInfoSlot, int[] clientInfoItem)
{
    bool passed = yesVotes > (numClients / 2);
    PrintToServer($"Vote: {yesVotes}/{numClients} clients voted yes\n");
    return passed;
}

// Analyze individual votes
private Bool8 OnVoteResultDetailed(int numVotes, int yesVotes, int noVotes,
                                   int numClients, int[] clientInfoSlot, int[] clientInfoItem)
{
    PrintToServer("Vote details:\n");
    for (int i = 0; i < clientInfoSlot.Length; i++)
    {
        int slot = clientInfoSlot[i];
        int choice = clientInfoItem[i];
        string vote = choice switch
        {
            VOTE_OPTION1 => "Yes",
            VOTE_OPTION2 => "No",
            _ => "Did not vote",
        };
        PrintToServer($"  Slot {slot}: {vote}\n");
    }

    return yesVotes > noVotes;
}
```

## Вспомогательные функции голосования

Система голосования предоставляет несколько утилитарных функций:

### Проверка активного голосования

```csharp
bool isVoting = PanoramaIsVoteInProgress();
if (isVoting)
{
    PrintToServer("A vote is currently active!\n");
}
```

### Удаление игрока из голосования

Удаляет игрока из текущего пула голосования (он больше не может голосовать). Отключившиеся игроки удаляются автоматически:

```csharp
PanoramaRemovePlayerFromVote(3);  // Remove player slot 3
```

### Проверка, находится ли игрок в пуле голосования

```csharp
int playerSlot = 5;
if (PanoramaIsPlayerInVotePool(playerSlot))
{
    PrintToServer($"Player {playerSlot} can vote\n");
}
```

### Перерисовка UI голосования для игрока

Сбрасывает текущий голос игрока и снова показывает ему UI голосования:

```csharp
bool success = PanoramaRedrawVoteToClient(playerSlot);
```

### Ручное завершение голосования

```csharp
PanoramaEndVote(VoteEndReason.Cancelled);
```

## Практические примеры

### Пример 1: Голосование за карту с ограничением по команде

Разрешить только контр-террористам голосовать за смену карты:

```csharp
public void StartMapVote()
{
    // Build recipients bitmask for CT team only
    ulong recipients = 0;
    for (int slot = 0; slot < 64; slot++)
    {
        if (!IsClientInGame(slot)) continue;

        if (GetClientTeam(slot) == CSTeam.CT)
        {
            recipients |= (1UL << slot);
        }
    }

    if (recipients == 0)
    {
        PrintToServer("No CT players to vote!\n");
        return;
    }

    PanoramaSendYesNoVote(
        duration: 30.0,
        caller: VOTE_CALLER_SERVER,
        voteTitle: "#SFUI_vote_changelevel",
        detailStr: "de_dust2",
        votePassTitle: "#SFUI_vote_passed_changelevel",
        detailPassStr: "de_dust2",
        failReason: VoteCreateFailed.Generic,
        filter: recipients,
        result: (numVotes, yesVotes, noVotes, numClients, slots, items) =>
        {
            bool passed = yesVotes > noVotes;
            if (passed)
            {
                // The result callback decides the outcome, so act here
                ServerCommand("changelevel de_dust2");
            }
            return passed;
        },
        handler: (action, clientSlot, choice) => { }
    );
}
```

### Пример 2: Отслеживание прогресса голосования

```csharp
private int totalYesVotes = 0;
private int totalNoVotes = 0;

public void StartTrackedVote()
{
    totalYesVotes = 0;
    totalNoVotes = 0;

    PanoramaSendYesNoVoteToAll(
        duration: 30.0,
        caller: VOTE_CALLER_SERVER,
        voteTitle: "#SFUI_vote_restart_game",
        detailStr: "",
        votePassTitle: "#SFUI_vote_passed_restart_game",
        detailPassStr: "",
        failReason: VoteCreateFailed.Generic,
        result: (numVotes, yesVotes, noVotes, numClients, slots, items) =>
        {
            PrintToServer($"Final: {yesVotes} Yes, {noVotes} No\n");
            return yesVotes > (numClients / 2);  // Majority of all clients
        },
        handler: (action, clientSlot, choice) =>
        {
            switch (action)
            {
                case VoteAction.Start:
                    PrintToChatAll("Vote started: Restart match?");
                    break;

                case VoteAction.Vote:
                    if (choice == VOTE_OPTION1)
                        totalYesVotes++;
                    else if (choice == VOTE_OPTION2)
                        totalNoVotes++;

                    PrintToChatAll($"Current: {totalYesVotes} Yes, {totalNoVotes} No");
                    break;

                case VoteAction.End:
                    VoteEndReason reason = (VoteEndReason)choice;
                    PrintToChatAll($"Vote ended: {reason}");
                    break;
            }
        }
    );
}
```

### Пример 3: Голосование за кик, инициированное игроком

```csharp
public void StartKickVote(int callerSlot, int targetSlot)
{
    if (PanoramaIsVoteInProgress())
    {
        PrintToChat(callerSlot, "A vote is already in progress!");
        return;
    }

    string targetName = GetClientName(targetSlot);

    PanoramaSendYesNoVoteToAll(
        duration: 30.0,
        caller: callerSlot,
        voteTitle: "#SFUI_vote_kick_player_other",
        detailStr: targetName,
        votePassTitle: "#SFUI_vote_passed_kick_player",
        detailPassStr: targetName,
        failReason: VoteCreateFailed.Generic,
        result: (numVotes, yesVotes, noVotes, numClients, slots, items) =>
        {
            // Require 60% yes votes
            bool passed = numVotes > 0 && ((double)yesVotes / numVotes) >= 0.6;
            if (passed)
            {
                KickClient(targetSlot, NetworkDisconnectionReason.Kicked, "Kicked by vote");
            }
            return passed;
        },
        handler: (action, clientSlot, choice) =>
        {
            if (action == VoteAction.Start)
            {
                // Remove target from vote pool
                PanoramaRemovePlayerFromVote(targetSlot);
                PrintToChatAll($"Vote: Kick {targetName}?");
            }
        }
    );
}
```

## Строки перевода

Окно голосования показывает строки перевода самой игры из `resource/csgo_<язык>.txt`. Если в тексте строки есть `{s:s1}`, игра подставляет туда `detailStr` (или `detailPassStr`). Строки без `{s:s1}` показывают свой фиксированный текст, и строка деталей не видна. Строки для произвольного вопроса в игре нет, поэтому выбирайте ту, что подходит к вашему голосованию:

| `voteTitle` | Текст | `votePassTitle` | Текст |
|---|---|---|---|
| `#SFUI_vote_restart_game` | Restart the match? | `#SFUI_vote_passed_restart_game` | Restarting the match... |
| `#SFUI_vote_changelevel` | Change current level to `{s:s1}`? | `#SFUI_vote_passed_changelevel` | Changing level to `{s:s1}`... |
| `#SFUI_vote_nextlevel` | Set the next level to `{s:s1}`? | `#SFUI_vote_passed_nextlevel` | Next level set to `{s:s1}`... |
| `#SFUI_vote_kick_player_other` | Kick player: `{s:s1}`? | `#SFUI_vote_passed_kick_player` | Kicking player: `{s:s1}`... |
| `#SFUI_vote_scramble_teams` | Scramble the teams? | `#SFUI_vote_passed_scramble_teams` | Teams will be scrambled. |
| `#SFUI_vote_swap_teams` | Swap the teams? | `#SFUI_vote_passed_swap_teams` | Teams will be swapped. |
| | | `#SFUI_vote_passed` | Vote Passed! |

Тексты в таблице приведены по английской локализации, у игрока они показываются на его языке.

::callout{type="warning"}
**Требование строк перевода:** Используйте только строки перевода, начинающиеся с `#SFUI_vote` или `#Panorama_vote`. Другие строки могут некорректно отображаться в UI голосования.
::

## Справочник методов

### Запуск голосований

| Метод | Описание |
|--------|-------------|
| `PanoramaSendYesNoVoteToAll(duration, caller, voteTitle, detailStr, votePassTitle, detailPassStr, failReason, result, handler)` | Начать голосование для всех игроков. Возвращает `true`, если голосование началось |
| `PanoramaSendYesNoVote(duration, caller, voteTitle, detailStr, votePassTitle, detailPassStr, failReason, filter, result, handler)` | Начать голосование для определенных игроков (используя битовую маску). Возвращает `true`, если голосование началось |

#### Параметры

- **`duration`** (double) - Максимальное время в секундах для голосования
- **`caller`** (int) - Слот игрока, который инициировал голосование, или слот сервера (`VOTE_CALLER_SERVER`, 99) для голосований сервера
- **`voteTitle`** (string) - Строка перевода для вопроса голосования, см. [Строки перевода](#строки-перевода)
- **`detailStr`** (string) - Текст, который подставляется в `{s:s1}` строки `voteTitle`
- **`votePassTitle`** (string) - Строка перевода, показываемая при прохождении голосования
- **`detailPassStr`** (string) - Текст, который подставляется в `{s:s1}` строки `votePassTitle`
- **`failReason`** (VoteCreateFailed) - Причина, показываемая при провале голосования (`VoteCreateFailed.Generic` для обычного "голосование провалено")
- **`filter`** (uint64) - Битовая маска слотов игроков, которые могут голосовать (только для `PanoramaSendYesNoVote`)
- **`result`** (обратный вызов YesNoVoteResult) - Функция, которая определяет, прошло ли голосование:
  ```csharp
  Bool8 Result(int numVotes, int yesVotes, int noVotes, int numClients,
               int[] clientInfoSlot, int[] clientInfoItem)
  ```
  - Возвращает `true` для прохождения голосования, `false` для провала
  - `numVotes`: Всего отдано голосов
  - `yesVotes`: Количество голосов "Да"
  - `noVotes`: Количество голосов "Нет"
  - `numClients`: Количество игроков в пуле голосования
  - `clientInfoSlot`: Слоты игроков в пуле голосования
  - `clientInfoItem`: Голос каждого из этих игроков (CastVote)

- **`handler`** (обратный вызов YesNoVoteHandler) - Функция, вызываемая для событий голосования:
  ```csharp
  void Handler(VoteAction action, int clientSlot, int choice)
  ```
  - `action`: Тип события (Start, Vote, End)
  - `clientSlot`: Зависит от действия (слот клиента для Vote, -1 для Start и End)
  - `choice`: Зависит от действия (выбор голоса для Vote, VoteEndReason для End)

### Управление голосованием

| Метод | Описание |
|--------|-------------|
| `PanoramaIsVoteInProgress()` | Возвращает `true`, если голосование в данный момент активно |
| `PanoramaEndVote(VoteEndReason reason)` | Вручную завершить текущее голосование с указанием причины |

### Управление игроками

| Метод | Описание |
|--------|-------------|
| `PanoramaRemovePlayerFromVote(int playerSlot)` | Удалить игрока из текущего пула голосования |
| `PanoramaIsPlayerInVotePool(int playerSlot)` | Проверить, может ли игрок голосовать в текущем голосовании |
| `PanoramaRedrawVoteToClient(int playerSlot)` | Сбросить голос игрока и снова показать ему UI голосования |

## Советы и лучшие практики

1. **Проверяйте активные голосования** - Всегда используйте `PanoramaIsVoteInProgress()` перед началом нового голосования
2. **Реализуйте пользовательскую логику прохождения** - Используйте обратный вызов `result` для определения, что означает "прохождение" для вашего голосования
3. **Отслеживайте прогресс голосования** - Используйте событие `VoteAction.Vote` обратного вызова `handler` для мониторинга голосов в реальном времени
4. **Отключения обрабатываются** - Отключившиеся игроки удаляются из пула голосования автоматически
5. **Используйте подходящую длительность** - 20-30 секунд типично для большинства голосований
6. **Проверяйте получателей** - Убедитесь, что в битовой маске получателей есть хотя бы один игрок
7. **Используйте строки перевода** - Придерживайтесь строк `#SFUI_vote` или `#Panorama_vote` для правильной локализации
8. **Удаляйте цели голосования** - Не позволяйте игрокам, против которых голосуют, участвовать
9. **Разделяйте логику** - Используйте `result` для логики прохождения/провала и действий по итогу, `handler` для событий прогресса
10. **Логируйте данные голосования** - Используйте массивы `clientInfoSlot` и `clientInfoItem` для детального отслеживания голосов
