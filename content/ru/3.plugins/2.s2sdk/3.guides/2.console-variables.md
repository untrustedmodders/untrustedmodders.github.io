## Обзор

Консольные переменные (ConVars) являются основным способом настройки параметров игры и поведения плагинов. С новой поддержкой классов вы можете работать с ConVars двумя способами:

- **Подход на основе классов** - Использование класса-обёртки `ConVar` для более чистого объектно-ориентированного кода
- **Подход на основе функций** - Традиционные функции в стиле C с явными дескрипторами

::callout{icon="i-lucide-lightbulb" color="blue"}
**Новое**: Класс `ConVar` оборачивает дескриптор и даёт более чистый синтаксис и лучшую поддержку IDE. Используйте его для нового кода, если он доступен на вашем языке!
::

## Поиск ConVar

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  Используйте статический метод `ConVar.Find` для получения экземпляра ConVar:
  ```csharp
  var cheatsCvar = ConVar.Find("sv_cheats");
  if (cheatsCvar.IsValid) {
      // Use the ConVar instance
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Используйте функцию `FindConVar` для получения дескриптора:
  ```csharp
  var cheatsCvar = FindConVar("sv_cheats");
  ```
  ::
::

## Манипулирование примитивными значениями

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  Чтение и установка значений более интуитивны с методами:
  ```csharp
  var cheatsCvar = ConVar.Find("sv_cheats");

  // Read value using typed methods
  bool value = cheatsCvar.GetBool();

  // Set value using typed methods
  cheatsCvar.SetBool(true, /*replicate*/true, /*notify*/false);

  // You can also use the generic Set method
  cheatsCvar.Set(true, /*replicate*/true, /*notify*/false);
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Чтение и установка требует явной передачи дескриптора:
  ```csharp
  var cheatsCvar = FindConVar("sv_cheats");

  // Read value
  bool value = GetConVarBool(cheatsCvar);

  // Set value with additional parameters
  SetConVarBool(cheatsCvar, true, /*replicate*/true, /*notify*/false);

  // Or use the generic setter
  SetConVar(cheatsCvar, true, /*replicate*/true, /*notify*/false);
  ```
  ::
::

## Манипулирование объектами

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  Строковые значения обрабатываются через типизированные методы:
  ```csharp
  var stringCvar = ConVar.Find("sv_skyname");

  // Get string value
  string skyName = stringCvar.GetString();
  PrintToServer($"sv_skyname = {skyName}");

  // Set string value
  stringCvar.SetString("foobar", /*replicate*/true, /*notify*/false);
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Строковые значения требуют явного преобразования типов:
  ```csharp
  var stringCvar = FindConVar("sv_skyname");

  // Get string value
  string skyName = GetConVarString(stringCvar);
  PrintToServer($"sv_skyname = {skyName}");

  // Set string value
  SetConVarString(stringCvar, "foobar", /*replicate*/true, /*notify*/false);
  ```
  ::
::

## Создание ConVars

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  Создавайте ConVars используя конструктор класса с автоматическим определением типа:
  ```csharp
  // Create different types of ConVars
  var stringCvar = new ConVar("my_plugin_name", "DefaultName", "Player name", ConVarFlag.None);
  var intCvar = new ConVar("my_plugin_maxplayers", 32, "Max players", ConVarFlag.None);
  var floatCvar = new ConVar("my_plugin_speed", 1.5f, "Speed multiplier", ConVarFlag.None);
  var boolCvar = new ConVar("my_plugin_enabled", true, "Enable plugin", ConVarFlag.None);

  // Use the created ConVars
  if (boolCvar.GetBool()) {
      int maxPlayers = intCvar.GetInt32();
      PrintToServer($"Plugin enabled with {maxPlayers} max players\n");
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Создавайте ConVars используя функции для конкретных типов:
  ```csharp
  // Create different types of ConVars
  var stringCvar = CreateConVarString("my_plugin_name", "DefaultName", "Player name", ConVarFlag.None);
  // Numeric types also take bounds: hasMin, min, hasMax, max
  var intCvar = CreateConVarInt32("my_plugin_maxplayers", 32, "Max players", ConVarFlag.None, true, 1, true, 64);
  var floatCvar = CreateConVarFloat("my_plugin_speed", 1.5f, "Speed multiplier", ConVarFlag.None, true, 0.1f, false, 0f);
  var boolCvar = CreateConVarBool("my_plugin_enabled", true, "Enable plugin", ConVarFlag.None, false, false, false, false);

  // Use the created ConVars
  if (GetConVarBool(boolCvar)) {
      int maxPlayers = GetConVarInt32(intCvar);
      PrintToServer($"Plugin enabled with {maxPlayers} max players\n");
  }
  ```
  ::

## Полный пример

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  ```csharp
  using Plugify;
  using s2sdk;
  using static s2sdk.s2sdk;

  public unsafe class ConVarDemo : Plugin
  {
      private ConVar speedCvar;
      private ConVar gravityCvar;

      public void OnPluginStart()
      {
          // Create custom ConVars
          speedCvar = new ConVar("demo_speed", 1.0f, "Player speed multiplier", ConVarFlag.None);
          gravityCvar = new ConVar("demo_gravity", 1.0f, "Gravity multiplier", ConVarFlag.None);

          // Hook ConVar changes
          speedCvar.HookChange(OnSpeedChanged);

          // Find existing game ConVars
          var cheatsCvar = ConVar.Find("sv_cheats");
          if (cheatsCvar.IsValid)
          {
              bool cheatsEnabled = cheatsCvar.GetBool();
              PrintToServer($"Cheats enabled: {cheatsEnabled}\n");
          }
      }

      public void OnPluginEnd()
      {
          // Unhook changes
          if (speedCvar != null && speedCvar.IsValid)
          {
              speedCvar.UnhookChange(OnSpeedChanged);
          }
      }

      private static void OnSpeedChanged(ulong conVarHandle, string newValue, string oldValue)
      {
          PrintToServer($"Speed changed from {oldValue} to {newValue}\n");
      }
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  ```csharp
  using Plugify;
  using s2sdk;
  using static s2sdk.s2sdk;

  public unsafe class ConVarDemo : Plugin
  {
      private ulong speedCvar;
      private ulong gravityCvar;

      public void OnPluginStart()
      {
          // Create custom ConVars
          speedCvar = CreateConVarFloat("demo_speed", 1.0f, "Player speed multiplier", ConVarFlag.None, false, 0f, false, 0f);
          gravityCvar = CreateConVarFloat("demo_gravity", 1.0f, "Gravity multiplier", ConVarFlag.None, false, 0f, false, 0f);

          // Hook ConVar changes
          HookConVarChange(speedCvar, OnSpeedChanged);

          // Find existing game ConVars
          ulong cheatsCvar = FindConVar("sv_cheats");
          if (cheatsCvar != 0)
          {
              bool cheatsEnabled = GetConVarBool(cheatsCvar);
              PrintToServer($"Cheats enabled: {cheatsEnabled}\n");
          }
      }

      public void OnPluginEnd()
      {
          // Unhook changes
          if (speedCvar != 0)
          {
              UnhookConVarChange(speedCvar, OnSpeedChanged);
          }
      }

      private static void OnSpeedChanged(ulong conVarHandle, string newValue, string oldValue)
      {
          PrintToServer($"Speed changed from {oldValue} to {newValue}\n");
      }
  }
  ```
