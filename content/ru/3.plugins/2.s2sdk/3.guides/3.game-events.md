## Обзор

События представляют собой информационные уведомления, передаваемые между объектами на сервере. Многие из них также передаются с сервера клиенту. Они определены в ресурсных файлах игры (`resource/*.gameevents`). Для базового списка см. [Source2 Game Events](https://cs2.poggu.me/dumped-data/game-events/).

Важно отметить несколько концепций о событиях:

- Они почти всегда информационные. То есть блокирование player_death не остановит смерть игрока. Это может заблокировать сообщение в HUD или консоли или что-то еще незначительное.
- То, что событие находится в файле ресурсов, не означает, что оно когда-либо вызывается или работает так, как вы ожидаете.

::callout{icon="i-lucide-lightbulb" color="blue"}
**Новое**: Класс `EventInfo` оборачивает дескриптор события и даёт более чистый способ работы с игровыми событиями через типизированные методы.
::

## Быстрый пример: Событие смерти игрока

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  ```csharp
  public void RegisterEvents()
  {
      HookEvent("player_death", Event_PlayerDeath, HookMode.Post);
  }

  public static ResultType Event_PlayerDeath(string name, nint @event, Bool8 dontBroadcast)
  {
      EventInfo eventInfo = new EventInfo(@event);
      
      // Use typed methods on the EventInfo instance
      int victim = eventInfo.GetPlayerSlot("userid");
      int attacker = eventInfo.GetPlayerSlot("attacker");

      /* CODE */
      return ResultType.Continue;
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}

## Добавление слушателя событий

Вы можете привязать слушатели событий в `OnPluginStart` (или где угодно).

::tabs{variant="card"}
::div{label="c#" icon="vscode-icons:file-type-csharp2"}
  ```csharp
  using Plugify;
  using s2sdk;
  using static s2sdk.s2sdk;
  
  public unsafe class Sample : Plugin
  {
      public void OnPluginStart()
      {
          HookEvent("player_death", (name, @event, dontBroadcast) =>
          {
              int playerSlot = GetEventPlayerSlot(@event, "userid");
              PrintToServer("event called.\n");
              return ResultType.Continue;
          }, HookMode.Post);
      }
  }
  ```
::
::div{label="c++" icon="vscode-icons:file-type-cpp3"}
  ```cpp
  #include <plg/plugin.hpp>
  #include <s2sdk/s2sdk.hpp>
  
  using namespace s2sdk;
  
  class Sample : public plg::Plugin {
  public:  
      plg::PluginResult OnPluginStart() override {
          HookEvent("player_death", [](const plg::string& name, void* event, bool dontBroadcast) -> ResultType {
                  int playerSlot = GetEventPlayerSlot(event, "userid");
                  PrintToServer("event called.\n");
                  return ResultType::Continue;
              }, HookMode::Post);
          return {};
      }
  };
  ```

::div{label="python" icon="vscode-icons:file-type-python"}

  ```python
    player_slot = s2.GetEventPlayerSlot(event, "userid")
  ```

::div{label="go" icon="vscode-icons:file-type-go"}
  ```go
  package main

  import (
      "fmt"

  }
  ```

## Доступ к параметрам событий

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  Доступ к параметрам событий с использованием типизированных методов на экземпляре EventInfo:
  ```csharp
  // Reading event parameters
  int playerSlot = eventInfo.GetPlayerSlot("userid");
  float damage = eventInfo.GetFloat("damage");
  string weaponName = eventInfo.GetString("weapon");
  bool headshot = eventInfo.GetBool("headshot");

  // Get entity references (entity pointers)
  nint playerController = eventInfo.GetPlayerController("userid");
  nint playerPawn = eventInfo.GetPlayerPawn("userid");
  nint entity = eventInfo.GetEntity("entityid");
  ```

  Установка параметров событий столь же проста:
  ```csharp
  // Setting event parameters
  eventInfo.SetPlayerSlot("userid", 3);
  eventInfo.SetFloat("damage", 50.0f);
  eventInfo.SetString("weapon", "ak47");
  eventInfo.SetBool("headshot", true);

  // Set entity references (entity handles)
  eventInfo.SetPlayerController("userid", controllerHandle);
  eventInfo.SetEntity("entityid", entityHandle);
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Доступ к параметрам событий с использованием явных функций с дескриптором события:
  ```csharp
  // Reading event parameters
  int playerSlot = GetEventPlayerSlot(@event, "userid");
  float damage = GetEventFloat(@event, "damage");
  string weaponName = GetEventString(@event, "weapon");
  bool headshot = GetEventBool(@event, "headshot");

  // Get entity references (entity pointers)
  nint playerController = GetEventPlayerController(@event, "userid");
  nint playerPawn = GetEventPlayerPawn(@event, "userid");
  nint entity = GetEventEntity(@event, "entityid");
  ```

  Установка параметров событий требует явных вызовов функций:
  ```csharp
  // Setting event parameters
  SetEventPlayerSlot(@event, "userid", 3);
  SetEventFloat(@event, "damage", 50.0f);
  SetEventString(@event, "weapon", "ak47");
  SetEventBool(@event, "headshot", true);

  // Set entity references (entity handles)
  SetEventPlayerController(@event, "userid", controllerHandle);
  SetEventEntity(@event, "entityid", entityHandle);
  ```

## Создание и запуск событий

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  Создавайте и запускайте пользовательские события используя класс EventInfo:
  ```csharp
  // Create a new event
  var customEvent = new EventInfo("player_hurt", /*force*/false);
  if (customEvent.IsValid)
  {
      // Set event parameters
      customEvent.SetPlayerSlot("userid", 1);
      customEvent.SetPlayerSlot("attacker", 2);
      customEvent.SetInt("health", 50);
      customEvent.SetString("weapon", "ak47");

      // Fire to all players (the engine frees the event)
      customEvent.Fire(/*dontBroadcast*/false);

      // Or fire to a specific player, then free the event yourself
      // customEvent.FireToClient(playerSlot);
      // customEvent.Cancel();
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Создавайте и запускайте пользовательские события используя явные функции:
  ```csharp
  // Create a new event
  nint customEvent = CreateEvent("player_hurt", /*force*/false);

  // Set event parameters
  SetEventPlayerSlot(customEvent, "userid", 1);
  SetEventPlayerSlot(customEvent, "attacker", 2);
  SetEventInt(customEvent, "health", 50);
  SetEventString(customEvent, "weapon", "ak47");

  // Fire to all players (the engine frees the event)
  FireEvent(customEvent, /*dontBroadcast*/false);

  // Or fire to a specific player, then free the event yourself
  // FireEventToClient(customEvent, playerSlot);
  // CancelCreatedEvent(customEvent);
  ```

## Отмена события

В хуке pre-события возврат `ResultType.Handled` или `ResultType.Stop` отменяет событие: остальные pre-коллбэки не вызываются, и движок его не запускает.

::tabs
  ::div{label="С классами (рекомендуется)" icon="lucide:box"}
  ```csharp
  public void OnPluginStart()
  {
      HookEvent("player_death", OnPlayerDeathPre, HookMode.Pre);
  }

  private static ResultType OnPlayerDeathPre(string name, nint @event, Bool8 dontBroadcast)
  {
      EventInfo eventInfo = new EventInfo(@event);
      int victim = eventInfo.GetPlayerSlot("userid");

      // Cancel death event for admin players
      if (IsPlayerAdmin(victim))
      {
          PrintToServer("Prevented admin death event\n");
          return ResultType.Handled;
      }

      return ResultType.Continue;
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  ```csharp
  public void OnPluginStart()
  {
      HookEvent("player_death", OnPlayerDeathPre, HookMode.Pre);
  }

  private static ResultType OnPlayerDeathPre(string name, nint @event, Bool8 dontBroadcast)

      {

  }
  ```
