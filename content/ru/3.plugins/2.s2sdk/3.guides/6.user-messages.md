## Понимание User Messages

User messages - это основной метод отправки пользовательских данных с сервера клиентам в Source 2. Они используют **Protocol Buffers (protobuf)** для сериализации, обеспечивая структурированный и эффективный способ передачи игровой информации.

Типичные случаи использования включают:
- Отображение HUD-элементов и уведомлений
- Воспроизведение звуков или визуальных эффектов на клиентах
- Отправка пользовательской информации о состоянии игры
- Создание чат-сообщений и подсказок
- Запуск событий на стороне клиента

User messages работают аналогично реализации SourceMod, где protobuf заменяет старую систему bitbuffer для лучшей типобезопасности и гибкости.

::callout{icon="i-lucide-lightbulb" color="blue"}
**Новое**: Класс `UserMessage` обеспечивает автоматическое управление ресурсами и более чистый синтаксис для работы с user messages. Он гарантирует правильную очистку и предоставляет интуитивные методы!
::

## Поиск определений сообщений

Вы можете найти определения protobuf-сообщений здесь:
- **CS:GO Protobufs**: [SteamDatabase/Protobufs](https://github.com/SteamDatabase/Protobufs/tree/master/csgo)
- Эти `.proto` файлы определяют доступные сообщения и их поля
- Часто используемые сообщения включают `TextMsg`, `HintText`, `Fade` и многие другие

Каждое определение сообщения показывает имя сообщения, ID и доступные поля с их типами.

## Перехват User Messages

Вы можете перехватывать user messages до того, как они будут отправлены клиентам:

```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public unsafe class Sample : Plugin
{
    public void OnPluginStart()
    {
        // Find message ID by name
        short msgId = UserMessageFindMessageIdByName("TextMsg");

        // Hook the message in Post mode
        HookUserMessage(msgId, OnTextMessage, HookMode.Post);

    {
        short msgId = UserMessageFindMessageIdByName("TextMsg");
        UnhookUserMessage(msgId, OnTextMessage, HookMode.Post);

    {
        // "param" is a repeated field, read its first element
        string text = PbReadString(userMessage, "param", 0);
        PrintToServer($"TextMsg intercepted: {text}\n");
        return ResultType.Continue;
    }
}
```

```lua
M.Sample = Sample
```

## Создание и отправка User Messages

Неизвестное имя или ID сообщения дают недействительное сообщение: `UserMessageCreateFromName` и `UserMessageCreateFromId` возвращают `0`, а у класса `IsValid == false`. Проверяйте это перед записью полей.

::tabs
  ::div{label="С классами (Рекомендуется)" icon="lucide:box"}
  Создавайте user messages используя класс `UserMessage` с автоматической очисткой:
  ```csharp
  // Create from message name (most common)
  using (var msg = new UserMessage("TextMsg"))
  {
      // Set recipients
      msg.AddAllPlayers();

      // Set message fields ("param" is a repeated field)
      msg.AddString("param", "Hello from server!");
      msg.SetUInt32("dest", 3);  // 3 = chat

      // Send the message
      msg.Send();
  } // Automatically destroyed

  // Or create from message ID
  short msgId = UserMessage.FindMessageIdByName("TextMsg");
  using (var msg = new UserMessage(msgId))
  {
      // Configure and send...
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  Создавайте user messages используя явные функции:
  ```csharp
  // Method 1: From message name (most common)
  nint msg = UserMessageCreateFromName("TextMsg");

  // Method 2: From message ID
  short msgId = UserMessageFindMessageIdByName("TextMsg");
  nint msg = UserMessageCreateFromId(msgId);

  // Method 3: From serializable (advanced)
  nint msg = UserMessageCreateFromSerializable(msgSerializable, message, recipientMask);

  // Set recipients (choose one approach)
  UserMessageAddAllPlayers(msg);  // All players
  // OR
  UserMessageAddRecipient(msg, playerSlot);  // Single player
  // OR
  UserMessageSetRecipientMask(msg, customMask);  // Custom mask

  // Set message fields
  PbAddString(msg, "param", "Hello from server!");
  PbSetUInt32(msg, "dest", 3);  // 3 = chat

  // Send the message
  UserMessageSend(msg);

  // Clean up (IMPORTANT! Sending does not free the message)
  UserMessageDestroy(msg);
  ```

## Чтение и запись типов данных

User messages поддерживают различные типы данных. Вы можете использовать либо методы класса `UserMessage` (рекомендуется), либо функции `PbRead*`, `PbGet*` и `PbSet*`. `Read*` сразу возвращает значение; `Get*` возвращает `true`/`false` и записывает значение в `ref`-параметр. Аргумент `index` у `Read*` равен `-1` для обычного поля и индексу элемента для повторяющегося поля.

Имена сообщений и полей в примерах ниже условные: используйте реальное сообщение и имена полей из его `.proto`-определения. Сеттер должен совпадать с типом поля (`SetUInt32` для поля `uint32`, `SetInt32` для `int32`), иначе он вернёт `false`.

### Целые числа

::tabs
  ::div{label="С классами (Рекомендуется)" icon="lucide:box"}
  ```csharp
  using (var msg = new UserMessage("CustomMsg"))
  {
      // Write integers
      msg.SetInt32("fieldName", 42);
      msg.SetInt64("bigField", 1000000L);
      msg.SetUInt32("unsignedField", 99u);

      // Read integers (in hook callbacks)
      int value = msg.ReadInt32("fieldName", -1);
      long bigValue = msg.ReadInt64("bigField", -1);
      uint unsigned = msg.ReadUInt32("unsignedField", -1);

      // Or check that the read succeeded
      int checkedValue = 0;
      if (msg.GetInt32("fieldName", ref checkedValue))
      {
          PrintToServer($"fieldName = {checkedValue}\n");
      }
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  ```csharp

  uint unsigned = PbReadUInt32(msg, "unsignedField", -1);

  // Write
  PbSetInt32(msg, "fieldName", 42);
  PbSetInt64(msg, "bigField", 1000000L);
  PbSetUInt32(msg, "unsignedField", 99u);
  ```

### Цвета

Функции цвета работают с полями `CMsgRGBA`; каждая компонента является числом от 0 до 255. Некоторые сообщения хранят цвет как упакованный `fixed32` (например, `color` в `Fade`): такие поля записывайте через `SetUInt32`.

::tabs
  ::div{label="С классами (Рекомендуется)" icon="lucide:box"}
  ```csharp
  using System.Numerics;

  using (var msg = new UserMessage("CustomMsg"))
  {
      // Write color (RGBA, 0-255)
      msg.SetColor("color", new Vector4(255, 0, 0, 255)); // Red, full alpha

      // Create color from components
      var color = new Vector4(255, 128, 0, 255);
      msg.SetColor("color", color);

      // Read color (in hook callbacks)
      Vector4 clr = msg.ReadColor("color", -1);

      // Extract components
      float red   = clr.X;
      float green = clr.Y;
      float blue  = clr.Z;
      float alpha = clr.W;
  }
  ```
  ::

## Работа с повторяющимися полями

Некоторые protobuf-поля являются массивами (repeated fields):

::tabs
  ::div{label="С классами (Рекомендуется)" icon="lucide:box"}
  ```csharp
  using (var msg = new UserMessage("CustomMsg"))
  {
      // Add values to repeated field
      msg.AddInt32("items", 10);
      msg.AddInt32("items", 20);
      msg.AddInt32("items", 30);
      msg.AddString("names", "Player1");
      msg.AddString("names", "Player2");

      // Get count of repeated field
      int count = msg.GetRepeatedFieldCount("items");
      PrintToServer($"Total items: {count}\n");

      // Read repeated values
      for (int i = 0; i < count; i++)
      {
          int value = msg.ReadInt32("items", i);
          PrintToServer($"Item[{i}] = {value}\n");
      }

      // Set specific index in repeated field
      msg.SetRepeatedInt32("items", 0, 999);  // Set index 0 to 999

      // Remove value from repeated field
      msg.RemoveRepeatedFieldValue("items", 0);  // Remove index 0
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  ```csharp
  // Get count of repeated field
  int count = UserMessageGetRepeatedFieldCount(msg, "items");

  // Read repeated values
  for (int i = 0; i < count; i++)
  {
      int value = PbReadInt32(msg, "items", i);  // Note: index is 3rd parameter
      PrintToServer($"Item[{i}] = {value}\n");
  }

  // Add values to repeated field
  PbAddInt32(msg, "items", 10);
  PbAddInt32(msg, "items", 20);
  PbAddString(msg, "names", "Player1");

  // Set specific index in repeated field
  PbSetRepeatedInt32(msg, "items", 0, 999);  // Set index 0 to 999

  // Remove value from repeated field
  UserMessageRemoveRepeatedFieldValue(msg, "items", 0);  // Remove index 0
  ```

## Работа с вложенными сообщениями

Некоторые сообщения содержат вложенные поля сообщений. `GetMessage`, `ReadMessage` и `GetRepeatedMessage` (`PbGetMessage`, `PbReadMessage`, `PbGetRepeatedMessage`) возвращают сырой указатель на protobuf-сообщение, а не user message: его нельзя передавать в функции чтения и записи `Pb*`. Передавайте его в `SetMessage`, `SetRepeatedMessage` или `AddMessage`, которые копируют его в поле того же типа. Вложенные векторы, углы и цвета читаются и пишутся функциями выше.

::tabs
  ::div{label="С классами (Рекомендуется)" icon="lucide:box"}
  ```csharp
  using (var source = new UserMessage("CustomMsg"))
  using (var msg = new UserMessage("CustomMsg"))
  {
      // Get nested message (raw protobuf pointer)
      nint nested = 0;
      if (source.GetMessage("nested_field", ref nested))
      {
          // Copy it into the same field of another message
          msg.SetMessage("nested_field", nested);
      }

      // Copy every element of a repeated nested field
      int count = source.GetRepeatedFieldCount("repeated_nested");
      for (int i = 0; i < count; i++)
      {
          nint item = source.ReadMessage("repeated_nested", i);
          if (item != 0)
          {
              msg.AddMessage("repeated_nested", item);
          }
      }
  }
  ```
  ::
  ::div{label="Без классов" icon="lucide:code"}
  ```csharp
  // Get nested message (raw protobuf pointer)
  nint nested = 0;
  if (PbGetMessage(source, "nested_field", ref nested))
  {
      // Copy it into the same field of another message
      PbSetMessage(msg, "nested_field", nested);
  }

  // Get repeated nested message
  nint item = 0;
  if (PbGetRepeatedMessage(source, "repeated_nested", 0, ref item))
  {
      // Add a copy to a repeated field
      PbAddMessage(msg, "repeated_nested", item);
  }
  ```

## Практические примеры

### Пример 1: Отправка чат-сообщения всем игрокам

::tabs{variant="card"}
::div{label="С классами" icon="lucide:box"}
```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public unsafe class ChatMessage : Plugin
{
    public void OnPluginStart()
    {
        AddConsoleCommand("say_all", "Send message to all players",
        ConVarFlag.LinkedConcommand | ConVarFlag.Release | ConVarFlag.ClientCanExecute,
        Command_SayAll, HookMode.Post);
    }

    public ResultType Command_SayAll(int caller, ConCommandContext context, string[] arguments)
    {
        if (arguments.Length < 2)
        {
            PrintToServer("Usage: say_all <message>\n");
            return ResultType.Handled;
        }

        string message = string.Join(" ", arguments, 1, arguments.Length - 1);
        SendChatMessage(message);

        return ResultType.Handled;
    }

    private void SendChatMessage(string text)
    {
        // Using statement ensures automatic cleanup
        using (var msg = new UserMessage("TextMsg"))
        {
            // Add all players as recipients
            msg.AddAllPlayers();

            // Set message fields
            msg.AddString("param", text);
            msg.SetUInt32("dest", 3);  // 3 = chat

            // Send
```

### Пример 4: Перехват и изменение сообщений

::tabs{variant="card"}
::div{label="С классами" icon="lucide:box"}
```csharp
using Plugify;
using s2sdk;
using static s2sdk.s2sdk;

public unsafe class MessageFilter : Plugin
{
    public void OnPluginStart()
    {
        short msgId = UserMessage.FindMessageIdByName("TextMsg");
        HookUserMessage(msgId, OnTextMessagePre, HookMode.Pre);
    }

    public void OnPluginEnd()
    {
        short msgId = UserMessage.FindMessageIdByName("TextMsg");
        UnhookUserMessage(msgId, OnTextMessagePre, HookMode.Pre);
    }

    private static ResultType OnTextMessagePre(nint userMessagePtr)
    {
        // Wrap the borrowed pointer (the default ownership is Borrowed)
        var userMessage = new UserMessage(userMessagePtr);

        // Read original message ("param" is a repeated field)
        string originalText = userMessage.ReadString("param", 0);

        // Filter profanity
        string filtered = originalText.Replace("badword", "****");

        if (filtered != originalText)
        {
            PrintToServer("Filtered message content\n");
        }

        // Replace the text with a prefixed, filtered version
        userMessage.SetRepeatedString("param", 0, "[Server] " + filtered);

        // Note: No need to destroy, the wrapper does not own the message
        return ResultType.Continue;
    }
}
```

## Советы и лучшие практики

1. **Всегда уничтожайте созданные сообщения** - Вызывайте `UserMessageDestroy()` после отправки (отправка не освобождает сообщение); никогда не уничтожайте сообщение, полученное в колбэке перехвата
2. **Проверяйте ID сообщений** - `UserMessageFindMessageIdByName()` возвращает `0` для неизвестного имени, а перехват ID `0` перехватывает все сообщения
3. **Передавайте правильный индекс** - `-1` для обычного поля, от `0` до `count - 1` для повторяющегося
4. **Используйте правильные имена полей** - Обращайтесь к определениям protobuf для точных имен полей
5. **Правильно обрабатывайте режимы перехвата** - Используйте `Pre` для изменения или блокировки сообщений (верните `Handled`), `Post` для наблюдения за ними
6. **Отменяйте перехваты в OnPluginEnd** - Всегда очищайте перехваты при выгрузке плагина
7. **Проверяйте количество повторяющихся полей** - Проверяйте количество перед доступом к индексам повторяющихся полей
8. **Тестируйте с клиентами** - Убедитесь, что сообщения правильно отображаются на стороне клиента
9. **Используйте соответствующие типы данных** - Сопоставляйте функции `PbRead*`/`PbSet*` с типами полей
10. **Учитывайте производительность** - Избегайте отправки больших сообщений или слишком большого количества сообщений за тик

## Часто используемые User Messages

Вот часто используемые user messages в CS:GO/CS2:

**TextMsg** (`CUserMessageTextMsg`) - Отправить текст в чат или консоль:
- `dest` (uint32) - Назначение: 1=уведомление, 2=консоль, 3=чат, 4=центр
- `param` (repeated string) - Текст сообщения, затем его аргументы

**HintText** - Показать подсказку на экране:
- `message` (string) - Текст подсказки для отображения

**Fade** (`CUserMessageFade`) - Эффект затемнения экрана:
- `duration` (uint32) - Длительность затемнения, в 1/512 секунды (512 = одна секунда)
- `hold_time` (uint32) - Время удержания, в тех же единицах
- `flags` (uint32) - Флаги затемнения (FFADE_IN, FFADE_OUT и т.д.)
- `color` (fixed32) - Упакованный цвет RGBA

**Damage** (`CCSUsrMsg_Damage`) - Показать индикатор урона:
- `amount` (int32) - Количество урона
- `inflictor_world_pos` (CMsgVector) - Позиция источника урона
- `victim_entindex` (int32) - Индекс сущности жертвы

**SayText2** (`CUserMessageSayText2`) - Форматированное чат-сообщение:
- `entityindex` (int32) - Индекс сущности отправителя
- `chat` (bool) - Отправить в чат
- `messagename` (string) - Строка формата сообщения
- `param1` ... `param4` (string) - Параметры сообщения

Обратитесь к [определениям protobuf CS:GO](https://github.com/SteamDatabase/Protobufs/tree/master/csgo) для полного списка сообщений и их полей.

## Режимы перехвата

- **Pre** (`HookMode.Pre`) - Перехват до обработки сообщения, позволяет модификацию
- **Post** (`HookMode.Post`) - Перехват после обработки сообщения, только чтение для наблюдения

Используйте режим Pre, когда хотите изменить или заблокировать сообщения, режим Post для логирования или запуска побочных эффектов.
