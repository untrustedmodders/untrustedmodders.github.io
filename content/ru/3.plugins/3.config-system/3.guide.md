Это руководство показывает, как плагин загружает свои настройки с помощью плагина **Configs**. Примеры написаны на Python. Функции одинаковы во всех языках, а как их вызывает ваш язык, описано в разделе [импорта функций](/ru/plugins/languages).

## Добавьте зависимость

Объявите `configs` в манифесте своего плагина, чтобы он загружался раньше вашего:

```json [my_plugin.pplugin]
{
  "$schema": "https://raw.githubusercontent.com/untrustedmodders/plugify/refs/heads/main/schemas/plugin.schema.json",
  "name": "my_plugin",
  "version": "1.0.0",
  "language": "python3",
  "description": "An example plugin",
  "author": "Your Name",
  "website": "https://example.com",
  "license": "MIT",
  "entry": "my_plugin.MyPlugin",
  "dependencies": [
    { "name": "configs" }
  ]
}
```

## Где хранить файлы

Называйте каждый файл по имени плагина, `<name>.<kind>.jsonc`, и храните его в стандартных местах:

| Где | Что хранить |
|---|---|
| Папка плагина, `<name>.settings.jsonc` | Значения по умолчанию из пакета |
| `configs/<name>/<name>.settings.jsonc` | Правки владельца сервера |
| `data/<name>/<name>.translations.jsonc` | Переводы и сохранённое состояние |
| `pkgs/<name>/` | Временные файлы, которые можно создать заново |

Имя плагина в имени файла важно: в одну папку окружения ставится несколько пакетов, и файлы с одинаковыми именами перезаписывали бы друг друга.

Если у плагина есть собственные плагины-модули, их файлы можно хранить в одной общей папке с именем основного плагина. Каждый файл при этом по-прежнему называется по имени своего плагина. Например, плагины [permissions](/ru/plugins/permissions/guide) хранят правки в `configs/permissions/`, а переводы в `data/permissions/`.

## Прочитайте настройки

Передайте в `ReadMultiple` три пути в порядке загрузки: пакет, `configs`, `data`. Более поздний файл перекрывает ключи более раннего, а несуществующие файлы пропускаются.

```python [my_plugin.py]
import os
from plugify.plugin import Plugin
from plugify.pps import configs


class MyPlugin(Plugin):
    def plugin_start(self):
        file = f"{self.name}.settings.jsonc"
        config = configs.ReadMultiple([
            os.path.join(self.location, file),
            os.path.join(self.configs_dir, self.name, file),
            os.path.join(self.data_dir, self.name, file),
        ])
        if not config:
            print("Failed to load settings: " + configs.GetError())
            return

        self.greeting = configs.GetString(config, "Greeting", "Hello")
        self.max_players = configs.GetAsInt(config, "MaxPlayers", 10)
        self.enabled = configs.GetBool(config, "Enabled", True)

        configs.Delete(config)
```

`Read` и `ReadMultiple` возвращают хэндл или `0` при ошибке. Причину возвращает `GetError`. Когда хэндл больше не нужен, освободите его через `Delete`.

Слияние идёт на один уровень: ключ верхнего уровня из более позднего файла заменяет значение этого ключа целиком. Учитывайте это, когда проектируете вложенные настройки.

## Чтение значений

Каждая функция чтения принимает хэндл, ключ и значение по умолчанию:

| Функция | Возвращает |
|---|---|
| `GetBool(config, key, default)` | `bool` |
| `GetInt(config, key, default)` | `int64` |
| `GetFloat(config, key, default)` | `double` |
| `GetString(config, key, default)` | `string` |
| `GetAsBool`, `GetAsInt`, `GetAsFloat`, `GetAsString` | Значение, преобразованное к запрошенному типу |
| `HasKey(config, key)` | Существует ли ключ |

Число из файла хранится как дробное, поэтому `GetInt` возвращает для него значение по умолчанию. Целые числа из файлов читайте через `GetAsInt`. `GetInt` читает значения, записанные через `SetInt`.

## Объекты и массивы

Хэндл работает как курсор, который указывает на один узел. Функции `Jump*` перемещают его, а функции чтения читают относительно текущего узла.

```jsonc [my_plugin.settings.jsonc]
{
  "Database": {
    "Host": "localhost",
    "Port": 3306
  },
  "Admins": ["alice", "bob"]
}
```

```python
# Step into an object, read, step back
if configs.JumpKey(config, "Database", False):
    host = configs.GetString(config, "Host", "")
    port = configs.GetAsInt(config, "Port", 0)
    configs.JumpBack(config)

# Walk an array
admins = []
if configs.JumpKey(config, "Admins", False):
    if configs.JumpFirst(config):
        while True:
            admins.append(configs.GetAsString(config, "##this##", ""))
            if not configs.JumpNext(config):
                break
        configs.JumpBack(config)
    configs.JumpBack(config)
```

Ключ может быть путём с `/` между частями: `GetString(config, "Database/Host", "")` читает вложенное значение, не перемещая курсор. Особый ключ `##this##` обозначает сам текущий узел, так читаются элементы массива.

| Функция | Куда перемещает курсор |
|---|---|
| `JumpKey(config, key, create)` | К дочернему узлу с этим ключом. С `create` узел создаётся, если его нет |
| `JumpFirst`, `JumpLast` | К первому или последнему дочернему узлу |
| `JumpNext`, `JumpPrev` | К следующему или предыдущему соседу |
| `JumpN(config, n)` | К дочернему узлу с номером `n` |
| `JumpBack` | К родителю |
| `JumpRoot` | К корню |

`GetSize` возвращает число дочерних узлов, `GetName` возвращает имя текущего узла, а `IsObject`, `IsArray`, `IsString` и остальные функции `Is*` сообщают его тип.

## Создание и изменение конфига

`Make` создаёт пустой конфиг. Функции `Set*` записывают значение под ключом текущего узла, а функции `Push*` добавляют элемент в текущий массив.

```python
config = configs.Make()
configs.SetString(config, "Greeting", "Hello")
configs.SetArray(config, "Admins")
configs.JumpKey(config, "Admins", False)
configs.PushString(config, "alice")
configs.JumpRoot(config)

text = configs.RootToJsonString(config)
configs.Delete(config)
```

`Merge(config, other)` копирует ключи другого конфига в этот, а `RemoveKey` и `Clear` удаляют узлы.

## Класс Config

В языках с поддержкой классов сгенерированные биндинги содержат класс `Config`. Он создаётся через `Read`, `ReadMultiple` или `Make`, содержит перечисленные выше функции как методы и сам освобождает хэндл. См. страницу Using Classes вашего языка.

Полный список функций с сигнатурами есть на [API Hub](https://api.plugify.net/?file=https://raw.githubusercontent.com/untrustedmodders/plugify-plugin-configs/refs/heads/main/plugify-plugin-configs.pplugin.in).
