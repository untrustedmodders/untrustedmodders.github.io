Плагин **Permissions** можно установить через менеджер пакетов Plugify или вручную из релиза.

## **Метод 1: Установка через менеджер пакетов**

::steps
### **Откройте консоль сервера**
Команда `mamba` встроена в консоль сервера, поэтому заранее ничего ставить не нужно. Операции с пакетами выполняются, пока Plugify выгружен: перед ними `plg unload`, после них `plg load`. См. [Команды](/ru/builds/management/commands).

### **Установите плагин**
1. Выполните в консоли сервера:
   ```bash
   plg unload
   mamba install -n plugins -c "https://untrustedmodders.github.io/plugify-plugin-permissions/" plugify-plugin-permissions
   mamba install -n plugins -c "https://fr0nch.github.io/permissions-storage/" permissions-storage
   mamba install -n plugins -c "https://fr0nch.github.io/permissions-connector-s2/" permissions-connector-s2
   plg load
   ```

   Вводите команды по одной, а не вставляйте блоком. См. [Команды](/ru/builds/management/commands).

   Первый пакет это ядро. `permissions-storage` сохраняет группы и игроков в базу данных, а `permissions-connector-s2` связывает ядро с сервером Counter-Strike 2 и добавляет команды `perms_*`. Коннектору также нужны пакеты `plugify-plugin-s2sdk` и `plugify-plugin-translations`.

### **Проверьте установку**
1. Выполните `plg plugins`: плагин показан как `permissions`.
::

## **Метод 2: Ручная установка**

::steps
### **Загрузите релиз**
1. Перейдите в [репозиторий Permissions](https://github.com/untrustedmodders/plugify-plugin-permissions).
2. Перейдите в раздел **Releases**.
3. Загрузите архив для своей платформы: `plugify-plugin-permissions-<версия>-linux_64.tar.bz2` или `win_64`.

### **Извлеките пакет**
1. Распакуйте архив в `addons/plugify/envs/plugins`, без папки `info`. Манифест `plugify-plugin-permissions.pplugin` должен оказаться в корне этой папки.

### **Проверьте установку**
1. Выполните `plg load` в консоли сервера или перезапустите сервер.
2. Выполните `plg plugins`: плагин показан как `permissions`.
::

## **Структура папок**

После установки файлы плагина лежат в окружении `plugins`:

::file-tree
---
tree:
- addons/plugify/envs:
    - plugins:
        - bin:
            - libplugify-plugin-permissions.so
            - plugify-plugin-permissions.dll
        - ^plugify-plugin-permissions.pplugin^
---
::

### **Объяснение**
- **`addons/plugify/envs/plugins`**: окружение, в которое `mamba` ставит плагины. Другие плагины лежат в той же папке.
- **`bin`**: библиотека плагина: `plugify-plugin-permissions.dll` в Windows, `libplugify-plugin-permissions.so` в Linux.
- **`plugify-plugin-permissions.pplugin`**: манифест плагина, который описывает плагин и его экспортируемые функции.

## **Устранение неполадок**

### **Плагин не найден**
- Убедитесь, что URL репозитория указан верно и доступен.

### **Ошибка установки**
- Проверьте подключение к интернету.
- Убедитесь, что у вас установлена последняя версия Plugify.
