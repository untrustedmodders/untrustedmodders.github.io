Это руководство показывает, как плагин перехватывает нативные функции с помощью плагина **PolyHook**. Примеры на C++ и используют сгенерированный заголовок `polyhook/polyhook.hpp`, где все функции лежат в пространстве имён `polyhook`. Функции одинаковы во всех языках, как их вызывать из вашего языка, см. [Импорт функций](/ru/plugins/languages).

## Добавьте зависимость

Укажите `polyhook` в манифесте своего плагина, чтобы он загружался раньше вашего:

```json
"dependencies": [
  { "name": "polyhook" }
]
```

## Опишите сигнатуру

Хуку нужно знать типы аргументов и возвращаемого значения. Они задаются через `DataType`:

```c++
enum class DataType : uint8_t {
  Void, Bool, Int8, UInt8, Int16, UInt16, Int32, UInt32,
  Int64, UInt64, Float, Double, Pointer, String
};
```

У метода класса первый аргумент это `this`, тип `Pointer`.

## Перехватите функцию

Каждая функция установки хука возвращает хэндл хука или `nullptr` при ошибке. `GetError` возвращает причину.

| Функция | Что перехватывает |
|---|---|
| `HookDetour(pFunc, returnType, arguments, varIndex, name)` | Функцию по адресу `pFunc` |
| `HookVirtualTable(pClass, index, returnType, arguments, varIndex, name)` | Виртуальную функцию номер `index` одного объекта `pClass`. Объект получает свою копию таблицы виртуальных функций, другие объекты класса не затрагиваются |
| `HookVirtualFunc(pClass, index, returnType, arguments, varIndex, name)` | Запись номер `index` в таблице виртуальных функций `pClass`. Затрагиваются все объекты, которые используют эту таблицу |
| `HookVirtualTable2`, `HookVirtualFunc2` | То же, но с указателем на метод `pFunc` вместо индекса |
| `HookDetour2(pFunc, name)` | Хук в середине функции по любому адресу, см. ниже |

- `varIndex` это индекс первого вариативного аргумента или `-1` для обычной функции.
- `name` это имя для логов и профайлера. Может быть пустым.
- `GetVirtualIndex(pFunc)` возвращает индекс виртуальной функции по указателю на метод.

Повторный хук той же функции возвращает уже существующий хук, поэтому несколько плагинов могут пользоваться одним хуком.

```c++
#include <polyhook/polyhook.hpp>

using namespace polyhook;

void* hook = HookDetour(pAdd, DataType::Int32, { DataType::Int32, DataType::Int32 }, -1, "Add");
if (!hook) {
  // GetError() tells why
}
```

## Добавьте колбэки

```c++
bool AddCallback(HookHandle hook, CallbackType type, CallbackHandler handler);
bool AddCallback2(HookHandle hook, CallbackType type, CallbackHandler handler, int32_t priority);
```

`type` это `CallbackType::Pre` (до исходной функции) или `CallbackType::Post` (после неё). Колбэки с большим приоритетом вызываются раньше, `AddCallback` использует приоритет `0`. `RemoveCallback` удаляет колбэк.

У всех колбэков одна сигнатура:

```c++
ResultType Handler(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type);
```

Результат pre-колбэков решает, что будет с исходной функцией. Побеждает наибольший результат среди всех pre-колбэков:

```c++
enum class ResultType : int32_t {
  Ignored,   // The callback did nothing
  Handled,   // The callback did something, the original function runs
  Override,  // The callback changed the result, the original function runs
  Supercede  // The original function is skipped, the value set with SetReturn* is returned
};
```

Результат post-колбэка не используется.

## Аргументы и возвращаемое значение

`GetArgument<Type>(params, index)` и `SetArgument<Type>(params, index, value)` читают и меняют аргумент. `GetReturn<Type>(ret)` и `SetReturn<Type>(ret, value)` читают и меняют возвращаемое значение. `<Type>` это один из `Bool`, `Int8` … `UInt64`, `Float`, `Double`, `Pointer` и `String`. Сеттеры для `String` принимают ещё и хэндл хука: `SetArgumentString(hook, params, index, value)` и `SetReturnString(hook, ret, value)`.

## Пример

Перехватим `int Add(int a, int b)`: перед вызовом прибавим единицу к каждому аргументу, после вызова удвоим результат.

```c++
ResultType PreAdd(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type) {
  int32_t a = GetArgumentInt32(params, 0);
  int32_t b = GetArgumentInt32(params, 1);
  SetArgumentInt32(params, 0, a + 1);
  SetArgumentInt32(params, 1, b + 1);
  return ResultType::Handled;
}

ResultType PostAdd(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type) {
  SetReturnInt32(ret, GetReturnInt32(ret) * 2);
  return ResultType::Ignored;
}

void Setup(void* pAdd) {
  void* hook = HookDetour(pAdd, DataType::Int32, { DataType::Int32, DataType::Int32 }, -1, "Add");
  AddCallback(hook, CallbackType::Pre, PreAdd);
  AddCallback(hook, CallbackType::Post, PostAdd);
}
```

Теперь `Add(2, 3)` возвращает `14`. Чтобы пропустить исходную функцию, задайте возвращаемое значение в pre-колбэке и верните `ResultType::Supercede`:

```c++
ResultType BlockAdd(HookHandle hook, ParametersHandle params, int32_t count, ReturnHandle ret, CallbackType type) {
  SetReturnInt32(ret, 100);
  return ResultType::Supercede;
}
```

## Хуки в середине функции

`HookDetour2` останавливает выполнение на любом адресе, даже в середине функции. Колбэки получают регистры процессора в `params`, `count` это число регистров, а `ret` пуст. Читайте и меняйте регистры через `GetRegister<Type>(params, reg)` и `SetRegister<Type>(params, reg, value)`, где `reg` это `RegisterType`, например `RegisterType::RDI` или `RegisterType::XMM0`.

```c++
ResultType OnMid(HookHandle hook, ParametersHandle registers, int32_t count, ReturnHandle ret, CallbackType type) {
  int32_t first = GetRegisterInt32(registers, RegisterType::RDI); // the first argument on Linux
  return ResultType::Ignored;
}
```

## Снятие хуков

| Функция | Что снимает |
|---|---|
| `UnhookDetour(pFunc)` | Detour-хук или хук в середине функции |
| `UnhookVirtualTable(pClass, index)`, `UnhookVirtualFunc(pClass, index)` | Хук виртуальной функции (и варианты `2`, которые принимают `pFunc`) |
| `UnhookAllVirtual(pClass)` | Все виртуальные хуки объекта |
| `UnhookAll()` | Все хуки |

Хуки общие для всех плагинов, и снятие хука удаляет вместе с ним колбэки всех плагинов. Если ту же функцию могут перехватывать другие плагины, при завершении своего плагина удаляйте только свои колбэки через `RemoveCallback`.

## Другие функции

- `FindDetour`, `FindVirtual`, `FindVirtual2` возвращают существующий хук или `nullptr`.
- `AreCallbacksRegistered`, `IsCallbackRegistered` сообщают, есть ли у хука колбэки.
- `GetFunctionAddr` возвращает адрес сгенерированной функции, `GetOriginalAddr` адрес для вызова исходной функции.

В C++ в заголовке есть также классы `Callback`, `Parameters`, `Return`, `Registers` и `PolyHook` с теми же функциями в виде методов. Там варианты `2` называются `HookVirtualTableByFunc`, `HookVirtualFuncByFunc` и `FindVirtualByFunc`.

Полный список функций с сигнатурами есть в [API Hub](https://api.plugify.net/?file=https://raw.githubusercontent.com/untrustedmodders/plugify-plugin-polyhook/refs/heads/main/plugify-plugin-polyhook.pplugin.in).
