Плагин **DynCall** (`dyncall`) вызывает нативные функции по их адресу во время работы. Плагин на любом языке передаёт аргументы по одному и вызывает функцию с ожидаемым типом результата, поэтому биндинг для функции компилировать не нужно. Плагин построен на библиотеке [dyncall](https://dyncall.org/) и работает на x86-64 в Windows и Linux.

## Что он делает

- **Вызов по адресу.** `NewVM` создаёт VM вызова, функции `Arg*` передают аргументы, а функции `Call*` вызывают функцию и возвращают её результат.
- **Все базовые типы.** Логические значения, целые от 8 до 64 бит, `float`, `double`, указатели и C-строки, для аргументов и для результата.
- **Соглашения о вызове.** `Mode` выбирает соглашение, например для методов C++ или вариативных функций.
- **Структуры по значению.** `NewAggr` и `AggrField` описывают структуру, `ArgAggr` и `CallAggr` передают и возвращают её.
- **Один API для всех языков.** Функции экспортируются через манифест плагина, а в языках с поддержкой классов VM оборачивает класс `DCCallVM`.

## Когда использовать

- Нужно вызвать функцию игры, которую Source 2 SDK не экспортирует, и у вас есть её адрес, например из сигнатуры в [gamedata](/ru/plugins/s2sdk/guides/gamedata).
- Ваш язык сам не умеет вызывать нативный указатель на функцию.
