Это руководство показывает, как плагин вызывает нативную функцию по её адресу с помощью плагина **DynCall**. Примеры на Python. Функции одинаковы во всех языках, как их вызывать из вашего языка, см. [Импорт функций](/ru/plugins/languages).

## Добавьте зависимость

Укажите `dyncall` в манифесте своего плагина, чтобы он загружался раньше вашего:

```json
"dependencies": [
  { "name": "dyncall" }
]
```

## Вызовите функцию

Пусть адрес `func` указывает на такую функцию:

```c++
double add(double a, double b);
```

Создайте VM вызова, передайте аргументы по порядку и вызовите функцию вариантом `Call*` для её типа результата:

```python
from plugify.pps import dyncall as dc

vm = dc.NewVM(4096)          # 4096 bytes for the arguments
dc.Reset(vm)                 # clear the arguments of the previous call
dc.ArgDouble(vm, 2.0)
dc.ArgDouble(vm, 3.5)
result = dc.CallDouble(vm, func)   # 5.5
dc.Free(vm)
```

Одну VM можно использовать для многих вызовов: перед каждым вызывайте `Reset`. Когда VM больше не нужна, освободите её через `Free`. `GetError(vm)` возвращает ненулевой код, если последний вызов не удался.

## Типы

| Тип C | Передать | Вызвать |
|---|---|---|
| `bool` | `ArgBool` | `CallBool` |
| `char` | `ArgChar` | `CallChar` |
| `int8_t` … `uint64_t` | `ArgInt8`, `ArgUInt8`, `ArgInt16`, `ArgUInt16`, `ArgInt32`, `ArgUInt32`, `ArgInt64`, `ArgUInt64` | `CallInt8` … `CallUInt64` |
| `float` | `ArgFloat` | `CallFloat` |
| `double` | `ArgDouble` | `CallDouble` |
| `void*` | `ArgPointer` | `CallPointer` |
| `const char*` | `ArgString` | `CallString` |
| нет значения | | `CallVoid` |

`ArgString` копирует строку и хранит копию, пока VM не освобождена. `CallString` копирует возвращённую C-строку в строку вашего языка.

Для метода C++ передайте `this` первым аргументом через `ArgPointer`.

## Соглашения о вызове

Новая VM использует соглашение платформы по умолчанию. `Mode(vm, mode)` меняет его, `mode` это число из `dyncall.h`:

| Режим | Значение |
|---|---|
| По умолчанию для платформы | `0` |
| Метод C++, по умолчанию для платформы (`this` первым аргументом) | `99` |
| Вариативная функция, обычные аргументы | `100` |
| Вариативная функция, часть `...` | `101` |
| Windows x64 | `7` |
| System V x64 (Linux) | `8` |

`GetModeFromCCSigChar` возвращает режим по символу соглашения о вызове из сигнатуры dyncall, например `:` для режима по умолчанию.

## Пример: функция из gamedata

Адрес обычно берут из сигнатуры в [gamedata](/ru/plugins/s2sdk/guides/gamedata). Здесь `GetCSWeaponDataFromKey(int, const char*)` из gamedata Source 2 SDK возвращает данные оружия:

```python
from plugify.pps import s2sdk as s2
from plugify.pps import dyncall as dc

func = s2.GetGameConfigSignatureAll("GetCSWeaponDataFromKey")

vm = dc.NewVM(4096)
dc.Reset(vm)
dc.ArgInt32(vm, -1)
dc.ArgString(vm, "weapon_ak47")
weapon_data = dc.CallPointer(vm, func)
dc.Free(vm)
```

## Структуры по значению

Функции, которая принимает или возвращает структуру по значению, нужно описание её раскладки:

1. `NewAggr(fieldCount, size)` создаёт описание структуры размером `size` байт.
2. `AggrField(aggr, type, offset, arrayLength)` добавляет поле. `type` это `SigChar`, например `SigChar.Int` или `SigChar.Float`.
3. `CloseAggr(aggr)` завершает описание.
4. `ArgAggr(vm, aggr, value)` передаёт структуру из памяти по адресу `value`. Для возвращаемой структуры вызовите `BeginCallAggr(vm, aggr)` перед передачей аргументов, затем `CallAggr(vm, func, aggr, returnValue)` запишет результат в `returnValue`.
5. `FreeAggr(aggr)` освобождает описание.

## Замечания

- Аргументы должны точно совпадать с сигнатурой функции по числу, порядку и типам. Неверный тип приводит к неопределённому поведению.
- Адрес должен указывать на функцию с одной и той же сигнатурой на каждой платформе. Функции игры часто отличаются в Windows и Linux.

Полный список функций с сигнатурами есть в [API Hub](https://api.plugify.net/?file=https://raw.githubusercontent.com/untrustedmodders/plugify-plugin-dyncall/refs/heads/main/plugify-plugin-dyncall.pplugin.in).
