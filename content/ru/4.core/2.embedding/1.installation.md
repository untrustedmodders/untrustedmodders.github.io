Эта страница для интеграторов: тех, кто встраивает Plugify в своё приложение или работает над ядром. Она показывает, как получить ядро и запустить `plug`, небольшое тестовое приложение, которое идёт вместе с ним.

::alert{type="info" icon="lucide:package-open" to="/ru/builds"}
Настраиваете игровой сервер? Эта страница вам не нужна. Поставьте готовый билд.
::

## Что вы получаете

В репозитории [plugify](https://github.com/untrustedmodders/plugify) лежат:

- **библиотека ядра**, с которой линкуется ваше приложение;
- **`plug`**, консольное приложение, в которое встроено ядро. Оно загружает модули и плагины из папки и принимает те же команды, что и команда `plg` в игровых загрузчиках.

`plug` это самый быстрый способ проверить плагин или языковой модуль вне игры.

## Запуск тестового приложения

::steps
### Клонируйте репозиторий
```bash
git clone https://github.com/untrustedmodders/plugify.git --recursive
cd plugify
```

### Соберите
```bash
mkdir build && cd build
cmake ..
cmake --build . --target plug
```

Нужные компилятор и инструменты перечислены в [инструкциях по сборке](/ru/core/embedding/building).

### Добавьте модули и плагины
Создайте папку `extensions` в той папке, из которой запускаете `plug` и положите в неё языковые модули и плагины, каждый в свою папку:

```bash
mkdir extensions
```

::file-tree
---
tree:
- build:
    - ^plug^
    - extensions:
        - plugify-module-cpp:
            - bin/
            - cpp_module.pmodule
        - my_plugin:
            - bin/
            - my_plugin.pplugin
---
::

### Запустите
Выполнить одну команду и выйти:

```bash
./plug plugins
```

Или запустить интерактивную консоль с `-i` и вводить команды, например `load`, `plugins` и `modules`:

```bash
./plug -i
```

Базовой папкой `plug` считает ту, из которой он запущен. Он находит все манифесты в `extensions`, загружает модули, а затем плагины. Список команд показывает `./plug --help`.
::
