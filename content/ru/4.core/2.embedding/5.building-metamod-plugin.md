[MM-Loader](https://github.com/untrustedmodders/plugify-metamod-loader) — плагин Metamod:Source, который загружает Plugify в Counter-Strike 2. Владельцу сервера собирать его не нужно: он уже есть в [билде](/ru/builds). Эта страница для тех, кто хочет изменить хост или собрать его сам.

## Что нужно

То же, что для [ядра](/ru/core/embedding/building): компилятор с C++23, CMake, Ninja и Git. Официальные билды для Linux собираются GCC 14 в контейнере Steam Runtime `registry.gitlab.steamos.cloud/steamrt/sniper/sdk`, чтобы результат работал на игровом сервере.

## Сборка

::steps
### Клонируйте репозиторий с сабмодулями
Metamod:Source, ядро, Source 2 SDK и другие библиотеки подключены Git-сабмодулями:

```bash
git clone https://github.com/untrustedmodders/plugify-metamod-loader.git --recursive
cd plugify-metamod-loader
```

### Сконфигурируйте и соберите
```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --target plugify-metamod-loader
```
::

## Результат

Ядро влинковано в сам плагин. В папке сборки появляются:

- `libplugify.so` (Linux) или `plugify.dll` (Windows), плагин Metamod;
- `micromamba`, пакетный менеджер, которым пользуется хост;
- `addons/metamod/plugify.vdf`, файл, по которому Metamod загружает плагин.

На сервере плагин и `micromamba` кладутся в `csgo/addons/plugify/bin/<платформа>/`, а папка `addons` в `csgo/`, см. [установку плагина Metamod](/ru/builds/hosts/metamod-plugin/installation).
