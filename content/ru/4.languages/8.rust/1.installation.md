**Языковой модуль Rust** можно установить двумя способами: вручную, загрузив релиз, или с помощью менеджера пакетов Plugify. Это руководство объясняет оба метода и предоставляет пошаговые инструкции.

## **Метод 1: Ручная установка**

::steps
### **Загрузите релиз**
1. Перейдите в [репозиторий языкового модуля Rust](https://github.com/untrustedmodders/plugify-module-rust).
2. Перейдите в раздел **Releases**.
3. Загрузите последний пакет релиза (например, `plugify-module-rust.zip`).

### **Извлеките пакет**
1. Извлеките загруженный пакет во временный каталог.

### **Поместите модуль в папку модулей**
1. Найдите папку `extensions` в вашем каталоге установки Plugify.
2. Скопируйте извлеченные файлы модуля в папку `extensions`.

### **Проверьте установку**
1. Запустите Plugify.
2. Языковой модуль Rust теперь должен быть доступен для использования.
::

## **Метод 2: Установка через менеджер пакетов**

::steps
### **Настройка Mamba**
Прежде чем продолжить, убедитесь, что у вас установлен [менеджер пакетов Mamba](https://mamba.readthedocs.io/en/latest/user_guide/mamba.html#mamba-user-guide) и вы понимаете основы создания и управления окружениями.
Если вы новичок в Mamba, ознакомьтесь с **Кратким руководством** в официальной документации.

### **Установите модуль**
1. Выполните следующую команду в вашем терминале (замените `your_env_name` на имя вашего окружения):
   ```bash
   mamba install -n your_env_name -c https://untrustedmodders.github.io/plugify-module-rust/ plugify-module-rust
   ```

### **Проверьте установку**
1. Запустите Plugify.
2. Языковой модуль Rust теперь должен быть установлен и готов к использованию.
::

## **Структура папок**

После установки языковой модуль Rust должен иметь следующую структуру папок:

::file-tree
---
tree:
- res/extensions:
    - plugify-module-rust:
        - bin:
            - plugify-module-rust.dll
            - libplugify-module-rust.so
        - ^plugify-module-rust.pmodule^
---
::

### **Объяснение**
- **`res/extensions/plugify-module-rust`**: Корневая папка для языкового модуля Rust.
- **`bin`**: Содержит скомпилированные бинарные файлы модуля (`.dll` для Windows, `.so` для Linux и т.д.).
- **`plugify-module-rust.pmodule`**: Файл манифеста модуля, который описывает модуль и его язык.

## **Необходимые компоненты**

Перед использованием языкового модуля Rust убедитесь, что у вас установлено следующее:

### **Тулчейн Rust**
Языковому модулю Rust требуются компилятор Rust и Cargo (менеджер пакетов Rust).

::steps
### **Установите Rust**
1. Перейдите на [https://rustup.rs/](https://rustup.rs/)
2. Следуйте инструкциям по установке `rustup` — установщика тулчейна Rust
3. Проверьте установку:
   ```bash
   rustc --version
   cargo --version
   ```

### **Установите нужные таргеты** (опционально)
Для кроссплатформенной разработки вам может потребоваться установить дополнительные таргеты:
```bash
# Для Windows
rustup target add x86_64-pc-windows-msvc

# Для Linux
rustup target add x86_64-unknown-linux-gnu

# Для macOS
rustup target add x86_64-apple-darwin
```
::

## **Устранение неполадок**

### **Модуль не найден**
- Убедитесь, что URL репозитория правильный и доступен.
- Проверьте, что файлы модуля размещены в правильной папке `extensions`.

### **Ошибка установки**
- Проверьте ваше интернет-соединение.
- Убедитесь, что у вас установлена последняя версия Plugify.

### **Тулчейн Rust не найден**
- Убедитесь, что Rust корректно установлен и доступен в системной переменной PATH.
- Попробуйте перезапустить терминал или IDE после установки Rust.
