Мы рады идеям для Plugify. Здесь описано, как предложить идею, чтобы её обсудили и рассмотрели.

## Как предложить возможность

::steps
### Проверьте существующие запросы
Просмотрите [открытые запросы возможностей](https://github.com/untrustedmodders/plugify/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement) и [обсуждения](https://github.com/untrustedmodders/plugify/discussions). Если ваша идея там уже есть, поставьте реакцию 👍 и опишите свой сценарий в комментарии.

### Выберите нужный репозиторий
Запрос для ядра открывайте в [plugify](https://github.com/untrustedmodders/plugify/issues). Запрос для языкового модуля, хоста или плагина открывайте в issue этого репозитория.

### Откройте issue
Нажмите **New issue** и опишите возможность. Если не уверены, что идея подходит, сначала начните обсуждение или спросите в [Discord](https://discord.gg/rX9TMmpang).
::

## Что указать

```markdown
### Description
What the feature does.

### Use case
What problem it solves and who needs it.

### Alternatives
How you work around it today.

### Additional context
Examples, links to similar features elsewhere, sketches.
```

## Советы

- **Описывайте проблему, а не только решение.** Сценарий использования помогает найти лучший способ её решить.
- **Одна возможность на запрос.**
- **Будьте конкретны**: какая часть Plugify, какой язык, какой хост.

## Что дальше

Разработчики читают запрос и обсуждают его в issue. Принятые идеи помечаются и реализуются, когда есть время; pull request с их реализацией приветствуются, см. [Как внести вклад](/ru/core/contributing/how-to-contribute).
